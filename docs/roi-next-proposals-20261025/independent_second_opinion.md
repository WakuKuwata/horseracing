2026-10-25。読み取り対象は142〜146の既存結果・保存予測、2026-10-05/08/10の既往研究。追加モデル学習、新しい購入条件・混合比・閾値の採点は行っていない。

## 確認できたこと

1. 144・145・146はいずれも利益の点推定が基準・③を下回ったが、利益差の補正区間は0を含む。「この方式が将来も劣る」「③が真に優れる」とは判定できない。
2. 既知の105.7倍の1件を除いても、各案の③比利益差は144 −108,790円、145 −411,670円、146 −149,790円。失敗はその的中を逃したことだけでは説明できない。
3. 全体NLL改善と購入に関係する領域の改善は異なる。保存予測7条件・343,883頭を独立にキー照合し、正規化確率からwinner NLLを再計算した。基準のraw EVで固定分割すると、145併用−基準の全体NLL差−0.00159465は、基準EV≤1の勝馬22,653頭が−0.00248609寄与する一方、EV1〜1.2の勝馬1,926頭が+0.00055692、EV>1.2の勝馬276頭が+0.00033452寄与している。基準の購入域の勝馬に対する平均差は+0.03012475と悪化していた。pace単独も同型だった。
4. 144新案−③の全体NLL差は−0.00012996だが、基準EV>1.2の勝馬群では+0.00223647だった。一方、146−③は全体+0.00055671の悪化に対し、その同じ勝馬群では−0.00043894だった。したがってこの分解だけで全ての利益差は説明できない。勝馬だけの事後診断であり、候補が実際に選ぶ全頭集合や賭け金配分を評価した指標でもない。
5. 144のa×b=wは数値的に厳密でも、LightGBMの2モデルの予測や利益が加算分解されるという意味ではない。146は古いOOFを加えたことで、古い行のカバー率と情報あり集合の正規化分母が同時に変化した。各々の単独効果は分離されていない。

独立分解コードと全数値は `independent_loss_attribution.py` / `independent_loss_attribution.json`。winner NLLと二値LogLossの両方を、固定基準EV帯・固定オッズ帯へ分解し、寄与和が全体差に一致することをassertした。各入力SHAを記録している。

- **seed一致度・seed SD・下側分位**：2026-10-10ではEV帯内の較正差を分けず、R10V2のseed SD係数は全年0。seed数追加も15本付近で飽和。今回のseed境界診断で不安定性が見えても、直ちに一致gateが収益を上げる根拠にはならない。
- **単純な較正と市場混合**：1D isotonic・温度・選択後較正は既試行。q+ens年次混合も既試行、142のraw>1.2かつmix>1.0交差は118.20%・+656,550円の点推定だが区間は0を含み、2026年は悪化。未実施の新案として紹介しない。
- **Kelly・逆オッズ・edge比例**：2026-09-30 F1等で既試行。資金配分は予測情報を生まず、軟らかい選定規則として同じ不確実性に服する。
- **直接収益回帰/Huber、20文脈の2段残差、R11市場offset、直近8年窓、earlystop/HPO、固定race-softmax**：既試行。変更点を特定しない一般的な再提案は避ける。
- **価格±10% gate**：既往で親内null p≈.93。倍率を変える探索を新案として数えない。
- **時間別オッズの再取得・前向き捕捉**：ユーザーが従来保留した範囲。今回の既存データ研究へ勝手に追加しない。

## 残る案への意見

**第一候補は異質モデルの確率平均**。基準77特徴と重みなしpace91特徴の保存15seed平均を、事前固定した比率で平均する。145は特徴と重みを同じ学習へ入れた比較であり、別学習した予測の平均とは異なる。旧「本番p合議」は別の勝率モデルとの合議であり、今回のpaceモデルとの平均を直接否定しない。再学習0で研究でき、特徴増加による買い目の全面変更を抑える仮説を検証できる。ただし混合は新情報を生まず、利益改善の保証はない。比率を2019〜2026の利益で選ぶことは避ける。

**異質モデル間の補助gateは第一候補と同族の別腕**。元の予測と購入条件を維持し、paceとの不一致がある買い目のみ見送り判定へ使う。seed一致度とは異なるが、過去に失敗した「合議」を言い換えただけになり得る。平均とgateを別々の独立改善源として数えず、家族内比較を明示する。gateが減らした点数だけでROIが上がったように見えないよう、利益・投資額・同じ予算・年別・高配当依存を併記する。

**学習を続けるなら市場列の重複を減らす小さな固定ablationを低優先で検討**。現在の市場ブロックはodds/q/popularity/odds_rank等の12列であり、以前のR11は全12市場列を除いたoffset別目的関数であった。qを残して重複順位・自馬odds等の一部だけを除く比較は変更点が異なる。ただし既に市場列が強いこと自体は欠陥を示さず、過去の少量特徴/HPO研究との重複確認が必要。優先度は保存予測による比較より下で、利益が上がるという直接根拠はまだない。

## 次回比較の必須条件

固定比率なら採点前に定義と対照を凍結する。学習する混合係数やgateなら年Yに対しY−1以前のOOFだけで決定し、候補の選択・ハイパーパラメータもその内側で完結する。外側2019〜2026は既参照なので未使用検証と呼ばない。新しい候補を多数作って同じ外側利益で選ばない。

現行同条件基準・③に加え、pace単独および元の購入政策を対照に置く。全807開催日を共通にし、購入0日も含める。回収率・利益・投資額・勝数予測の較正・高払戻依存・年別・最大DDを全件報告し、比較族を補正する。2026年の部分年と全年の寄与を単純比較しない。確定オッズ代理精算・既参照期間という限界を維持する。

この独立意見は候補の採用や実施を承認する文書ではなく、既往重複と原因説明の過大解釈を避けるための第二意見である。

## 最終候補2案の追加監査

root案の「③の予測確率をレース内で合計1へ直し、同じレース予算で比較する」は、**既往手法の未比較の組合せ**として実在する。`scripts/roi_explore/comprehensive_20261005/online_normalization.py` のprotocolは、旧現行ens15を対象に、選択した全馬へ固定100円を置く。`scripts/roi_explore/roi_improvement_142/policies.py` の5政策にはpure `p/Σp` は無い。143の`score()`はNLL/ECE用に正規化確率を計算するが、購入はraw EVを使い、144〜146も同じ購入ルールを再利用している。したがって、元③×予測確率正規化×1レース1,000円の組合せは、これらの研究では採点されていない。

これは正規化という新原理の発見ではなく、旧N1を別の保存予測・同予算配分へ適用する追加比較である。旧N1のROIや改善幅を新案の期待利益として扱ってはいけない。とくにレース別の資金の重みが固定100円/頭から変わるため、旧ROIの移植はできない。

最終提案は、(1)基準77と重みなしpace91の固定1:1確率平均、(2)元③と基準それぞれの予測確率正規化、の2案で十分である。新規性と今回の展開モデルの結果から(1)を先に置き、(2)を低費用の追加確認とする順序に賛成する。両案とも追加fitは0で、まだ新政策の成績は計算していない。

正規化は完全な出走集合の各馬の15seed平均を先に作り、その全頭和で割る。選択後の買い目だけを分母にしない。基準/③×raw/正規化の4条件を残すと、③だけで有効なのか、共通の配分変更なのかを区別できる。正規化だけではwinner NLLは変わらず、購入対象と配分の評価であることを明確にする。平均案と正規化案を結果を見て組み合わせたり、混合比・EV閾値を追加探索したりしない。
