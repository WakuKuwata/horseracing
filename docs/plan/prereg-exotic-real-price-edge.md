# 事前登録 — 実 exotic 価格に対する EV 政策

**Status**: PRE-REGISTERED(実行前に確定。以後の変更は契約変更として記録する)
**Created**: 2026-07-30
**目的**: 利益仮説(ROI > 1.0)の追求
**関連**: [accuracy-roi-decoupling-investigation.md](accuracy-roi-decoupling-investigation.md) §5.2a-d

## これまで測れなかった理由と、いま測れる理由

Hausch–Ziemba–Rubinstein (1981) が正の期待値を得た方法は「勝ちプールが示す確率」と
「**別プールが実際に付けている価格**」のズレを突くことだった。我々は後者を持っていなかったため、
組合せ券種の測定(§5.2c)は**勝ちプールから合成した推定価格**で選定するしかなかった。
合成価格は定義上いつも勝ちプールと整合するので、**ズレそのものが構造的に存在し得ない**測定だった。

netkeiba のオッズ API が `type=4..8` で負け組を含む全通りの価格を返すと判明し(§6.1b)、
**1,001 レース / 169 開催日**を取得済み。これで初めて「割安な組合せを買う」政策が定義できる。

**前提として λ の是正が必要だった**(§5.2d)。勝ちプール由来の確率が実価格から 30% ずれた状態では、
観測されるズレが我々の導出誤差か市場の歪みか区別できない。ワイドで 0.704 → 0.941 まで直したので、
残差を市場側の情報として読める。

## 母集団

- `exotic_quotes` に価格グリッドがあり、かつ `exotic_odds` に実配当があるレース
- started 全頭に有効な単勝オッズがある(勝ちプール q が完全な field で作れる)
- 結果表の 1 着馬が複勝配当に現れる(取込整合性・§5.2a と同じチェック)
- **想定件数: 約 1,001 レース / 169 開催日**(実行時の実数を出力に記録する)

## 政策(固定)

**確率**: 勝ちプール q → 009 エンジン(stage discount は現行既定 λ=0.75/0.70)。
**モデル p は使わない** — ΔR² ≈ 0 かつ組合せ選定で市場 q に全券種で負けた(§5.2c)ため。

**価格**: 実 exotic 価格グリッド `O_real`。ワイドは下限を使う(保守側)。

**選定**: `EV = P_market × O_real` が閾値以上の組合せを全部買う。
閾値 **T ∈ {1.0, 1.1, 1.2, 1.5, 2.0}**(事前固定・実行後に足さない)。

**券種**: 馬連 / ワイド / 三連複(グリッド取得済みの 3 種)。

**賭け金**: 1 点あたり等額(flat)。

**精算**: 実配当。的中組合せを買っていればその配当、そうでなければ 0。同着は複数支払う。

## 主判定

セル = (券種 × 閾値) = **15 セル**。各セルで `ROI = Σ払戻 / Σ賭け金`、
**開催日クラスタ bootstrap**(B=2000, seed 20260730, 両側 95%、replicate ごとに分母も再計算)。

| 条件 | 判定 |
|---|---|
| `ROI` の CI 下限 > 1.0 | **profitable** |
| CI 上限 < 1.0 | unprofitable |
| それ以外 | NO_DECISION |

**多重比較**: 15 セルに **Holm 補正**(一側 bootstrap p 値 `P(ROI ≤ 1)`)。補正後に生き残ったものだけを
利益の主張に使う。

## 必須の付帯診断(§5.2c と同じ降格ルール)

各セルについて出力する:
- `n_races` / `n_bets` / `n_hits` / `n_days`
- **最大 1 的中の払戻寄与率**
- **leave-one-hit-out ROI**
- 参照値(控除率): 馬連・ワイド 0.775 / 三連複 0.750

`n_hits < 20` または `最大 1 的中の寄与率 > 0.5` のセルは、CI に関わらず **NO_DECISION に降格**。

## 事前に想定される交絡(結果を見る前に記録)

1. **取得したグリッドは確定後レースの最終オッズ**。選定に最終価格を使うのはこれまでの全測定と
   同じ closing lookahead だが、**exotic では影響がより大きい可能性がある**(締切直前の資金流入が
   組合せ価格を大きく動かす)。発走前グリッドが貯まるまで解消できない。
2. **自己影響を測れない**。薄い組合せプールでは自分の購入が配当を下げるので、実運用の ROI は
   これより低い。
3. **P_market の残差**(§5.2d)。1000 倍超の帯は全券種で 0.70〜0.85、三連複は約 10% 行きすぎ。
   **EV が高く出る組合せは、市場が割安なのではなく我々の確率が高すぎるだけかもしれない。**
   → 帯別の内訳を必ず出し、EV の高いセルが特定の帯に偏っていないか確認する。
4. 169 開催日。§4.2 の外挿で MDE はおよそ 0.04。数ポイントの効果は検出できない。
5. ワイドの下限を使うため、ワイドの EV は構造的に保守側になる。

## 予測(結果を見る前に記録)

- 実 exotic 価格が勝ちプールと整合しているだけなら、全セルが `1 − takeout` 付近に並ぶ。
- HZR 型の非効率が JRA にも存在するなら、高い閾値のセルほど ROI が上がり、
  どこかで 1.0 を超える。
- **交絡 3 が真なら、EV の高いセルは 1000 倍超の帯に偏り、ROI はむしろ下がる。**
  この 3 つを実行前に区別できる形で記録しておく。
