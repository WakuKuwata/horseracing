## なぜこれを測るのか

これまで測ったのは **「単勝・複勝を、1 点ずつ、均等額で」** という形だけだった。
一方、日本で唯一検証可能な利益事例(最高裁 2 件)は**まったく別の構造**をしていた:

| | 既測 | 判例 |
|---|---|---|
| 券種 | 単勝・複勝 | **馬連・馬単・三連複** |
| 買い目 | 1 点 | **1 開催日あたり数百〜1,000 点超** |
| 賭け金 | 均等 | **残高 × 係数 ÷ オッズ** |
| 結果 | 0.72–0.86 | **104.9% / 107.83%(6 年連続黒字)** |

判例の被告人は**市場を上回る勝率予測をしていない**(公開データ + 市販ソフト)。勝ったのは
**組合せの選び方と賭け金配分**である。この構造は我々のデータで未検証。

理論的な傍証:
- Benter: 「賭けが specific であるほど advantage は高い」。単勝で EV 0.955 / 0.996 の**両方とも EV<1**
  の 2 頭が、quinella では **EV 1.16** になる数値例を提示。
- Snowberg & Wolfers (2010): 206,808 レースで **exotic 価格が win 価格から系統的に予測可能**。
- 我々の複勝 cross-pool の +7%(§5.2a)は「1 点・均等」での話。組合せプールの歪みは桁で大きい可能性がある。

## 政策(固定)

**選定確率**: 009 エンジンに **市場 q**(単勝オッズ由来・complete field)を入れて全組合せの確率を導く。
これを **PRIMARY** とする(ΔR² ≈ 0 でモデル p は市場に情報を足していないため)。
モデル p 由来は SECONDARY。

**買い目**: 確率上位 **K ∈ {1, 3, 5, 10, 20, 50}** 点。K は事前固定。実行後に足さない。

**賭け金**:
- **flat**(PRIMARY): 1 点あたり等額。1 レースの総賭け金 = K 単位。
- **inverse_odds**(SECONDARY・判例の方式): 1 レース総額 1 単位を `∝ 1/O_est` で配分。
  `O_est` は**単勝オッズのみ**から作る(010)ので発走前に計算可能=リークしない。

**精算**: 実配当。的中組合せを買っていればその配当 × 賭け金、そうでなければ 0。
同着は複数の的中組合せが立つので**それぞれ支払う**。

## 主判定

各セルで `ROI = Σ払戻 / Σ賭け金`、**開催日クラスタ bootstrap**(B=2000, seed 20260729, 両側 95%、
replicate ごとに分母も再計算)。

| 条件 | 判定 |
|---|---|
| `ROI − 1` の CI 下限 > 0 | **profitable** |
| CI 上限 < 0 | unprofitable |
| それ以外 | NO_DECISION |

## 多重比較(実行前に規定)

**主ファミリ** = 4 券種 × 6 K × flat × 市場 q = **24 セル**。**Holm 補正を適用**する。
それ以外(inverse_odds / モデル p / 三連単)は **exploratory** とし、補正せず、
単独で利益主張の根拠にしない。

## 必須の付帯診断(codex 指摘・実行前に固定)

各セルについて出力する:
- `n_races` / `n_bets` / `n_hits`
- **最大 1 的中の払戻寄与率**(1 件で利益が作られていないか)
- **leave-one-hit-out ROI**(最大の的中を除いた ROI)
- 開催日数

`n_hits < 20` または `最大 1 的中の寄与率 > 0.5` のセルは、CI に関わらず **NO_DECISION に降格**する。

## 事前に想定される交絡(結果を見る前に記録)

1. 選定は closing 寄りの単勝オッズ由来 → **選定側に lookahead**。払戻側は本物。
2. **実 exotic の発走前価格は無い**ので、これは「勝ちプールから作った合成確率で固定した政策が、
   将来払戻に対して勝つか」であり、「実 exotic プールの割安な組合せを発見する政策」ではない。
3. 67 開催日。§4.2 の外挿で **MDE ≈ 0.066**。数ポイントの効果は検出できない。
4. 自己影響(自分の購入が配当を下げる)は測れない。薄い組合せプールでは実運用の ROI はこれより低い。
5. 控除率: ワイド/馬連 22.5%、馬単/三連複 25% → 損益分岐に必要な市場比優位は ×1.29 / ×1.33。

## 予測(結果を見る前に記録)

- 組合せプールが勝ちプールの単なる写像なら、全セルが `1 − takeout`(0.775 / 0.75)付近に並ぶ。
- 判例の構造が再現するなら、多点(K 大)× 人気サイド寄りのセルで 1.0 超が出る。
- **どちらでも解釈できるよう、両方の可能性を実行前に明記しておく。**
