## 0. Executive Summary

1. **精度は ROI の式に現れない。** パリミュチュエルでは `ROI = E_A[c_r · t/q] − 1`(`c_r` = 1/overround)であり、モデルは「どの賭けを選ぶか」経由でしか ROI に入らない。利益条件は `t/q > 1.25`、実測は `1.02`。
2. **現行モデルの ROI 寄与は測定限界内でゼロ。** `odds<21` の全馬を**モデル抜き**で買うと 0.8123、モデル EV≥1.0 を掛けると 0.8120(差 −0.0003、95%CI [−0.023, +0.023])。既報の `×0.816` は**オッズ上限だけ**の効果である。
3. **機構も特定した。** 市場 q の上にモデル p をブレンドした最適重みは **a ≈ 0.0085 ≒ 0**。モデルは市場が知らない情報をほぼ持っていない。これは Benter(1994)の枠組みで **ΔR² ≈ 0**、同論文が反例として挙げた「新聞予想家集計」と**数学的に同一の状態**である。
4. **世界の到達点でも足りない。** 米 CAW の粗回収は約 90%(一次資料)。黒字化はリベート 10–13% による。**JRA にリベート制度は無い。**
5. **残る道は 3 本**: ①券種を変える(cross-pool / exotic・複勝) ②判定指標を ΔR² に変える ③市場が織り込んでいない可能性のある未読データ。**先に測定契約を直す必要がある。**
6. **単勝の精度改善を ROI レバーとみなす路線は閉じた。** これは失敗ではなく、確定した測定結果である。
7. **【2026-07-30 追記】唯一の正の結果 — exotic プールは勝ちプールが持たない情報を持つ。**
   実 馬連 グリッド由来の信号は `ΔR²(exotic|win) = +0.001687`・CI [+0.00074, +0.00274]・
   ブレンド重み α ≈ 0.62(モデル p は 0.004)。**ただし利益への変換は 2 通り試して両方失敗**
   (実価格 EV ルール §5.2e / 比の閾値で単勝 §5.2g)。情報の存在と利益化は別問題であり、
   +0.0017 は Benter の基礎モデルの 1/10 = 控除率 20% を埋めるには 1 桁足りない。

## 1. 機構 — なぜ精度が ROI に変換されないのか

### 1.1 閉じた式

レース `r`、馬 `i` について `t` を真の勝率、`p` をモデル確率、`q` を市場確率、`O` を払戻倍率とする。表示オッズから devig すると

```
q_ri = (1/O_ri) / Σ_j (1/O_rj)
c_r  = 1 / Σ_j (1/O_rj)          →  O_ri = c_r / q_ri
```

したがって flat stake の回収率は

```
ROI(A) = E_A[ c_r · t/q ] − 1 = E_A[ c_r · (1 + (t−q)/q) ] − 1
```

**利益条件**(単勝 `c ≈ 0.8`):

```
t/q > 1/0.8 = 1.25        すなわち  (t−q)/q > 25%
```

**モデル確率 `p` はこの式に一度も現れない。** `p` は賭ける集合 `A` を決めることでしか ROI に影響しない。「精度を上げれば回収率が上がる」という前提が成り立つのは、精度改善が `A` を `t/q > 1.25` の領域へ動かした場合に限られる。

### 1.2 実測値との対応

| 指標 | 実測 |
|---|---|
| overround(実測平均) | 1.25696 → `c = 1/overround = 0.7961` |
| cap 方策の `E_A[t/q]` | `0.816 / 0.80 = **1.02**` |
| 必要値 | **1.25** |
| 047 本命帯(q≥0.30)の `t/q` | `0.413 / 0.405 = **1.020**` |

FL バイアスの**符号は存在するが、控除率を越える大きさが無い**。これが状況の全てである。

### 1.3 方策の幾何学

```
x = log(p/q)     モデルが観測する乖離
y = log(t/q)     真の乖離
h = −log c ≈ 0.223
```

- モデル EV 方策が選ぶ領域: `x ≥ h`
- 真に利益が出る領域: `y ≥ h`

低 `q`(大穴)ほどモデルの tail 過大により **`x` だけが大きくなり `y` は上がらない**。帰結:

- **EV 閾値を上げるほど右へ進むだけで利益領域には近づかず、悪化する**(実測 EV≥1.3 で ×0.703)
- **odds cap は正のエッジの発見ではなく、誤差分散と過信が最大の領域の削除**である

### 1.4 LogLoss との関係(全馬比例賭けの場合)

race-level winner NLL について `L(p) = H(t) + E[D_KL(t‖p)]`、`L(p) − L(q) = E_t[log(q_W/p_W)]`。
資金比率 `p_i` で全馬に賭けるポートフォリオの期待対数成長率は

```
G(p) = E_t[ log(c · p_W/q_W) ] = log c + L(q) − L(p)
```

`p = q` でも `G(q) = log 0.8 = −0.2231`。正の成長には **`L(p) < L(q) − 0.2231`** が必要。
実測(2019+ OOS, winner NLL): モデル **2.0700** / 市場 **1.9327** → 必要値は **1.7087**、改善量 **0.361** = F02 の改善幅(0.00575)の約 **63 倍**。

ただしこれは全馬比例賭けの式であり、選択的な固定額ベットでは単一の LogLoss から ROI を一意に逆算できない。稀な部分集合だけ当てれば、全体で `p` が `q` に負けていても利益は論理上可能である(§5.1)。

### 2.3 機構の裏付け — 最適ブレンド重み

市場 q の上にモデル p を race-softmax でブレンド(`p^a · q^b`)し winner NLL を最小化:

| 構成 | winner NLL |
|---|---|
| a=1, b=0(モデル単独) | 2.06997 |
| a=0, b=1(市場単独) | 1.93272 |
| **最適 a=0.0085, b=1.0178** | **1.93245**(市場単独からの改善 +0.00027) |
| 市場の power 較正のみ(a=0) | 1.93246(ブレンド利得は **+0.00001**) |

**モデル p は市場が知らない情報をほぼ 1 ビットも持っていない。**

### 2.4 構造的な壁

- **`q·O` はレース内で完全に定数**。実測 `mean(q·O) = 0.7959`。
  → **市場と全く同じ確率を持つ予測子は、EV≥1.0 の賭けを 1 つも生成できない**(358,047 行中トリガー 420 行 = 0.12%、それもオッズ欠測起因のアーティファクト)。
  → 「市場と同等の精度」の回収率上限は **0.796 で、しかも賭ける対象が存在しない**。ROI>1 には市場を*上回る*しかない。
- **市場 q の FL 補正**: `q^γ` の最適 **γ = 1.0246 ≒ 1**、winner NLL 改善 0.00026。**オッズだけから搾れる系統バイアスは実質ゼロ。**
- **オッズのみを使う in-sample 40 分位較正オラクル**(オッズだけ知る者の理論上限)でも EV≥1 回収率 0.7435 / odds<21 で 0.8691。**1.0 に届かない。**

### 2.9 精度弾力性

**オラクル補間実験**(`p_mix ∝ p^(1−t) · u^t`, `u = normalize(y+0.01)`)。
**注: これは達成可能性の見積もりであってモデルではない**(y を混ぜている = 定義上リーク)。

| t | binLogLoss | Δ | EV≥1 回収 | EV≥1&O<21 回収 |
|---|---|---|---|---|
| 0(現行) | 0.21659 | — | 0.7363 | 0.8120 |
| 0.010 | 0.21331 | −0.0033 | 0.7871 | 0.8984 |
| 0.020 | 0.21003 | −0.0066 | 0.8419 | **0.9970** |
| 0.050 | 0.20030 | −0.0163 | 0.9728 | 1.3093 |
| 0.075 | 0.19229 | −0.0243 | **1.0847** | 1.5888 |

**ROI=1.0 に必要な binLogLoss**: 補間方式により **0.19835〜0.20994**(現行との差 **−0.0067〜−0.0182**)。

**判断: 非現実的。** 理由は 3 段階。

1. 必要量 −0.007〜−0.018 は、プロジェクト全史の改善量(0.2388→0.2145 = **−0.0243**)と同オーダー。「もう一度これまでの全歴史ぶん」に相当。
2. 到達点 0.198〜0.209 は**市場の 0.20509 とほぼ同じかそれ以下** = 市場に並ぶか上回る精度が必要。
3. **決定的**: 実際には過去 15 世代 −0.0243 の改善で ROI は動かなかった。補間実験は**市場と直交する情報**を注入するが、現実の改善は **p を q に近づけた**だけ(最適ブレンド重み a≈0.0085 がその証拠)。
   実モデル世代間の実測弾力性は lgbm-061→065 で **符号すら逆**(ΔL −0.000492 に対し cap 回収 0.818→0.816)。

> **LogLoss は ROI の十分条件ではない。同じ LogLoss でも市場と同じ情報なら ROI 効果はゼロ。**

## 3. 文献 — 世界の到達点と、我々の位置

### 3.1 Benter(1994)の実像 — 利益の源泉は「基礎モデル」ではない

原論文([gwern ミラー](https://gwern.net/doc/statistics/decision/1994-benter.pdf) / [World Scientific](https://www.worldscientific.com/doi/10.1142/9789812819192_0019))の二段目モデル:

```
c_i = exp(α·f_i + β·π_i) / Σ_j exp(α·f_j + β·π_j)
f_i = out-of-sample 基礎モデル確率の対数
π_i = 公衆インプライド確率の対数
```

**これは我々のブレンドと同型である。** 論文の pseudo-R²(Bolton–Chapman 定義):

| 対象 | pseudo-R² |
|---|---|
| 公衆推定のみ | 0.1218 |
| **基礎モデルのみ** | **0.1245** ← 単独で公衆に勝っていた |
| 合成 | 0.1396 |
| **ΔR²** | **0.0178** |

同論文が挙げる**反例**(2,313 レース):

| モデル | standalone R² | 合成後 | ΔR² |
|---|---|---|---|
| 基礎モデル(9因子) | 0.1016 | 0.1327 | **+0.0090** |
| 新聞予想家 48 人集計 | 0.1014 | 0.1239 | **+0.0002** |

tipster モデルは「公衆と食い違ったときは公衆の方が正しい」ため、二段目を通すと**常に公衆と同一出力になり advantage bet が一切出ない**。

> **我々の a≈0 は、この tipster ケースと数学的に同一の状態である。**
> Benter 本人が「ΔR² が大きいほど例外なくシミュレーション収益も大きかった」と述べており、
> **ΔR² は我々がまだ計測していない、文献上の標準ヤードスティックである。**

その他の一次情報:
- **リベートの記述は 1994 年論文に一切なし。** 当時の香港平均控除率は本文で「約 19%」と明記。
- **券種**: 「normal と exotic の両プールで正の期待値のベット全てに賭けた。ただし place と show は除く」。EV<1 の 2 頭(0.955 / 0.996)を組み合わせると **quinella で EV = 1.16** という数値例を提示。「**賭けが specific であるほど advantage は高い**」。実績も「exotic プールのリターンが simple プールより一般に高かった」。
- **規模**: 開発サンプル約 2,000 レース、モデル整備に 5 人年 + 収益化にさらに 5 人年。5 シーズン中 4 シーズン黒字、負けシーズンは開始資本の約 20% 減。
- **収益上限(自己インパクト)**: 実現可能な最大期待利益は**レースあたり総売上の 0.25〜0.5%**、「いかなる場合も 1.5% を超えることはまずない」。プール $100,000・EV 1.20 のとき期待利益最大化ベットは **$416**。
- 後年([Bloomberg 2018](https://gamingsupport.com/blogs/posts/businessweek-the-gambler-who-cracked-the-horse-racing-code)): 因子数は 2000 年頃に 1 頭あたり 120 超。「**公開オッズを出発点に自前アルゴリズムで精緻化する方式が劇的に収益的だった。これが単一で最も重要な発明**」。模倣シンジケートの参入で香港の収益は侵食されたと明記。

### 3.2 米 CAW — 現代の天井(一次資料)

[Elite Turf Club → California Horse Racing Board 公開書簡(2024-09-05)](https://chrb.ca.gov/misc_docs/Computer_Assisted_Wagering.pdf):

- Santa Anita は CAW プレイを総売上の約 20%、かつ **win rate(払戻÷投票)が 90% を「大きく超えない」水準**に維持することを健全とみなす。直近暦年の CAW プレイはこのパラメータ内だった。
- Elite の最低投票額は年 $2,000 万、会員は常時 12〜20 名。**retail と同じ tote feed のみ**、締切後の投票・キャンセル不可。

| 要素 | 寄与 |
|---|---|
| モデル精度(vs プール平均) | 80% → **90%**(+10pt) |
| リベート | +10〜13pt |
| 合計 | 100〜103%(薄利) |

> **世界最高水準のインフラでも、パリミュチュエル単体の粗回収は約 90% = 依然として負け。**
> **黒字化はリベートによる。JRA にリベート制度は存在しない。**

### 3.3 日本市場の特性 — FL バイアスが元々弱い

- Busche & Hall(1988, J. Business 61(3))が香港 2,653 レースで **FL バイアスの非存在**を示し、Busche(1994)が香港 2,690 + **日本 1,738 レース**で追認。
- 対して米国は明確な FL バイアス: **100/1 以上 −61%、ランダム −23%、1番人気 −5.5%**([Snowberg & Wolfers 2010](https://www.nber.org/system/files/working_papers/w15923/w15923.pdf))。
- **§2.5 の我々の実測がこれを完全に再現している**(1.5〜11 倍で 0.79 平坦、崖は 21 倍以上のみ)。

> **米英豪には「市場が構造的に間違っている領域」が大きいが、日本の単勝市場には収穫すべき系統誤差が無い。**

### 3.4 パリミュチュエルでは「早く賭けて得をする」が原理的に不可能

ブックメーカー市場では複数業者のオッズ分散を使って「他より甘い価格」を取れるが、**パリミュチュエルはいつ賭けても払戻が最終オッズで決まる**。Benter が「最終オッズの正確な推定が不可欠」と書いているのは、早く賭けて得をするためではなく、**遅く賭けても最終オッズを外すと損をするから**である。

> **締切寄りの単一 q に対して測っているのは、正しい(そして唯一意味のある)ベンチマークである。**
> 「もっと早い時刻のオッズなら勝てるはず」という方向は追わない。

## 4. 測定契約の欠陥 — ROI を測り直す前に直すべきもの

codex 監査(全文: [codex-roi-investigation-lensB.md](codex-roi-investigation-lensB.md))。

### 4.1 致命

| 欠陥 | 内容 |
|---|---|
| **選定価格と精算価格の混同** | `policy-gate-eval` は `race_horses.odds`(締切寄りの単一値)で買い目を選び、**同じ値を払戻倍率として使う**(`training/src/horseracing_training/cli.py:434`)。パリミュチュエルの判断時表示オッズは約定価格ではない |
| **公式単勝払戻が保存されていない** | JRA 最終オッズは「勝馬 1 頭」前提の概算。同着・特払い・丸め・プラス 10 を再現できない。`api/src/horseracing_api/backtest.py:36` の `win_realized` は同着を検出しても凍結オッズを返す |
| **closing lookahead の符号を「楽観」と決め打ちしている** | 早期に `p×odds>1` だった勝ち馬が締切までに売れると、closing 基準では**そもそも選ばれない** = **本物のエッジを測定が消している**。これが最大の偽陰性リスク |

### 4.2 検出力(重要)

079 の実測分散(baseline 107,211 bets / candidate 106,876 / 61,745 レース / 2,004 開催日 / ΔROI −0.00536 / 95%CI [−0.01376, +0.00306])から `SE ≈ 0.00429`:

| 条件 | MDE(80% power) | +0.02 の検出力 |
|---|---|---|
| **全期間** | **0.0120** | **99.7%** |
| **直近 525–600 開催日** | **0.0220–0.0235** | **66–72%** |

- 80% power で +0.02 を検出するには約 **724 開催日 ≈ 7 年**。
- → **「全期間で 2 ポイント級の恒常改善を見逃している可能性は低い」は強い結論。**
- → **しかし「直近 regime だけのエッジ」「締切前だけ存在するエッジ」には言えない。**
- → 観測差 0.002 は MDE より小さいので、**「同値」ではなく「優越性を検出できない」**が正しい表現。

### 4.3 その他の重大な欠陥

- **cap=21 は独立確認ではない**。同じ 2008–2026 で約 10 種の lever と cap 帯を探索した後、その同じ期間で「事前登録」している。19/19 年も探索選択を補正しない。
- **expanding-window が現運用の estimand と合わない**。2008 fold は 2007 年だけで学習し、さらに最新 30% を校正用に除外。年 1 票の多数決と worst-fold ゲートは、079 実測で確認された時変(2009–2011 大幅負 / 2022–2025 全て正)を構造的に殺す。
- **有効標本数は馬でも券でもなく、レース・開催日・市場 regime**。080 の `n_min=1500 trifecta bets` は実質 300 レース程度で、数件の的中で結論が反転しうる。**leave-one-hit-out / 最大 1 的中の利益寄与率**が必須。
- **取消・結果欠損の扱いが経路間で逆**。API は結果行が無いだけで void → 分母外(上方バイアス)、policy gate は同じ馬を非勝者として損失計上(下方バイアス)。部分取込と取消の区別が必要。
- **オッズ欠損馬の確率分母**が driver と本番 `select_ev_bets` で不一致(`cli.py:461`)。
- **自己影響**: `O'_i/O_i = (1 + B/T)/(1 + b_i/W_i)`。同じ馬への投票は倍率を下げるので、`stake × odds` を払う現実装は上方バイアス。プール総額・馬別票数を保存していないため定量確認不能。

### 4.4 是正した ROI 評価契約(次に測るときの規約)

- **窓**: 2008–2026 は全て development evidence へ降格。historical primary を置くなら直近の完了年 2021–2025。confirmatory は契約 freeze 後の prospective のみ。
- **単位**: Primary = 100 円/券 flat、`Σ公式払戻 / Σat-risk stake`。返還券は stake・payout 双方から除外(attempt と void 件数は残す)。同着は馬別の公式払戻、取消は refund、DNF・失格は loss、結果取込不完全は race 全体を未精算として除外。Secondary で「1 レース 100 円を選択馬に等分」を併記。
- **CI**: 開催日を paired cluster として 20,000 bootstrap、seed 固定。各 replicate で両 arm の `Σpayout/Σstake` を再計算(bet 単位や年別 ROI 平均は禁止)。
- **判定**: 利益 = `ROI−1` の 95%CI 下限 > 0。損失低減 = candidate−current の CI 下限 > 0。「差がない」の主張は TOST。
- **常に添付**: n_bets / n_races / n_days / MDE / selection Jaccard / 上位勝ち馬への払戻集中 / official-settlement coverage。

## 5. 残っている論理的経路

### 5.1 論理的には何が開いているか

`p` が `q` に全域で負けていても、**稀な集合 S で `t/q > 1.25` を識別できれば ROI>1 は可能**。したがって「p が q に勝つこと」は必要条件ではない。ただし「q のバイアスの符号を当てる」だけでは足りず、**控除率を越える大きさ**まで必要である。

| 経路 | 必要条件 | 評価 |
|---|---|---|
| 1. 券種を変える(cross-pool / exotic) | 別プールの価格が win プールと不整合で、その差が追加控除を上回る | **文献・判例・自データが同じ場所を指す。最有望** |
| 2. 060 市場残差 + edge policy | 判断時 q に対する残差の符号・大きさを再現し、選択集合で `E[t/q]>1.25` | 予測面で具体的な正の兆候あり。ただし利益の証拠ではない |
| 3. q の系統バイアスだけを狙う | p が q より正確である必要はないが、事前定義した部分集合で +25% 以上 | 論理上可能。広い q 帯・新馬・頭数ではほぼ棄却済み |
| 4. 独占情報・手数料低下 | 公開市場にない情報、または 18% 以上のリベート | JRA 通常条件の外 |
| 5. 無リスク裁定 | 全状態を固定価格で被覆し総費用が最低払戻以下 | 変動するパリミュチュエル・空売り不能では成立しない |

### 5.2 ★1 券種を変える — モデルが市場に勝つ必要が無い唯一の路線

**根拠の三方向一致**

- **Hausch–Ziemba–Rubinstein(1981)の Dr.Z**([Management Science 27(12)](https://pubsonline.informs.org/doi/abs/10.1287/mnsc.27.12.1435)): **ファンダメンタル予測を一切使わず**、「単勝プールが示す勝率」と「複勝/show プールの投票配分」の**不整合だけ**で正の期待値。1 レースあたり候補は通常 3 つ以下。
- **Benter**: 単勝で EV 0.955 / 0.996 の**両方とも EV<1 の 2 頭**が、合成すると **quinella で EV 1.16**。実績も exotic > simple。
- **Snowberg & Wolfers(2010)**: 206,808 レース・1,485,112 スタートの exacta/quinella/trifecta 配当で、**exotic 価格が win 価格から系統的に予測可能**。
- **日本の三連単**: 実得票数データで**大穴側の過剰人気**を確認([行動経済学 vol.7](https://www.jstage.jst.go.jp/article/jbef/7/0/7_1/_article/-char/ja/))。
- **§3.5 の判例 2 件で実際に勝ったのは、まさに馬連・馬単・三連複。**

**逆風(正直に)**

| 券種 | 払戻率 | 損益分岐に必要な真値/市場比 | 現在の +2% 優位を移植した場合 |
|---|---|---|---|
| 単勝・複勝 | 0.800 | ×1.250 | 0.816 |
| 馬連・ワイド | 0.775 | ×1.290 | 0.791 |
| 馬単・三連複 | 0.750 | ×1.333 | 0.765 |
| 三連単 | 0.725 | ×1.379 | 0.740 |

**「薄いプールだから少し非効率」では全く足りない。** 加えて PL/Harville は逃げ馬の共倒れ・同脚質・ペース・位置取りといった条件付き相関を単一 utility に潰しており、**高次券種ほど誤指定が累積する**(Σ=1 が成り立つことと着順依存を正しく表すことは別問題)。券種別 joint NLL / reliability、field size 別校正、着順段階別校正が無い段階で三連単 ROI を論じるべきではない。

**→ 順序は 複勝 → ワイド/馬連 → 馬単 → 三連複、三連単は当面保留。**

**測定対象の区別(重要)**
- 実 exotic の**判断時オッズ**が無い状態で測れるのは「レース前に固定した `O_est` 政策の実払戻 ROI」。
- 測れないのは「実 exotic プールで割安な組合せを発見する政策」。後者には負け組を含む判断時の実オッズグリッドが要る。

### 5.2a 複勝 cross-pool の実測【2026-07-29 実施】

**測ったもの**: 勝ちプールの情報**だけ**で選んだ複勝政策を、**実際の複勝配当**で精算した収益。
複勝プールが勝ちプールを言い換えただけなら、**どの馬を買っても** `1 − takeout = 0.80` に着地する
(勝ちプールが 1.5〜11 倍で 0.79 に平坦なのと同じ)。**平坦でなければ cross-pool 構造がある。**

**設計上の核**: P_place の導出には Harville の stage discount λ が要り、049 で生 λ=1 の較正が悪い
(top3 ECE が win の 34 倍)と分かっている。しかし**レース内の順位は λ に対して不変**なので、
**順位ベースの政策を主読み出し**にすれば結論が我々自身の導出の較正に依存しない。
実際 λ=1 と 084 の市場 q fit(λ2=0.83036893 / λ3=0.71110581)の 2 回実行で **rank profile はバイト一致**した。

#### 結果(2,083 レース / 67 開催日 / 2025-11-23〜2026-07-26、開催日クラスタ bootstrap)

| 勝ちプール人気順 | n | 複勝的中率 | 平均 q | **複勝 ROI** | 95% CI |
|---|---|---|---|---|---|
| **1(1番人気)** | 2,083 | 66.0% | 0.3300 | **0.8551** | **[0.8289, 0.8806]** |
| **2** | 2,083 | 52.9% | 0.1953 | **0.8499** | **[0.8174, 0.8840]** |
| 3 | 2,083 | 40.5% | 0.1333 | 0.8015 | [0.7532, 0.8520] |
| 4 | 2,083 | 34.2% | 0.0954 | 0.8024 | [0.7535, 0.8505] |
| 5 | 2,083 | 25.8% | 0.0686 | 0.7553 | [0.6981, 0.8081] |
| 6 | 2,081 | 21.1% | 0.0503 | 0.7738 | [0.7065, 0.8453] |
| 全馬 無差別 | 29,435 | — | — | 0.7044 | [0.6795, 0.7304] |

**判定: 構造は実在する。しかし 1.0 には遠い。**

1. **平坦ではない。** 人気側 0.855 → 人気薄側 0.755 の傾き。**rank 1・2 の CI は 0.80 を上回る**
   (下限 0.8289 / 0.8174)ので、これは統計的に本物の構造。
2. **符号は FL バイアスと同じ。** 複勝プールでも人気馬が過小評価・人気薄が過大評価されている。
   相対では `0.855/0.80 = 1.069` = **約 +7%**。**必要なのは +25%**(§2.6)なので、**桁が 1 つ足りない**。
3. 最良の主政策(1番人気の複勝)でも **0.855** で、勝ちプールの最良帯(11–21 倍の 0.849、
   〜1.5 倍の 0.876)と**ほぼ同水準**。券種を変えても壁は動かなかった。

#### λ 依存の従属読み出し(参考・単独の証拠にしない)

| 政策 | λ=1 | λ=市場 q fit |
|---|---|---|
| P_place ≥ 0.3 | n=7,999 ROI 0.8234 | n=7,917 ROI 0.8262 |
| P_place ≥ 0.5 | n=4,049 ROI 0.8605 | n=3,321 ROI 0.8780 |
| P_place ≥ 0.7 | n=1,556 ROI 0.9095 | n=932 ROI 0.9088 |
| **P_place ≥ 0.9** | n=238 ROI 0.9576 [0.9116, 0.9973] | **n=78 ROI 0.9897 [0.9240, 1.0423]** |

最後のセルは CI が 1.0 を跨ぐが、**証拠として扱わない**: (a) n=78 / 67 開催日で検出力が無い
(b) 4 閾値 × 2 λ = 8 回の観察の**最端セル**で多重比較未補正 (c) λ 依存の従属読み出し。
これは「オッズ 1 倍台の堅い馬を複勝で買う」という既知の低ボラ戦略で、**新しい発見ではない**。

#### まだ閉じていないこと(正直に)

**これは Dr.Z の完全再現ではない。** HZR は複勝プールの**実際の投票配分**を使って「どの複勝価格が
割高か」を特定した。我々には**発走前の複勝価格**が無い(あるのは配当=着順が出た馬の払戻だけ)ので、
「勝ちプールの情報が複勝プールに平均して勝つか」までしか測れない。
配当で `EV = P_place × O_place ≥ 1` の選定をすると**結果を見て選ぶ**ことになるので、やってはいけない。

→ **発走前の複勝価格は 2026-07-29 から蓄積が始まった**(§6.1a)。67 開催日ぶん貯まる約 8 か月後に、
初めて Dr.Z 本来の形(どの複勝価格が割安かを発走前に特定する)が測れる。

### 5.2b 単勝 vs 複勝の対比較【2026-07-29 実施・事前登録済】

**多重比較の扱い(事前登録どおり)**: 6 本を補正していない。rank 2 / 3 の CI 下限は
+0.0058 / +0.0039 と**ゼロすれすれ**で、Bonferroni では残らない。**頑健なのは rank 1 だけ**。

**実用的な含意(利益ではなく損失の話)**: 1 番人気で比べると、単勝券は −23.1%、**複勝券は −14.5%**。
賭けるならという条件つきで、**同じ馬でも券種の選択が損失率を 8.6 ポイント動かす**。
どちらも 1.0 には届かない。

**なお、この対比較の実装がバグを 1 件炙り出した**: 完全に均衡した入力では bootstrap CI が幅ゼロに潰れ、
浮動小数点ノイズ(−1e-17)が方向つき判定(`win_cheaper` / `harmful`)に化けていた。
`ZERO_TOL = 1e-12` を両計器(cross_pool / delta_r2)の判定に導入して是正済み。

### 5.2c 組合せ券種のポートフォリオ backtest【2026-07-29 実施・事前登録済】

事前登録: [prereg-exotic-portfolio.md](prereg-exotic-portfolio.md)

**なぜ測ったか**: ここまで測ったのは「単勝・複勝を、1 点ずつ、均等額で」だけ。日本で唯一検証可能な

1. **判定軸が間違っていた。** λ をどう動かしても RMSE は 1% しか動かない = 候補を区別できない。
   実際に差が出るのは**帯別の平坦さ**で、そこを見ていなかった。
2. **標本が足りなかった。** 201 レースでは帯別の各セルが数百組合せしかなく、過剰適合と区別不能。

**払戻率が法定を超えるのは物理的にありえない**ので、これは確率側の誤差を実体のありそうな名前で
吸収していただけだった。当初「端数切り捨てとして解釈できる」と書いたが、その解釈は数字に否定された。

#### 残る課題

- **1000 倍超の帯は全券種で 0.70〜0.85 に沈む。** λ をこれ以上下げると人気側が逆に傾く
  (実測: λ=0.65 で馬連 0.71 → 1.11)。**単一の λ 対では両端を同時に直せない。**
- **三連複は 1.107 と約 10% 行きすぎ**(馬連・ワイドは 0.94〜0.98)。
- λ は**着順ステージごと**のパラメータで券種をまたいで共有されるため、**券種別に分けると
  エンジンの恒等式**(`ワイド{i,j} = Σ_k 三連複{i,j,k}`、`馬連 = 馬単の両順序の和`)**が壊れる**。
  券種別の補正が必要なら、確率ではなく価格側に当てる別の機構が要る。

#### 何が閉じて、何が閉じていないか

**閉じた**: 「**勝ちプールが示す確率**(または現行モデル p)で組合せを選ぶ政策は、組合せプールに勝てない」
= cross-pool 裁定の路線。

**閉じていない**: 判例との差分は**選び方**ではなかった。残る候補は
(a) 全レース網羅と資金管理(3〜6 年・我々は 67 開催日) (b) 2004–2010 当時の市場環境
(c) 発走前の実 exotic 価格(未取得)。**(c) が最も具体的**で、オッズ API `type=2..8` を叩けば取れる
(券種あたり +1 req/race)。

**実際の発走前価格に対して**「勝ちプール由来の確率が安いと言う組合せを買う」政策を測った。

事前登録: `docs/plan/prereg-exotic-real-price-edge.md`。1,001 レース。
`EV = P_market × O_real`、精算は**実配当**。券種 3 × 閾値 5 = 15 セル、Holm 補正。

| 券種 | R=1.0 | R=1.1 | R=1.2 | R=1.5 |

| 馬連 | 0.684 | 0.677 | 0.805 | 0.885 |
| ワイド | 0.557 | 0.486 | 0.483 | 0.411 |

#### 決定的な診断 — 外れているのは価格ではなく我々の確率

セルごとに**期待的中数 vs 実的中数**を出した。ここが本質:

同じ買い目について、市場の含意確率は実的中数をほぼ正確に当てている。

これは「価格が間違っている」のではなく、**我々の確率の誤差が大きい所を選び出している**という
選択効果そのものである。§2.2 の「モデルの ROI 寄与ゼロ」と同じ機構が、券種を変えても再現した。

### 5.2f exotic プールは勝ちプールが持たない情報を持つか【2026-07-30 実施】

ここまでの全測定は「**我々の導出** vs 市場」で、市場が勝ったとき 2 つの説明が絡んでいた:

1. 勝ちオッズからの PL 導出が劣化している、または
2. 組合せを買う人が、勝ちプールに入っていない情報を持っている。

**利益への道が残るのは (2) だけ。** 分離するには我々の導出を捨てればよい。
実 馬連 グリッドから直接 `x_i = Σ_{j≠i} devig(1/O_ij)` を取り、**勝者の予測子として**
勝ちプールに何か足すかを ΔR²(§5.3 の計器)で測る。`x` が較正済みの勝率であることは要求しない —
二段ブレンドが尺度を吸収するので、PL の誤指定が「exotic は無情報」に化けない。

**結果(7,847 レース / 277 開催日 / 31 ブロック prequential)**:

```
ΔR²(exotic | win) = +0.001687   95% CI [+0.000736, +0.002736]   material_positive
ブレンド重み α = 0.62-0.67 が 6 ブロック連続で安定
```

標本を増やすと点推定は動かず CI だけ縮んだ(1,001 → 3,997 → 7,847)。**このプロジェクトで
初めての、有意な正の結果である。**

退屈な説明は 2 つとも潰した:

- `corr(log x, log q) = 0.992` — x と q はほぼ同じもの。**残り 1% の食い違いにだけ意味がある。**
- 同じ「上位2着」の量を **q から自前導出**すると ΔR² = −0.000078・α = **−0.32**。
  つまり α ≈ 0.62 は「top2 vs 1着という枠組みの違い」ではなく**情報源そのもの**から来ている。

| 情報源 | ΔR² | α |
|---|---|---|
| モデル p(単勝 OOF) | −0.000016 | 0.004 |
| q から導出した top2 | −0.000078 | −0.32 |
| **実 exotic プール** | **+0.001687** | **0.62** |

**限界**: +0.0017 は Benter の基礎モデル(0.0178)の **1/10**。情報の存在と利益化は別問題である。

#### 対照が効いた — 選定は情報ではなく「人気薄」を拾っていた

平均選定オッズが順方向 88.7→130.9 倍に対し、逆方向は 14.0 倍。

これで exotic の情報を利益に変える試みは 2 つとも失敗した(§5.2e の EV ルール、本節の比の閾値)。

**閉じていない**: ΔR² が有意である以上、情報そのものは実在する。ただし
**全馬に薄く分布した情報**であり、「どの馬を買うか」という離散的な判断に変換する方法が未知。
なお +0.0017 は控除率 20% に対して 1 桁足りないので、変換法が見つかっても利益に届く見込みは薄い。

### 5.3 ★2 ΔR² — 市場に情報を足しているかの計器【2026-07-29 実装済・実測済】

winner NLL は「このモデルは正確か」に答えるが、「このモデルは ROI を動かしうるか」には答えない。
`ROI = E[c·t/q]` でモデルは**どの賭けを選ぶか**経由でしか入らないので、情報が既に `q` に入っている
モデルは市場が値付け済みのものしか選べない。Benter の計器がまさにこれを測る。

```
c_ri(α,β) ∝ p_ri^α · q_ri^β          (レース内 softmax)
R²(s) = 1 − D(s)/D₀,  D(s) = Σ_r −log s_r,winner,  D₀ = Σ_r log N_r
```

`D₀` は一様(1/N_r)null = McFadden の likelihood-ratio index(Bolton–Chapman 1986 の定義を Benter が採用)。
**`Σ log N_r` を比較対象全モデルで同一の適格レース集合について取る**こと(`log(mean N)` や
per-race R² の平均は別物)。

**2 つの増分を出す。差が本質的:**

| 指標 | 定義 | 位置づけ |
|---|---|---|
| `delta_r2_literal` | R²(c) − R²(q) | Benter の公表値と同じ量 |
| **`delta_r2_model_given_market`** | R²(c) − R²(m)、`m ∝ q^γ` | **PRIMARY** |

`m` は**市場を自分自身の最適 power で再較正**したもの。これが無いと、市場が単に γ≠1 を要求している分
(FL バイアス補正)が**モデルの手柄に計上される**。

**実装**: `eval/delta_r2.py`(pure)+ `bootstrap.race_day_cluster_ratio_bootstrap_ci_v1` +
`training delta-r2-eval` CLI。**係数は prequential**(ブロック k は厳密に過去のブロックだけで fit・
開催日粒度で切断・最初のブロックは fit 専用)。in-sample の ΔR² は reduced model が α=0 で nested
なので構造的に ≥ 0 = それ単体では何も言っていないため。

**ΔR² は比率なので、bootstrap は replicate ごとに分母も再計算する**(分母を固定すると分散を過小評価
する。頭数は resample される開催日と共変するため)。

| 一様(null, mean log N = 2.59612) | 2.59612 | 0 |

#### ゲートへの位置づけ(当初案を修正)

当初この文書は「**ΔR² が動かない特徴は LogLoss をどれだけ下げても採らない**」と書いたが、
これは製品目的に対して過剰な一般化だった。製品目的は「正直な意思決定支援」であって ROI ではなく、
ΔR² ≈ 0 の精度改善にも表示・説明・早期予測としての価値がありうる。正しい位置づけは:

| 対象 | ゲート |
|---|---|
| 一般的なモデル採用 | winner NLL + 校正 + top2/top3 + subgroup(従来どおり主ゲート) |
| **buy/EV/市場超過を目的とした変更** | **ΔR² を必須条件にしてよい** |
| 表示・説明・早期予測の改善 | ΔR² ≈ 0 だけを理由に拒否しない |

したがって実装は `can_adopt: false` の**evidence instrument**とし、δ_min=0(CI がゼロを跨がなければ
`evidence_positive`、それ以上の実用性主張は別途 δ_min の根拠が要る)。

**限界**: `q` は closing 寄りなので、これは**最も厳しいベンチマークに対する retrospective な増分**であり、
「判断時点の市場を超える能力」ではない。また 2019–2026 は既に他の分析で閲覧済みなので、
confirmatory な読みには固定した前向き holdout が要る。

## 8. やらないと決めること

| 方向 | 理由 |
|---|---|
| 単勝の LogLoss をさらに数 bp 改善し ROI 変換を期待する | 弾力性が実測で符号すら逆。必要 ΔL は 4 年間の全改善の 1.86 倍で、過去 15 世代の改善は ROI を動かしていない |
| EV 閾値の引き上げ(1.0→1.3 等) | 幾何学的に `x` 方向へ進むだけで利益領域に近づかない(実測 0.703)。tail 過信を強めるだけ |
| リベート型ビジネスの日本移植 | JRA に制度が存在しない(公式情報に記載なし) |
| 「もっと早い時刻のオッズなら勝てる」 | パリミュチュエルは払戻が最終オッズ。原理的に不可能(§3.4) |
| **WIN5 キャリーオーバー** | `EV = 0.70 + CO/S`(キャリーオーバーに再控除はかからない)。過去 10 回の的中 0 票イベントで **2018 年以降の 6 回すべて EV < 1.0**(売上増で希釈率が上昇し窓が閉じた)。加えてプール平均 EV の実現には全通り(最大 18^5 ≈ 189 万通り = 最低 1.89 億円)が必要で、最適ベットサイズを桁で超える。100 円あたり払戻上限 600 万円の天井もある |
| 「2014 年以降 13/13」を 13 件の独立証拠として数える | expanding fold は学習集合を共有し、2014 という境界を結果後に発見している |
| 少頭数・新馬など条件で市場が弱いという仮説 | 047 で棄却済み。日本には「非効率だが薄いプール」自体が存在しない(JRA は 10 場・全プールが大きい) |
| dutching / hedge / Kelly を alpha 生成器として扱う | 算術 ROI は +0。負のエッジを正にはできない。点推定 EV での full Kelly は特に危険 |
| closing オッズまたは確定配当を選定側に使う | リーク |
| `O_est` を「実 exotic 市場価格」と呼ぶ | `O_est` は単勝 q を PL へ流した**合成価格**であり、実 exotic プール固有の歪みを一切入力していない |

## 9. 正直な期待値と限界

### 9.1 期待値

- **ROI>1.0 に届く確率は低い。** 米 CAW ですら粗回収 90%、我々は 0.82。
- ただし **§3.5 の判例 2 件は exotic で 105–114% を 3〜6 年継続**しており、**単勝で無理だったことは exotic で無理だったことを意味しない**。そしてその市場を、我々はまだ一度も実データで測っていない。
- **Phase 2 が null なら、「現在の情報集合では市場超過収益は無い」と根拠を持って言い切ってよい。** その場合の合理的な製品価値は、no-bet を基準にした損失抑制、市場 q を第一表示にした正直な意思決定支援、オッズがまだ無い時点の能力予測・説明・異常検知に限定される。
- 参考: cap による損失低減は実在する(損失率 28.1% → 18.4% = **損失額 約 34.5% 削減**)。

### 9.2 分析の限界

1. **オッズは closing(確定)値。** 絶対回収率は全て楽観方向にバイアス。**ただしモデル vs 盲目の相対比較は同一オッズを共有するので無傷** — §2.2 の最重要結論はこの限界の影響を受けない。
2. **交換レートは補間方式に依存**(幾何 −0.018 vs 線形 −0.0073 で 2.5 倍差)。方式に依らない結論は「必要量が市場の LogLoss 以下」という点のみ。
3. **オラクル補間は市場直交な情報を注入する**ため現実の改善より構造的に有利。**上表は楽観的上限**。
4. 実測弾力性は 1 ペア(lgbm-042→058-acc)・8,642 レースの単発比較で CI 無し。傾向の裏取りであって精密推定ではない。
5. 市場オラクル(`q^γ`・40 分位較正)は in-sample フィット。実運用では使えない上振れ値。それでも 1.0 に届かなかったことが結論を強める方向。
6. **単勝のみ。** exotic の非効率は本分析の対象外。
7. **未検証として残ったもの**: (a) 2010 年代以前の result ページが同じ払戻 markup を返すか (b) exotic 相乗りが動かない正確な原因 (c) 生 CSV idx24/25/43/53/55 の意味 (d) 1986–2006 の ID 体系に関する README の記述との食い違い(§6.6) (e) Benter が 1988–93 当時 HKJC からリベートを受けていたか (f) 2010 年代以降の JRA で回収率>100% を達成した検証可能な事例(発見できなかった)。
8. 税: 一般には払戻金は一時所得で外れ馬券が控除できない(購入態様により雑所得と判断された事例もある)。**粗 ROI>1 でも足りない。** これは税務助言ではなくシステム要件上の盲点。

### 9.3 容量の制約(見落としやすい)

評価対象は ROI 単独ではなく

```
年間利益 = edge × 実行可能turnover − 自己price impact
```

である。Benter の自己インパクト計算ではプール $100,000・EV 1.20 でも最大ベットは $416、収益上限はレースあたり総売上の 0.25〜0.5%。JRA の 1 レース平均は全券種合計で約 9.6 億円(2024 年売得金 約 3 兆 3,134 億円 ÷ 年約 3,450 レース)なので流動性は世界屈指だが、**ROI 1.1 でも年数千円しか賭けられないなら投資システムとしての価値は小さい**。薄いプールは非効率と同時に容量が小さい。
