# 事前登録 — 単勝券 vs 複勝券の対比較

**Status**: PRE-REGISTERED(実行前に確定。以後の変更は契約変更として記録する)
**Created**: 2026-07-29
**関連**: [accuracy-roi-decoupling-investigation.md](accuracy-roi-decoupling-investigation.md) §5.2a

## なぜ事前登録するか

複勝 cross-pool の結果(§5.2a)を**既に見た後**にこの比較を思いついた。したがって、政策・母集団・判定規則を
結果を見る前に固定しないと post-hoc になる。ここに書いた内容だけを実行し、実行後に政策や閾値を足さない。

## 問い

**同一レース・同一馬について、複勝券は単勝券より割安か。**

§5.2a で分かったのは「複勝プールには構造がある(人気側 0.855 / CI が 0.80 を上回る)」ことだが、
それが**複勝プール固有**なのか、**単勝プールの FL バイアスがそのまま写っているだけ**なのかは区別できていない。
同じ馬の単勝券と対にすれば区別できる。

## 母集団

§5.2a と**同一**:
- 実 place 配当がある(= 払戻表が取り込まれている)レース
- started 全頭に有効な単勝オッズがある
- 配当行数が頭数ルール(8頭以上=3行 / 5-7頭=2行 / 4頭以下=複勝なし)を満たす
- **追加の整合性チェック**: 結果表の 1 着馬が複勝配当に現れること(現れなければ取込不整合として除外)

## 政策(固定)

§5.2a と同じ**勝ちプール人気順 rank 1..6**、および全馬無差別。各政策について:

- **単勝券**: 払戻 = `race_horses.odds`(1 着なら)/ 0
- **複勝券**: 払戻 = 実 place 配当(着内なら)/ 0
- stake は両者とも 1 単位(同一の賭け数・同一の分母)

閾値政策・λ 依存の読み出しは**この比較に含めない**(§5.2a で λ 依存は従属と位置づけたため)。

## 主判定量

各 rank について

```
ΔROI = ROI_place − ROI_win
```

分母(賭け数)が両者で完全に同一なので、これは 1 賭けあたり平均払戻の差に一致する。
CI は**開催日クラスタ bootstrap**(B=2000, seed 20260729, 両側 95%、replicate ごとに分母も再計算)。

## 判定規則

| 条件 | 判定 |
|---|---|
| CI 下限 > 0 | **複勝が割安**(place_cheaper) |
| CI 上限 < 0 | **単勝が割安**(win_cheaper) |
| それ以外 | NO_DECISION |

- δ_min は置かない(evidence-only)。
- rank 6 本の多重比較は**補正しない**が、「6 回見ている」ことを出力に明記し、
  単一 rank の有意性を単独の根拠にしない。**主張は profile の形**に対して行う。

## 事前に想定される交絡(結果を見る前に記録)

1. **単勝の払戻は `race_horses.odds`(closing 寄り)**。パリミュチュエルでは払戻が最終オッズなので、
   これは単勝の実払戻とほぼ同義。ただし**同着 1 着**では名目値と実払戻が乖離する(件数は出力する)。
2. **複勝は 1 レースで 2〜3 頭が payout する**ので、単勝より的中率が高く分散が小さい。
   ROI の差は「割安さ」の差であって、リスク調整後の優劣ではない。
3. 選定は両者とも同じ勝ちプール情報なので、**選定側の lookahead は両者で共通**=差分では相殺される。
4. 67 開催日しかない。§4.2 の外挿で **MDE はおよそ 0.066**。数ポイントの差は検出できない。

## 予測(結果を見る前に記録)

複勝プールの構造が単勝の FL バイアスの写像に過ぎないなら **ΔROI ≈ 0 が全 rank で並ぶ**。
複勝プール固有の歪みがあるなら rank 依存の非ゼロパターンが出る。どちらでも解釈できるよう、
**両方の可能性を実行前に明記しておく**。
