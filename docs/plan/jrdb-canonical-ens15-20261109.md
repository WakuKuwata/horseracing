# JRDB 正本 DB で期待回収率モデル(ens15 と同じ作り方)を学習し直す — 比較の事前登録

2026-11-09 22:00 JST・結果を見る前に固定。利用者依頼「切り替えて過去データ全取得とそれを使用したモデルを作成してほしい」。

## 作るもの
- `mev-ens15-jrdb-v1`: 正本 DB(`horseracing_jrdb`)の 2007-01-01〜2026-11-08 から `market_ev.load_rows`+`build_features` で作った行に、
  本番 `mev-ens15-v1` と同じ設定(binary・300 rounds・2007 年〜の拡張窓・年次 walk-forward・`sameday`/`weightlive` 除外・
  1 スレッド決定論・seed 1〜15 の算術平均)で学習。artifact は `artifacts/market_ev/mev-ens15-jrdb-v1/`(gitignore)。
- 基準 `cur1108`: 現行 DB から同じコード・同じ締切で作った行に同じ設定で学習(本番 ens15 は 09-22 締切なので比較には使わない)。
- 本番への結線(serving・API・ops)はしない。

## 比較 A: パイプライン同士(主)
- 母集団: 2010〜2026 の平地で、**両 DB の出走馬(馬番の集合)が一致し、勝ち馬(馬番)が一致し、単勝オッズが全馬一致**するレース。
  外れたレース数と年を報告する(出走集合の違い=中止/取消の判定差)。
- 主指標: レースごとの勝ち馬 NLL(p をレース内で正規化)。差 = jrdb − cur、開催日ブロック bootstrap(B=2000・seed 20261109)。
- 判定: 95% 区間の上限 < +0.002 なら「劣らない」、上限 < 0 なら「良い」、下限 > 0 なら「悪い」、それ以外は「決まらない」。
  年別と 2019〜2026 の値も出す(合否には使わない)。
- 副指標: 全馬 LogLoss・Brier・ECE(10 等質量 bin)・Σp の分布。
- 経済: 生の p で p×odds > 1.2 の馬に 100 円(確定オッズ・各モデルが選んだ馬)。回収率 = 総払戻/総賭金、差を同じ bootstrap で。
  確定オッズなので判断時点の回収率ではない(参考)。

## 比較 B: 本番の入力で使えるか(切替判断の材料)
- 2019〜2026 の各年 booster(jrdb 学習)に **現行 DB の行** を入れる(cat は jrdb 学習時の対応表で写像・未知値は NaN)。
  同じ行に cur1108 の booster を入れたものと、比較 A と同じ母集団・指標・判定で比べる。
- running_style・sire_line は語彙が違う(JRDB コード vs netkeiba の語)ので現行行では NaN になる。これが差の主因になりうる。

## 切替の条件(この文書では切り替えない)
比較 B が「劣らない」以上、かつ Σp・ECE が悪化しないこと。満たさなければ本番に載せる前に特徴量の語彙をそろえる必要がある。
