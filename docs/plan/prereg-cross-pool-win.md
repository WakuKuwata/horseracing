# 事前登録 — exotic プールの情報で「単勝」を買う

**Status**: PRE-REGISTERED(実行前に確定。以後の変更は契約変更として記録する)
**Created**: 2026-07-31
**関連**: [accuracy-roi-decoupling-investigation.md](accuracy-roi-decoupling-investigation.md)

## 問い

exotic プールは勝ちプールが持たない情報を持つ(ΔR² = +0.001687・CI [+0.000736, +0.002736]・
material_positive)。**その情報で単勝を買ったら利益が出るか。**

HZR は「勝ちプールが示す確率」で複勝を買った。これはその**向きを逆にしたもの**で、
情報量が有意だと確認できている側(exotic)から、控除率が最も低い側(単勝 20%)へ賭ける。

## これまでの全テストとの違い

| これまで | 今回 |
|---|---|
| **我々のモデル**が市場と食い違う馬を選ぶ | **別の市場**が食い違う馬を選ぶ |
| モデルは市場に情報を足さない(ΔR² ≈ 0)→ 食い違い = 我々の誤差 | exotic は足す(有意)→ 食い違いに実体がある |

同日の `exotic-price-edge` が全滅した原因は「我々の確率で選んだこと」だった
(選ばれた買い目の期待/実的中が 2.5〜3.7 倍過大、市場含意は実的中をほぼ正確に当てた)。
今回は**両側とも市場**なので、その交絡は構造的に存在しない。

## 母集団

- 馬連グリッドがあり、started 全頭に有効な単勝オッズがあり、単独勝者が確定しているレース
- グリッドは取消前に捕捉されうるので、started 馬だけの組合せに絞ってから devig する
- **想定 7,847 レース / 277 開催日**(実行時の実数を出力に記録)

## 政策(固定)

```
x_i = Σ_{j≠i} devig(1/O_ij)   exotic プール由来(正規化)
q_i = devig(1/単勝オッズ)      勝ちプール
選定: x_i / q_i >= R  の馬を単勝で買う
```

**R ∈ {1.05, 1.10, 1.20, 1.50}**(事前固定・実行後に足さない)。
**賭け金**: 1 点あたり等額。**精算**: 実単勝オッズ(勝てば odds 倍、外れれば 0)。

診断のため、**逆向き**(`q_i / x_i >= R` = 勝ちプールのほうが強く見ている馬)も同じ閾値で出す。
情報が exotic 側にあるなら順方向が上回るはずで、両方が同じなら「食い違いの大きい馬」という
選定自体の効果(分散が大きいだけ)を拾っている疑いが立つ。

## 主判定

セル = 方向 × 閾値。順方向 4 セルを**主ファミリ**とし、**Holm 補正**(一側 bootstrap p 値)。
逆方向 4 セルは診断で、補正せず単独の主張には使わない。

| 条件 | 判定 |
|---|---|
| `ROI` の CI 下限 > 1.0 | **profitable** |
| CI 上限 < 1.0 | unprofitable |
| それ以外 | NO_DECISION |

CI は**開催日クラスタ bootstrap**(B=2000, seed 20260731, 両側 95%、replicate ごとに分母も再計算)。

## 必須の付帯診断

`n_races` / `n_bets` / `n_hits` / `n_days` / **最大 1 的中の払戻寄与率** /
**leave-one-hit-out ROI** / 参照値 **0.80**(単勝の控除率)。

`n_hits < 20` または `最大 1 的中の寄与率 > 0.5` のセルは **NO_DECISION に降格**。

## 事前に想定される交絡

1. **両信号とも確定オッズ**。締切時点の価格で選び、同じ締切価格で精算するので、
   実運用の「判断時点で買えるか」は測れない。パリミュチュエルでは払戻が最終オッズなので
   精算側は正しいが、選定側の lookahead は残る。
2. **x は「上位2着」の量**で、単勝は「1着」。ブレンド測定では尺度が吸収されたが、
   比 `x/q` を閾値で切るここでは吸収されない。比が大きい馬は「2着に来やすいが勝ちにくい」
   タイプに偏る可能性がある。
3. 277 開催日。§4.2 の外挿で MDE はおよそ 0.04。
4. 自己影響は測れない。

## 予測(結果を見る前に記録)

- ΔR² +0.0017 は控除率 20% を埋めるには 1 桁足りないので、**0.80 前後に着地する可能性が高い**。
- 情報が実体を持つなら、**順方向が逆方向より高く**なるはず。両者が同じなら交絡 2 か、
  単に分散の大きい馬を選んでいるだけ。
- 順方向が 0.80 を明確に超えたら、初めて「使える情報」の候補になる。
