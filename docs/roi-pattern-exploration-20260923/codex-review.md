# codex レビュー(2026-09-23・design.md v1 に対して・read-only)

起動 1 回で完走。以下は要点の転記(原文は日本語・長文のため要約。採否は design.md §6)。

## 1. 設計の穴(偽の発見の経路)
- 過去研究に使った 2019–2026 を「独立した確認期」と呼べるか。結果を見たことによる設計変更があれば独立ではない。→ 使用済み期間と未使用期間を区別し、主張の範囲を限定する。
- 凍結対象がパターン一覧だけでは不足。B の探索文法、C の学習手順、D の買い目生成、精算、除外条件、最終検定、終了日まで凍結する。
- 長い過去(1986〜)の追加は「現在の期待 ROI の証拠」と同義ではない(控除率・制度・市場参加者・クラス体系が異なる母集団の混合)。年代別に別掲する。
- 同着の「0 として除外」は精算契約として曖昧(賭け金を残すか、レースごと外すかで推定対象が違う)。
- closing-line oracle は注意書きだけでは実運用への橋渡しにならない(選ばれる馬自体が変わる・不利側になる符号も保証されない)。
- 同日先行レース情報にはレース番号だけでなく公開時刻が必要。
- strictly-before と「当時利用可能だった情報」は別(現在 DB の訂正・1986 年開始による履歴の左側切断)。
- D の 2025/2026 分割は無効ではないが専用プロトコルと、2026 年の過去利用の有無の明示が必要。

## 2. 統計
- **市場 q による勝者抽選は E[ROI]≈1/Z_r<1 の世界であり、帰無 θ≤1 の代替にならない**(最重要)。市場 q シミュレーション(診断)と利益の確認検定(E[D_dj]≤0 の直接検定)を分ける。
- ROI=1 の境界帰無を「勝率=1/o」で作ることはできない(Σ1/o>1)。固定戦略ごとの利益を直接検定し、同じ日の全戦略を一緒に再標本化して相関を保存する(max-statistic / Holm)。
- 確認期で候補ごとに 95% CI を作るだけでは FWER は制御されない。確認期に入る前に最終集合を固定し Holm または同時信頼限界。
- 「確認窓まで到達する本数」は誤発見の定義として不足。到達本数・未補正通過本数・補正後の候補本数・帰無での「1 本以上宣言」率を分けて報告。
- 200 回の反復は低い誤検出率の評価には粗い(5% なら SE≈1.5pt)。
- 「全パイプラインを流す」なら結果依存の特徴と再学習も合成結果で更新する必要がある。固定した条件付き診断ならその限定を明記。
- D は勝者一頭の抽選では的中が決まらない(着順同時分布が必要)。固定戦略の実測系列の確認検定に限定する。
- 開催日 bootstrap と的中 20 回では 95% 被覆は保証されない。片側下限と両側 CI 下限の区別を明示。

## 3. アーム C(直接 ROI 回帰)
- Var(Y|X)=100²o²p(1−p) でラベル分散はオッズとともに増える。「予測純収益>0」の選抜は推定誤差の上振れを選別する。葉の支持数・正則化・オッズ帯別校正・払戻集中度を重視。
- Huber などの頑健損失は条件付き平均でなく別の量を推定する。基本モデルは平均純収益。最終評価は加工していない払戻で。
- オッズを特徴に使うこと自体はリークではないが、最終オッズを使う C は oracle 戦略の学習。
- 年次 walk-forward だけではチューニングの時間漏洩を防げない。仕様は発見期内で選び確認期前に凍結する。

## 4. アーム B(貪欲探索)
- beam 幅 20・深さ 3 は比較数 60 ではない。述語・閾値・結合制約・枝刈り・評価指標・同点処理・乱数・停止条件を固定し、生成候補数/評価候補数/最終残存数を分けて保存。
- 2,000 賭けは 2,000 の独立観測ではない。レース数・日数・年代の広がり・集中度を制約に。
- 確認期で閾値を少し動かすことも新しい探索。
- max-statistic の帰無では探索全体を各反復で再実行する。

## 5. 追加パターンの方向
- オッズ帯ごとの t/q(to>1 ⟺ t/q>Z_r)。
- 騎手・調教師の「勝率」でなく市場期待を上回る成績(勝ち数 − Σq)。
- 前走の市場評価と結果のずれ × 今回の条件変化。
- モデルと市場の不一致を校正可能な少数の層で扱う。
- 複勝・組合せの市場間価格差には購入時点の券種別価格が必要。

## 6. DSL / 語彙
- 1.1 の「pre_entry で既知」は fav_odds / fav_q / q_entropy_norm / n_fav_under_2 / field_size 等に当てはまらない(closing 由来)。各列に利用可能時刻を持たせる。
- 結果列は述語だけでなく top_k.by・軸選定・賭け金計算からも参照できる → 全参照箇所を許可リストで検査。
- edge / inverse_odds の未定義領域(負・ゼロ総和・購入単位)。
- 組合せの生成仕様(軸の位置・順序・重複・不足時)を券種別に定義。
- 複勝の的中は公式配当基準に。
- 欠損規則と isnull の整合。
- 「買わない 1.00」は賭け金 ROI ではなく資金維持の基準。
