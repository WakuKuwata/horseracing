# 期待回収率モデル(mev-ens15-v1)をさらに良くするには(2026-10-10)

問い: 「期待回収率モデル(市場連動 LightGBM・15 seed 平均・2007 年〜)をさらに良くしたい。何をすればよいか。」

方法: 読み取り専用の 4 調査(試行済みレバーの台帳/OOF 予測の誤差構造/学習レシピの監査/判断時オッズへの整合レバーの計測と spike)。リポジトリ・DB・既存の凍結結果は変更していない。再計算スクリプトと出力は `evidence/`。前提は `docs/roi-independent-eval-20261008/report.md`(Codex レビューの独立評価)。

## 0. 結論

1. **「良くする」を 3 つに分けないと答えが出ない。** (a) 確定オッズでの予測の良さ(winner NLL・ECE)、(b) 判断時オッズでの EV の正しさ(Σwon/Σp̂_J・NLL_J)、(c) 回収率。(c) は前向きでは数十年規模で判定できず(評価報告 §0)、目標指標にできない。
2. **モデルは確定オッズでは既に健全で、周辺較正の伸びしろは無い。** 全体 ECE 0.0009(市場 q 0.0017)、オッズ帯別の Σwon/Σp̄ は 0.98〜1.04、市場に対し winner NLL −0.009/レース(17 年全て)。1 次元の事後較正(isotonic・温度・帯切片)は NLL を動かさず(±0.002)、seed 平均は k=7 で飽和、rounds 増・直近窓・本番 p 追加は**悪化**。
3. **過大評価は「選ばれた馬」に集中する(勝者の呪い)。** EV 帯別 Σwon/Σp̄: 1.0–1.2 で 0.91、1.2–1.5 で 0.78、>1.5 で 0.57、>2.0 で 0.32。表示の EV(S3 平均 1.36)は約 25% 過大で、真値は 1.05〜1.11(実測 ROI 1.07 と整合)。これは p̄ だけの関数では直らず、市場 q との 2 次元混合 softmax(a·log q + b·log p̄) で S3 の Σwon/Σp_cal が 0.75→0.92 に直る(係数は年次 walk-forward で安定: a 0.37→0.28・b 0.63→0.73)。
4. **判断時(発走の中央値 6 時間前)の p̂ はさらに約 2 倍過大。** R02 の 443 レース集合で EV_J>1.0 の Σwon/Σp̂_J は 0.57 [0.35, 0.88]。同じ馬を確定時 p̂ で見ると 0.80、確定市場 q では 1.08。判断時→確定の EV 低下(log 平均 −0.315)は、オッズ側 +0.503 より p̂ 側 −0.818 が支配する(モデルの自馬オッズ弾力性 −1.1〜−1.2)。**学習は確定オッズ・適用は判断時オッズという train/serve skew が、モデル側で直せる唯一の大きな欠陥**。
5. **その skew は再学習で直せることを spike で確認した(採用判定ではない)。** 判断時相当のオッズずれを horizon 条件付きで注入して学習し直すと(V2・3 seed)、確定オッズの OOS NLL は不変のまま、判断時 NLL が −0.0023〜−0.0028、EV_J>1.0 の較正が 0.63→0.79〜0.88 に改善した。ただし選ぶ馬は現行とほぼ別物(重なり 3/143)で、**「判断時該当が締切でも残る率」という受入基準は原理的に満たせない**(締切モデルを正とみなす指標)。受入は較正と NLL に置き換える。
6. **順位**: ① 判断時 EV の較正(skew 是正の判断時専用版+暫定の縮小注記) → ② 表示 EV の市場混合較正と閾値の再設定 → ③ 早期停止+小 HPO(容量は**減らす**向き) → ④ race-softmax 目的関数 → やらない: rounds 増・直近窓・本番 p 合議・seed 増・seed 一致度の表示・1 次元 isotonic・TE・R11 再試行。**どれも回収率を上げる証拠は出せない**。回収率に直結する作業は引き続き「発走直前(T−3 分)の捕捉」で、これは利用者の決定待ち。

## 5. 今言えること・言えないこと

言えること: モデルの周辺較正・判別は市場より良く、改善余地は「選ばれた馬の EV」と「判断時の EV」にある。前者は市場との 2 次元混合で、後者は skew 是正の再学習で、それぞれ 25%→8%・2 倍→約 0.85 まで直せる見込み(後者は spike・楽観側)。容量は減らす向きが正しい。

言えないこと: どの作業も回収率を上げる証拠は出せない(前向きの判定は数十年規模)。判断時専用版の該当馬(確定で短くなる馬)の精算 ROI 0.75〜0.85 は 12〜19 勝の値。直前(T−3 分)の挙動は観測ゼロからの外挿。
