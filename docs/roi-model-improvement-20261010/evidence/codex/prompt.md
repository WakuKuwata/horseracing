# 背景(事実・再検証済み)
- 競馬(JRA)アプリ。「期待回収率モデル」= 現在の単勝オッズ+馬/騎手/調教師の過去成績 77 列(うちカテゴリ 11)を入力にした LightGBM binary(lr 0.05・leaves 63・min_data_in_leaf 1000・feature_fraction 0.8・bagging 0.8・λ2 10・300 rounds 固定・早期停止なし)、15 seed 平均、2007 年以降で年次 walk-forward(年 Y は 2007..Y−1 で学習)。出力は市場連動の勝率 p̂、期待回収率 EV = p̂ × 現在オッズ。本番の勝率モデル(市場非入力)とは別系統で、本番 p は入力に無い(足しても増分 ≈0 を実測済み)。
- 画面は EV>1.2 を強調。注目条件 S3 = EV>1.2(保存価格で 2013〜2026 通算 ROI 106.98%・事後値)、S1 = S3 ∧ 20〜40 倍 ∧ 間隔 14〜112 日(121%・事後)。前向き検証(2026-10-05〜・公式払戻精算)は append-only で記録中だが、1 点あたり払戻の SD 6〜7(100 円単位・平均オッズ 33 倍)のため ROI>100% の判定は 1〜2.8 万点=数十年規模で不可能。
- パリミュチュエルなので判断時に買っても払戻は確定オッズ。判断時(発走の中央値 6 時間前)のオッズで EV>1.2 だった馬のうち確定時にも >1.2 なのは 17〜20%。
- 2007〜2025 の判断時(購入時)オッズは復元不能。発走 10 分以内の判断時点データは事実上ゼロ(直前捕捉 T−3 分の実装は利用者の決定待ち=本レビューの対象外)。

# 私(Claude)の診断(OOF 15 seed・2013〜2026・44,791 レース・読み取り専用で実測)
1. 周辺較正は健全: ECE 0.0009(市場 q 0.0017)、オッズ帯別 Σwon/Σp̄ 0.98〜1.04。1 次元の事後較正(isotonic・温度 γ・オッズ帯ロジット切片)を walk-forward で当てても winner NLL ±0.002・EV>1.2 の過大(Σwon/Σp̄ 0.74〜0.81)は不変。
2. 判別: レース内正規化 p̄ の winner NLL は市場 q より −0.0090/レース(17 年全て負)。
3. 過大は選択条件つき(勝者の呪い): EV 帯別 Σwon/Σp̄ = <0.8 1.046 / 0.8–1.0 0.981 / 1.0–1.2 0.908 / 1.2–1.5 0.783 / >1.5 0.572 / >2.0 0.32。市場 q は同帯で 1.20〜1.27(過小)。EV>1.2 集合では真値 ≈ p̄^0.45·q^0.55。年次 walk-forward の 2 次元混合 softmax(a·log q + b·log p̄)(係数 a 0.37→0.28・b 0.63→0.73 と安定)で S3 集合の Σwon/Σp_cal 0.75→0.92、較正後の平均 EV 1.11(実測 ROI 1.07 と整合)。ただし閾値 1.2 を据え置くと較正後 EV>1.2 は 2,330 頭・Σwon/Σp 0.77 と過大が再発(極端側の再選択)。較正後 EV>1.0 は 24,737 頭・ROI 1.06・現 S3 との重なり 91%。
4. 損失源は 10〜20 倍帯(EV 1.2–1.5: Σwon/Σp̄ 0.74 [0.65,0.82]・ROI 0.94・真値の重み w_model 0.30)、利得源は 20〜40 倍(0.86 [0.73,1.00]・ROI 1.14・w 0.64・市場は 41% 過小)。
5. seed 平均は k=7 で飽和(15 seed −0.004)。seed 一致度は EV 帯内で較正を分けない(高一致=高 EV=より過大)。
6. 容量は逆向き: rounds 600 は 300 比で winner NLL +0.0056(2019〜26・SE 0.0006)/+0.0158(通算)悪化、反復曲線の最適は通算 200・直近 250〜300。直近 8 年窓 +0.0035/+0.0063 悪化、本番 p 追加 +0.0052 悪化。レース内 Σp̂ は sd 0.075(24% のレースで ≥1.05)、事後正規化は通算 −0.0029 だが 2019〜26 は +0.0042 悪化(年平均 Σ 1.01 の水準ずれ)。
7. 判断時(R02: 443 レース・5,967 頭・17 開催日・判断時/確定時の同一馬ベクトル)の較正: EV_J>1.0 の Σwon/Σp̂_J = 0.57 [Poisson 0.35,0.88](20 勝)、同じ馬の確定時 p̂ 0.80・確定市場 q 1.08。判断時→確定の log(EV_F/EV_J) 平均 −0.315 の分解はオッズ +0.503・p̂ −0.818(自馬オッズ弾力性 −1.13〜−1.23)=p̂ 側が支配。判断時オッズは確定より圧縮(確定 1〜5 倍で log(O_J/O_F) +0.08〜+0.44、100 倍超で −0.48〜−1.07)。注入生成器: u = a(h)+b(h)·log q_F+ε、a 0.34→1.03・b 0.14→0.36・残差 sd 0.24(<10 分)→0.74(>10h・出所差あり)・レース共通成分の分散比 0.16。判断時オッズで再計算される入力は 12 列(odds・q・popularity・odds_rank・q_share_of_fav・fav_q・fav_odds・second_odds・odds_gap12・q_entropy_norm・n_fav_under_2・n_odds_under_10。重要度 q 52%・odds 24%)、残り 65 列は学習と同一分布。
8. spike(採用判定ではない): 学習行を「未摂動(h=1 分)+注入行」に倍増し log(分) を特徴に加えて seed-1 系で 3 seed 再学習(1 seed 25 秒)。確定オッズの 2026 OOS NLL 0.20416→0.20406〜0.20423(不変)、判断時 443 集合の NLL_J 0.21835→0.2155〜0.2161、EV_J>1.0 の Σwon/Σp̂_J 0.63→0.79〜0.88。ただし該当馬は現行と別物(判断時 EV>1.2 の重なり 3/143・確定 EV>1.2 との重なり 1〜3%・該当馬の O_F/O_J 中央値 0.63=確定で短くなる馬)、該当は >10h 帯に 138/157 集中し <30 分では 2 頭。h=0 で使うと確定時 EV>1.2 の件数が 543→212〜233 に 6 割減る(NLL 不変)。注入 1 コピーのみ・h 特徴なし(V1)は確定 NLL +0.0026 悪化で不可。生成器パラメータは評価と同じ 17 日から推定(楽観側)。
