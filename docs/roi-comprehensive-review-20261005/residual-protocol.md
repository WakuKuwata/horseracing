# 未実行だった市場残差モデルの追加診断

2026-10-05、採点前に固定。既に2019–2026の結果は使用されているため、全て探索・診断であり独立確認や製品採用の証拠ではない。

R11（060型）は計算量を理由に未実行だった。ここでは060の全特徴・top3目的関数・校正を再現するのではなく、単勝の勝者だけをレース内softmaxで学ぶ小さい追加実験を行う。全馬確率の合計を1とし、市場qをoffsetに置く。同じ市場価格を木の入力として二重に学習する方式との差を見る。

- 入力: 9/30に2007年以降の履歴から再構築・検証した strict2007/input/rows.parquet。2007年より前を使わない。取消を含めない既存started集合、全馬オッズ完全、一意の勝者、同着なし。保存ens15予測をキーで1対1結合。
- 学習年: 2023、2024、2025、2026。それぞれ2007年〜前年末。ハイパーパラメータを成績で変えない。2026評価上限は06/26（既存の精算問題が広がる前）。2023は混合校正の初年度でもある。
- 入力列: ens15の77列から当走odds/q/popularity/rank/市場構造の12列を除外する。field_sizeは残す。前走以前のodds/qは既知履歴として残す。同日実績・当日馬体重は既存ens15と同様に除外。
- 目的関数: -log softmax(log q + residual)[winner]。LightGBM300rounds、63leaves、min_leaf1000、lr.05、feature_fraction.8、baggingなし、lambda_l2=10、seed1、deterministic、1thread。カテゴリ辞書は各学習年の過去年だけで作る。
- 保存: 年別booster・カテゴリ辞書・入力/source/runtime hash・予測・学習末日。
- 比較A: 残差モデル単体 vs 正規化ens15。同じレースの勝者NLL。
- 比較B（段0に対応する小実験）: softmax(a log q + b log p_ens + c log p_residual) vs softmax(a log q + b log p_ens)。係数は2023以降の前年までのOOFだけでfit、a,b,cは[0,5]、2024–2026に適用。両モデルのfit母集団は完全一致。追加cの性能寄与を日別paired bootstrap4000で比較。A/Bの2検定にはHolm5%。年別も全て報告し、通過モデルだけを抜き出さない。
- ROIの副診断: 単体/混合それぞれEV>1、1.2、1.4の6固定条件。全件100円。S3（ens15 EV>1.2）と同時期・同じ入力で比較。差のpaired日別bootstrap4000、ROI区間・年別・的中・購入数を保存。保存オッズ×勝者は歴史的精算近似であり実購入ROIではない。
- 価格診断: R02の判断時/確定時の同一馬ベクトルで2026boosterを再推論し、選択保持率・選択数・公式精算可能な範囲のROIを比較する。天候等は後の再構築なので、当時の本番予測そのものの再現とは呼ばない。R02と同様、同レースでは最も発走に近いsnapshotを1つだけ使用。
- 意味のある検証: ベクトル化objectiveを既存cond_logitのoffset実装と照合、数値差分gradient、レース内shift不変、sum=1、学習cutoff、カテゴリ未知値、snapshot整列を確認。終了後の再調整はしない。

独立意見: pattern_replayのレビューを受け、R11全体の検証という呼称を避け、現在市場の派生列も全除去、一意勝者と完全レースを固定した。単seedの結果は学習乱数への頑健性を主張しない。

採点前の追加レビュー: data_auditの指摘により、2023年に存在しない混合予測を2023年も購入するS3と比べるALL比較を削除。混合は2024年以降の共通期間だけで比較する。平均EVの診断列も親ens15の値と明記した。
