# R10 正規化を前年までの閾値で選ぶ追加検証

固定 `EV_norm>1.2` は保存価格上の回収率が全期間で約 112% となった。ただし **元の S3 からの改善幅の 95% 区間は全 4 条件で 0 を含む**。前年の購入比率を移す N3/N4 は 2023 年以降で S3 を約 8 ポイント下回った。R10 の年内順位方式を使わない選択は実装できたが、改善が確実とは判断できない。

本検証は 2026-10-05 に既存報告を見た後で定義した探索である。過去期間は既読で、95% 区間は多重比較・既読後の提案を調整していない。下限が 100% を超える行も「利益が検証できた」とは呼ばない。`can_adopt=false` を保持する。

## 事前に固定した条件

`EV_s=1+pred_s/100`, `p_s=EV_s/odds`, `p_bar=mean(p_s)`, `EV_norm=(p_bar/Σ_race p_bar)*odds`。S3 は全馬から `EV_ens>1.2` を選ぶ従来条件。全て該当馬を 100 円ずつ買う。

| 条件 | 買い方 |
|---|---|
| N1 | 全馬の `EV_norm>1.2` |
| N2 | `EV_ens>1` の親集合に限って `EV_norm>1.2` |
| N3 | 前年の全馬における S3 購入比率に対応する、前年 EV_norm の分位を当年の閾値とする |
| N4 | 前年の `EV_ens>1` 親集合における S3 購入比率に対応する、前年親集合の EV_norm 分位を当年の閾値とする |

N3/N4 は前年当時の OOF 保存予測を使用し、当年モデルで前年を再推論しない。分位は linear 補間。移送した閾値以上を選ぶので同値は含める。当年の件数には合わせ直さない。前年候補ゼロ／S3 ゼロなら買わないと事前定義したが、実データでは欠損閾値・同値とも 0 件だった。

母集団は 2007 年から履歴を作った `rows_2007` と 15 seed の年次保存予測。2010 年以降を読み、適用は 2013 年以降、上限は 2026-06-26（実際の最終開催日は 06-21）。正常・非同着 774,482 頭、54,753 レースを入力として、適用対象は 1,463 開催日。2010 年以降で同着 77 レース・1,077 頭を除外。正常レース以外の 14 頭はこの同着行数と重なる。

精算は `won*stored_odds*100` の近似で、長期の掲載払戻を照合した精算ではない。既知の R05 汚染期間を避けるため 06-26 で切る。「オンライン化」は当年未来の件数・分布を使わない選択方式という意味で、判断時に観測したオッズでの実運用検証ではない。
