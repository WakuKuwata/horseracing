# 保存ens15の年次較正と固定EV条件の追加診断

2026-10-05、採点前に固定。2007年以降の履歴から作られた保存ens15の2010年以降のOOFを用いる。2019〜2026年を含む履歴は既に閲覧・探索済みで、価格も保存された確定寄りの値である。本実験は探索・診断であり、独立した確認、実購入価格での利益、製品採用の根拠にはしない。

## 採点前の定義

- 入力は `artifacts/roi_strict2007_20260930/input/rows.parquet` と本番15seed再凍結に使った各年OOFの `predictions.parquet`。2010年以降、2026-06-26以下、started、平地、全馬オッズあり、一意の勝者、同着なし。各seedの全行をrace/horseキーで一対一に合わせ、保存oddsも一致確認する。
- 各年y=2013..2026の係数を、2010..y−1の同じ完全レースでfitする。2モデルは (A) softmax(a log q)、(B) softmax(a log q+b log p_ens)、係数はそれぞれ[0,5]。p_ensは15seedの算術平均。レース内定数を除くのでp_ensの正規化前後は混合に同値。目的関数は勝者NLL、stable log-sum-exp、初期値(1) / (1,0)、L-BFGS-B、maxiter1000、ftol1e−12、gtol1e−8。学習期間と適用期間を保存する。
- 買目は4政策すべて単勝・100円・厳密なEV>1.2で固定する。`calibrated_q`、`calibrated_q_ens`、`raw_S3`（p_ens×odds）、`normalized_S3`（レース内で合計1に正規化したp_ens×odds）。閾値、条件、係数範囲、選択政策の追加調整はしない。
- 評価窓はD=2013–2018、Q=2019–2022、R=2023–2026-06-26とALL。全政策で同じ利用可能レースと日付を使い、年別も全て報告する。購入数、的中、賭金、払戻、ROI、各政策の選択時EV平均を保存する。精算はwon×保存odds×100円の近似。
- CIは全利用可能開催日（購入0の日を含む）を単位とする4,000回bootstrap、seed20261005。窓内で4政策に同じ抽選を使い、ROIと6組すべてのpaired ROI差を保存する。購入0の政策はROI/CI=null、再標本の購入0は除外数を明記。CIは探索・固定モデル条件付きの記述区間で、多重探索を補正した利益確認とは呼ばない。
- 新特徴、現在DBの修復後値、当時と異なる天候・馬場、2010年以前のモデル予測は使わない。学習は係数fitだけで、新boosterは作らない。計算は1worker・BLAS等1thread。
- 入力・コード・この計画・runtimeのSHA/版を採点前にfreezeする。この本文の採点前コピーを成果物に残し、結果は実行後に別節で追記する。

## 残差小実験の数値安定性監査（固定済みの別確認）

`residual_spike/predictions.parquet` と `results.json` の保存係数を入力に、2024/25/26のbase/extendedをすべて確認する。固定係数でclip lossとstable lossの差、最低勝者確率とclip対象件数を計算する。さらにstable lossで同じ初期値から再fitし、係数、訓練NLL、適用年確率、適用年勝者NLLを比較する。差があってもその結果で採用係数を選ばず、元実験を書き換えない。入力/sourceのSHAを保存する。

実装前レビューは親担当に加えmethod_reviewへ依頼した。小検査ではstable objectiveの数値勾配、レース内shift不変、正規化前後のlog p同値、未知カテゴリに依存しない純係数fit、期間切分け、ゼロ購入とpaired集計を確認する。


## 2026-10-05 実行結果

採点前計画と入力・実装をSHAで凍結し、method_reviewの独立レビュー後に4政策を実行した。14年分の較正はすべて前年末までの2010年以降OOFを使用した。凍結23ファイルの不変、16政策×窓の購入数/ROIの独立算術、14レシピの時間順、確率和を確認した。`protocol_frozen.md`はこの結果節を加える前の本文をそのまま保存している。結果追記は凍結実装・入力・元集計を変更しない。

### 取消と価格ベクトルの構造QA

qのみ較正の88購入すべてが、出走馬の逆数オッズ和が1未満になる8レースに集中したため、固定条件 `sum(1 / stored_odds) >= 1` を全政策へ同一適用する感度確認を追加した。閾値は控除市場の整合性に基づき1で固定し、結果による調整は行わない。係数・予測・N3/N4の前年閾値・買条件は保存値のまま維持した。

全評価母集団には同条件違反が40レースある。read-only DB照合で40全件について、保存された出走馬集合と現在DBのstarted集合が一致し、全出走馬の保存oddsも一致した。40全件に取消馬が存在し、その価格を含めると逆数和は1以上に戻る。qのみ対象の8件は取消馬1頭が1.4〜2.3倍、取消馬を含む逆数和1.20〜1.29。元exportとstrict再構築でもoddsは一致しており、手動補正やstarted行欠落は検出しなかった。抽出SQLは`entry_status=started`であり、最終出走集合と取消前の価格が混在した疑いが強い。ただし過去の価格固有時刻や公式払戻はこの照合だけでは確定しない。

### R11のclip損失とstable損失

保存された2024/25/26のbase/extended、計6fitすべてでclip対象勝者は0件。最低訓練勝者確率は0.00094635で、clip閾値1e−15より十分大きい。固定係数のNLL差は0、同じ初期値からstable損失で再fitした係数の最大差は2.45e−15、適用年確率の最大差は3.89e−16。今回のR11数値にclipの実害は検出されなかった。元結果や採用係数は変更していない。
