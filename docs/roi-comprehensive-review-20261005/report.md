## 3. 較正・市場残差モデル

年次較正は2010年以降の前年までのOOFで `softmax(a log q + b log p_ens)` をfitし、EV>1.2を買った。モデルのみの正規化とは違い、市場との縮小係数も過去から決める。

| 年次較正条件 | 全期間ROI | 2013–2018 | 2019–2022 | 2023年以降 |
|---|---:|---:|---:|---:|
| 市場qのみ | 77.95% | 54.57% | 126.77% | 46.36% |
| 市場q＋ens15 | 93.97% | 96.84% | 90.54% | 64.83% |

市場qのみの購入88点は8レースに集中しており、全レースの逆オッズ和が1未満という価格異常を拾っていた。全8レースに取消馬があり、その馬の取消前らしいオッズを戻すと逆数和が約1.20〜1.29となる。取消を除いた出走集合と保存価格の時点がずれた可能性が高い。逆数和が1未満の全40レースを全条件で共通除外する追加QAを別出力で保存した。全40でstarted集合・保存オッズは現在DBと一致し、取消馬を戻すと逆数和は1以上。逆数和が1未満なら逆オッズに比例した資金配分では理論上の裁定になるが、均等100円購入が必ず利益になるという意味ではない。

共通QA後の全期間ROIは、S3=107.25%、N1=113.36%、N2=113.53%、N3=110.52%、N4=111.25%、較正q+ens=96.65%。qのみは88点全て除外され、購入0・ROI=nullとなった。成功しそうな方式だけに適用した除外ではない。予測・係数・前年閾値は固定しており、元学習への混入は未修復。これは結果を見た後の品質感度で、利益を上げる新ルールとして採用しない。[全方式・全窓・除外内訳](</Users/kuwatawaku/workspace/horseracing/artifacts/roi_comprehensive_20261005/calibration_roi/underround_sensitivity.json>)を保存した。新混合のEV>1.4はこのQA後300%になるが、12点3的中しかなく利益の裏付けではない。

R11は、当走の市場価格・人気等12列を木の入力から除き、65列の履歴・条件で `softmax(log q + residual)` の勝者NLLを学ぶ小実験を実施した。2007年〜前年末で2023/24/25/26の4boosterを学習し、同じ年度のens15と比較。これは060の全特徴・top3・校正・採用ゲートを再現したものではない。

- 単体はens15よりNLLが悪化（NLL改善量＝NLL_ens−NLL_residualが全4年で負、改善量−0.00445 nats/レース、95%区間−0.00671〜−0.00228）。
- 市場＋ens15へ加えた増分は+0.000157、区間−0.000578〜+0.000884、Holm後p=0.651。増分を確認できない。
- 単体のEV>1.2は2023年以降3,136点132的中、ROI100.42%［77.39,127.35］。EV>1.4は166.54%だが557点24的中で区間83.69–266.57%。高い点推定だけで選ばない。
- 混合のEV>1.2は、予測が揃う2024年以降274点19的中、ROI124.38%［61.04,203.42］。同期間S3は126.43%。EV>1.4は26点3的中で177.69%、区間0–680.91%。

単体/混合×3閾値の6条件を全て保存した。混合の2023年予測は存在しないので、S3側だけ2023年を含む比較は削除した。勾配の数値差分、既存objectiveとの一致、合計1、過去カテゴリ・未知値、混合係数の別実装照合を実施。clipとstable lossの差は実データで0、適用確率の差は3.89e−16以下。学習seed1本なので学習乱数への頑健性は未検証。

## 4. 購入時価格で成立するか

R02からレースごとに発走へ最も近いsnapshotを1つだけ選び、非同着443レース・17日・5,967頭で診断した。自馬価格を変更した際はq・全馬の順位・上位価格等を再構成して15モデルを再推論する。元の判断時予測の再現差は0。ただし天候等の非価格特徴は後の再構築なので、当時の本番計算を全て再現したという意味ではない。

公式払戻の確認済み389レース・15日も共通集合で別集計した。元R02で公式列があった232レースは古いオッズが残ったaffectedレースだけだったため、追加157レースの公式値を照合した補助集計が正しいcoverageである。全体の精算額変更は0。残る54レースは保存確定価格近似を使うので、443集合は全件公式精算ではない。

| 条件 | 443レース集合：点数 / 的中 / ROI | 公式389レース集合：点数 / 的中 / ROI |
|---|---:|---:|
| S1 | 39 / 2 / 156.67% | 34 / 1 / 61.18% |
| S3 | 82 / 2 / 74.51% | 75 / 1 / 27.73% |
| N1正規化 | 88 / 2 / 69.43% | 79 / 1 / 26.33% |
| 新残差EV>1.2 | 76 / 2 / 14.74% | 68 / 2 / 16.47% |
| 新混合EV>1.2 | 14 / 1 / 148.57% | 13 / 1 / 160.00% |
| S1 ±10%価格gate | 23 / 1 / 90.43% | 19 / 1 / 109.47% |
| S3 ±10%価格gate | 39 / 1 / 53.33% | 34 / 1 / 61.18% |

全政策の95%区間下限は0。S1の156.7%や混合の160%も1〜2的中で振れる値で、利益確認ではない。443レース集合の親内で価格帯・出所・時刻ごとに同件数を無作為に残した対照に対して、価格gateが良いという証拠はない（親内null pはS1=.933、S3=.927）。

N1の締切価格への選択保持率は17.0%、S3は17.1%。残差モデルは81.6%と高いが回収率は低く、価格に安定することだけでは利益にならない。新混合は7.1%。元のR02の11%/20%とはsnapshotの採用方法が異なるので同じ値になるとは期待しない。

価格gateで使う仮想人気順位はodds.rank(min)でもある。ゼロ価格変更の対照を追加すると、元S3の82点と選択集合は一致し、gate39点も全て残った。EV自体には小差があり、価格と順位の再構築を含む診断と説明する。

## 5. 誤実装と精算の盲点

初ダート血統セルR09-X09では、馬順に作った芝ダ配列を元の行順へ戻さず使っており、931,017行中463,686行（49.80%）が不一致。旧セルは後期17,914頭中15,075頭が芝だった。修正すると後期は4,469頭で全てダート、ROI79.45%。発見104.59%・資格67.47%、元の13セル検定でも通過0。旧の値を正しい初ダート検証と読むことはできない。別の日別累積実装・同日除外・未来ラベル改変でも修正後特徴を照合した。

アプリの会計と時点記録には次の確定問題が残る。

1. **実購入の単勝が公式払戻表に接続されていない。** 注目条件は139で公式へ移ったが、購入記録の関数は保存オッズ×購入額を実払戻扱いする。2026-08-16の同着例で、100円の公式1,340円に対して関数は2,650円を返した。これは関数の再現例で、その馬券を利用者が購入したという主張ではない。同着時に最終オッズと実払戻が異なることは[JRA公式FAQ](https://jra.jp/faq/pop03/1_20.html)にも明記される。
2. **ワイドの3着同着ペアを的中扱いする。** 2026-10-04の実レースで公式に無い組合せに推定払戻5,824.55円を出した。[JRAの的中条件](https://www.jra.go.jp/kouza/beginner/baken/)ではこの組合せは不的中。研究側の別精算器はさらに5〜7頭で3着を除外する不一致があり、元の関数本体を抽出した固定例でも再現した。
3. **価格取得時刻が出走馬行の更新時刻。** オッズを取らず出走表だけ更新しても時刻が進むトリガを実DBで確認。古い価格を新鮮と扱い得る。
4. **初回の全馬snapshot不足。** 結果前18レースの初回run_idは全18でlatest予測から消えていた。選択外馬の初回価格・予測・特徴を保存pickだけから再計算できず、新旧選択ルールの前向き比較を制限する。

実DB・コード位置・再現・修正項目は[精算・データ監査](data-audit.md)。今回、これらの本番コードやDBは変更していない。

## 6. 使えるものの判断と残る検証

**次の優先候補はN1/N2の固定正規化条件。** 2007年以降の履歴・前年までの学習を守り、年内の未来分布を使わず実装できる。過去ROIの参考値は有望だが、購入価格での改善が未確認なので買い推奨へ昇格しない。

上乗せ日は契約上の控除を減らし、相手全頭への展開を避けることは過去の損失低減に根拠がある。これらも絶対ROI100%超の証明とは別。全seed拒否も締切価格では損失低減が見えたが、判断時価格での再現は未確立。資金配分は重みによってROIやリスクを変え得るが、未知の優位を作れるという意味ではなく、過去の良い結果へ資金を寄せて採用しない。

較正、R11小実験、価格gateは今回固定した定義のままでは積極的な採用を支持しない。特に「非有意なので全て効果ゼロ」「ΔR²が小さいので利益パターンは存在しない」「17日から換算した85〜90%が確定した将来期待値」は言い過ぎる。確認できたことと未検出を分ける。R02の換算は歴史ROIと価格差の移送シナリオで、元ROIの不確実性・出所偏りも残る。

次に必要な具体材料は、公式精算の統一、quote固有の価格取得時刻、同時刻の全馬予測・全馬オッズ・入力/モデルhashの保存。そこでS3、N1/N2、全seed拒否、同じ期間の本命・複勝等を先に固定して比較する。未取得の時点情報を後日の最新DBで埋めて成功条件を作らない。馬体重・取消・馬場の更新、直前価格、券種間価格の同時刻比較もこの記録に依存する。
