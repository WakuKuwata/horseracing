# 148正規化の2026年差と次案に関する独立意見

2026-10-25。担当 `norm148_next_review`。148の結果・保存予測・保存購入・レース集計と、143〜147、過去のR10・較正・資金配分検証を閲覧した。新モデル学習、新しい購入方策の回収率採点、既存凍結ファイルの変更は行っていない。

## 2026年の減益の読み方

③の2026年（1,591レース）の保存済みレース集計を独立に読むと、rawは投資172,300円・払戻347,230円・利益174,930円、正規化後は投資166,700円・払戻295,830円・利益129,130円。投資が5,600円減った一方、払戻が51,400円減ったため、利益差は−45,800円となる。

そのうち、202608030111の1レースはrawで1,000円購入・払戻105,700円・利益104,700円、正規化後は購入0円・利益0円で、差は−104,700円。したがって、その他の2026年レースの利益差は **＋58,900円**。既知レースの除外は感度診断であり、購入ルールへ取り込む条件ではない。

同レースのraw③確率合計は `S=1.0504068704519292`。全馬に同じ `1/S` を掛けるため、当該勝馬だけを低く評価する変更ではない。rawで閾値付近だった105.7倍の勝馬が選択から外れ、従来1頭に1,000円配る方式により、1回の選択変更が約10万円の利益差となった。

これをもって「正規化が2026年のレース構造に合わない」「2026年だけrawへ戻す」とは判断できない。2026年は52開催日の部分年で、集計差は1的中の影響で符号が変わる。逆に、そのレースを除いたプラスだけで正規化の安定性を証明することもできない。2024年にも減益しており、2026年だけを救済する条件には根拠がない。

正規化は同一レースの順位を変えず、全頭のEVを一律に変える。合計が1超なら選択が減り、1未満なら増える。候補数が変わると、共通して残った馬の賭金も `100 × floor(10 / 候補数)` に従い変わる。購入の追加・除外と、残存馬への金額変更を別に確認するのが適切である。勝馬NLLは従来からレース内正規化して測定しているため、今回の前後で数学的に不変。減益を学習精度の悪化へ直結させない。

### 主担当の群別分解を受けた追加レビュー

主担当の `attribution.json` と `allocation_detail.json`、両生成スクリプトを閲覧した。保存148の同一全頭キーへ購入額を戻し、`(正規化後賭金−raw賭金) × (的中×オッズ−1)` を加算する説明用分解で、新しい方策の採点は含まれない。

③の2026年の差は、新規購入40頭＋55,200円、取りやめ53頭−78,400円、共通購入の金額変更10頭−22,600円、同額の共通購入136頭0円で、合計−45,800円。取りやめ群から既知105.7倍レースの−104,700円を外すと＋26,300円になり、取りやめ全般が悪かったとする説明も適切ではない。全期間では新規購入＋171,640円、取りやめによる差＋101,330円、共通金額変更＋29,490円であり、正規化の増益を「買う数を減らしただけ」と説明するのも不十分である。

3月15日の202609010807では、51.7倍の勝馬のEVが1.2401→1.3441へ上がったにもかかわらず、賭金は1,000円→500円へ下がった。別の馬が追加され、1レース予算を分けたためである。勝馬への金額変更は−25,350円、追加した不的中馬は−500円、レース合計−25,850円。**EVが上がった馬の賭金が下がる**という現行配賦の機械的な経路が、金額切り離し診断を行う具体的な理由になる。ただし共通金額変更は全期間ではプラスであり、その配賦を廃止すれば全体が良くなるとは予測できない。

一方、3月1日の202610011209は、rawでは選ばなかった58.6倍の勝馬を正規化で追加し、＋57,600円を生んだ。部分補正は3月15日の追加を抑えて勝馬への配賦低下を避ける可能性がある反面、3月1日のような有益な追加も抑え得る。正規化が追加する馬全体を悪いとみなす根拠はない。この対称的な失敗経路を記録したうえで、以下の①固定部分補正、②同一買い目100円の優先順位は維持してよい。**①は利益改善を試す限定1条件、②は原因を切り離す診断としての位置づけ**であり、どちらも改善幅は未採点である。

## 次案の優先順位

### 1. 補正を半分にする固定1条件

親の15seed raw確率平均を `p_i`、全出走馬の合計を `S` とし、購入判断用スコアを `p_i / sqrt(S)` とする。元の `p_i` と完全補正 `p_i/S` の対数尺度での中間に当たる。EV閾値は1.2、1レース上限予算1,000円、最大10頭、配賦方式は148と同じに固定し、指数0.5だけを追加する。0.25、0.75等の指数や閾値を探索しない。

これは正しい勝率分布を新たに作る方法ではなく、購入用EV補正の強さを弱める仮説である。合計は一般に1にならないため、UIの「勝率」として扱わない。根拠は、完全補正が利益を改善する年と取りこぼす年の両方を生み、閾値付近の一括出入りが大きいこと。どの程度が最適かを過去結果で選ぶ根拠はないため、固定0.5の1条件に限定する。

105.7倍の既知勝馬を残せると説明してはいけない。その馬のraw EVは1.2をわずかに超えただけであり、合計Sの補正を弱めても引き続き1.2未満になり得る。この案は既知的中の救済ではない。

比較はmatched77と③の両親に同じ式を適用し、rawと完全正規化を必ず残す。回収率だけでなく利益、共通全レース予算あたり利益差、年別・同暦期間、最大DD、上位払戻への感度、開催日単位の補正区間を報告する。既読期間での追加探索であり、改善しても本番採用へ直結させない。新boosterは0本。

失敗条件は、完全正規化より不要な購入を戻して利益・回収率を下げる、改善が既知の少数高配当だけに集中する、年別の悪化を別年の一発で埋める、最大DDが大幅に悪化すること。未参照期間での有効性を保証する案ではない。

### 2. 同じ買い目を各100円にして配賦の影響を切り離す

rawと完全正規化で決まった148の買い目をそれぞれ保持し、各馬100円、最大10頭、未使用分は現金にする。閾値・モデル・選択順位は変更しない。候補が1頭になっただけでその馬へ1,000円が集中する現行配賦を外し、選択の改善と金額配分の影響を分ける。

先に診断として実施する価値が高い。各100円は新しい予測情報を加えず、利益額が下がる可能性も高いので、回収率が上がったことだけで採用しない。共通1,000円予算に対し余った現金を明記し、利益とDDも同時比較する。後から年間投資額をそろえる倍率を掛けて「利益が増えた」とは言わない。

従来のN1/N2は保存現行ens15に各100円を適用済みであり、各100円自体を新発見とはしない。今回未確認の対象は、③およびmatched77の同じ24,855レースで、148の1,000円均等配賦と100円固定を直接切り分ける部分である。Kellyや逆オッズ比例は広く既検証であり、ここで追加しない。新boosterは0本。

失敗条件は、損益の変動額が小さくなるだけでROI・予算あたり利益が改善しない、または選択差自体の利益が悪く、配賦を変えても取りこぼしを改善しないこと。賭金を一律に減らすだけでは期待優位は新たに生まれない。

## 今回は優先しない案

- 合計S・seed分散・合意率・他馬不一致から買い目の質を学ぶ案は、R10のメタ補正族と重なる。R10の当年top-Nや当年分位を使わない過去OOF版は修正版として定義できるが、新しい仮説族として試行回数をリセットしない。③の過去OOFを増やすほど外側前半の学習可能期間も短くなるため、今回の低コスト比較より優先する根拠は弱い。
- 市場qとモデル確率の年次softmax較正は、前年OOFのみの固定EV購入まで実施済み。過去ens15で積極的な利益改善を支持していない。親モデルを③へ変えただけで新情報とはしない。
- seed一致・分散、追加特徴、直近学習窓、直接収益回帰、Kelly、価格±10%の見送り、閾値やオッズ上限の細分化は既検証との重複が強い。
- 2026年だけraw、Sが既知レースの値付近ならraw、高配当的中を残せるところまで指数や閾値を調整する案は、結果を知った救済になるため提案しない。
