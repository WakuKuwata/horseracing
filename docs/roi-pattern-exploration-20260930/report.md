# 2007 年以降のモデルの上に回収率 100% 超の買い方はあるか — 結果(2026-09-30)

**結論: 無い(確認できなかった)。** 事前に凍結した 150 本の買い方(閾値×上限×賭け方 36 / 区分条件 85 / レース内選択 5 / モデル変種 16 / 選択後の再校正 4 / 本番モデルとの合議 4)を、発見期 2010–2015 → 資格期 2016–2018 → 確認窓 2019–2026 の順で一度だけ流した。発見・資格の両方で回収率 ≥ 1.00 を保ったのは 25 本、確認窓で **Holm(片側 FWER 2.5%)を通ったものは 0 本、未補正の 95% 区間下限が 1 を超えたものも 0 本**。最小の片側 p は 0.021(馬場「重」・726 賭け・回収 1.449 だが区間 [0.92, 2.05])で、Holm の要求 0.001 には遠い。しかもこの 1 本は学習 seed を変えると 0.96 / 0.90 に落ちる(seed の偶然)。

いちばん筋のよい候補は **3 seed 平均モデルの EV>1.2**(確認窓 1.079・区間 [0.91, 1.25]・p=0.16・8 年中 6 年で ≥1)だが「利益がある」とは言えない水準で、前向き検証の候補として記録するに留める。**人気 2〜3 番手の EV>1.2**(1.183・p=0.03)は rounds 600 の seed 2/3 で 0.995 / 0.976 に落ち、seed の偶然と判明した(§2.4)。

設計は `design.md`(事前登録)・codex レビューは `codex-review.md`・機械化は `scripts/roi_explore/patterns_2007.py`・出力は `artifacts/roi_explore/results/patterns_2007/`。

## 1. 何を測ったか

- 土台: 137 の製品モデル `mev-binary-v2`(2007 年〜のみで学習・現在オッズ+馬履歴 77 入力・二値)の年次 walk-forward 予測(2010–2026・786,049 行)。期待回収率 EV = p̂ × 単勝オッズ。
- 候補 150 本を**結果を見る前に**コードに凍結(`patterns.json`)。窓と生存規則(点推定 ≥1.00・的中 ≥20・開催日 ≥100・最大 1 的中の払戻寄与 ≤50%)も事前固定。
- 確認窓の判定 = ROI=1 に帰無中心化した開催日クラスタ bootstrap(10,000 反復)の片側 p に、確認窓へ到達した 25 本で Holm。非生存 125 本の確認窓の値は別ファイルに出し判定に使っていない。
- codex レビュー(1 回・取得成功)で追加した診断: 確認窓の年ブロック別 ROI(2019–20/21–22/23–24/25–26)・leave-one-year-out・モデル変種の seed 安定性。採否は design.md §6。

### 2.4 上位 2 本の seed 安定性(事後・診断)

同じ買い方を、学習 seed だけ変えたモデル(seed 2・seed 3・3 seed 平均・rounds 600)の予測で確認窓に当てた。

| 買い方 | 基準 seed 1 | seed 2 | seed 3 | 3 seed 平均 | rounds 600 |
|---|---|---|---|---|---|
| 馬場=重 & EV>1.2 | 1.449 (n=726) | 0.960 (698) | 0.901 (687) | 1.229 (511) | 1.126 (1,480) |
| 人気 2–3 & EV>1.2 | 1.183 (n=500) | 1.044 (489) | 1.175 (506) | 1.117 (329) | 1.174 (1,235) |

馬場=重は seed で消える(seed 1 の偶然)。人気 2–3 は基準モデルの seed 1/2/3 では 1.04〜1.18 に留まり、rounds 600(seed 1)では n=1,235 で 1.174・区間 [1.04, 1.32]・p=0.004 に見えた。**そこで rounds 600 も seed 2・3 で再学習して同じ区分を当てた(codex 指摘 3 の seed 安定性検査)**:

| rounds 600 の seed | EV>1.2 発見 / 資格 / 確認 | 人気 2–3 & EV>1.2 発見 / 資格 / 確認 |
|---|---|---|
| seed 1 | 1.011 / 1.019 / 1.008 (n=15,437) | 0.917 / 1.012 / **1.174** (n=1,235, p=0.004) |
| seed 2 | 1.010 / 0.953 / 0.981 (15,724) | 0.950 / 1.069 / **0.995** (1,197, p=0.52) |
| seed 3 | 1.003 / 0.951 / 1.026 (15,381) | 0.914 / 0.913 / **0.976** (1,217, p=0.67) |
| 3 seed 平均 | 1.030 / 0.946 / 1.073 (12,284, p=0.12) | 0.933 / 1.059 / 1.050 (868, p=0.25) |

**人気 2–3 の 1.174 も seed 1 の偶然だった**(seed 2/3 で 0.995 / 0.976、しかも rounds 600 では発見期 0.91〜0.95 で最初から落ちている)。rounds 600 の EV>1.2 は seed によらず 0.98〜1.03 で、3 seed 平均でも 1.073(p=0.12)。事後の再計算であり確認ではないが、方向は一貫して「1.0 前後に収束」。

### 2.6 帰無診断(多重比較制御の実効確認)

予測を固定し、各レースの勝者を市場 q から抽選した合成結果で同じ手順を 50 回流した: 発見期通過は平均 2.3 本(最大 12)・資格期到達は平均 0.06 本(最大 1)・Holm 棄却 0・弱い候補 0(全馬回収率の平均 0.795)。実データの 91 → 25 → 0 と比べると、発見→資格の段は q 世界では通らない=モデルの EV>1.2 選択は市場 q に対して実在の情報を持つ(全馬 0.72 に対し ≈1.0)。ただしこの帰無は E[ROI]≈0.80 の甘い世界であり利益の検定ではない(設計 §4)。

### 2.7 検出力(何が言えないかの規模)

確認窓の bootstrap 標準偏差から、片側 2.5%・検出力 80% の最小検出可能な回収率の上乗せ(≈2.8×sd):

| 集合 | 賭け数 | sd | 検出できる上乗せ |
|---|---|---|---|
| EV>1.2(基準) | 7,682 | 0.068 | **+19%** |
| EV>1.1 | 16,517 | 0.046 | +13% |
| EV>1.0 | 35,245 | 0.029 | +8% |
| 区分 1 本(例: 人気 2–3・500 賭け) | 500 | 0.116 | +32% |

**+5〜10% 程度の優位は、この 8 年の確認窓では原理的に検出できない**。本探索が言えるのは「+19%(基準集合)/+8%(広い集合)を超える優位は無い」まで。

### 2.8 事後診断: 失格組の確認窓(判定には使っていない)

150 本全体で確認窓 ≥1.10 かつ 500 賭け以上は 13 本。上位は 馬齢=4(1.384・発見/資格で失格)・競馬場=10 小倉(1.303・失格)・重賞(1.264・249 賭け・失格)など、**発見・資格で落ちた区分が確認窓だけで高い**=ノイズが窓ごとに別の区分に出る形そのもの。ここから「後で」拾えば必ず何か見つかるが、それは今回の設計が禁じた操作。

## 3. 言えること・言えないこと

**言えること**
- 2007 年以降のデータだけで学習した市場連動モデルの上では、閾値・オッズ上限・賭け方・20 軸 85 区分・レース内選択・seed/容量/目的関数/学習窓/本番 p 追加のモデル変種・選択後の再校正・本番モデルとの合議のどれを試しても、確認窓で「回収率 >1」を統計的に主張できる買い方は無かった(Holm 0/25・未補正 CI 下限 >1 も 0/25)。
- 発見・資格で目立った細い区分は確認窓で戻る。確認窓で 1 を超えるのは広い集合の 1.00〜1.08 だけで、再学習ノイズ(±0.05)と同じ大きさ。
- 帰無世界では発見→資格を通らないので、手順が「何でも通す」わけではない。

**言えないこと**
- +8〜19% 未満の優位の不存在(検出力の床)。
- 実運用の回収率(確定オッズで選定した closing-line oracle。実際に買える時点のオッズは違い、自分の投票も価格を動かす)。
- 2019–2026 は 137 の評価で基準 3 閾値だけ既視で、F5(再校正)の発想は pooled の較正診断を見た後のもの(codex 指摘)。真に独立な確認は前向きにしか無い。
- モデル変種は各 1 seed(3 seed 平均を除く)。Holm は凍結リスト内の偶然しか抑えず、候補族を作るまでの試行錯誤・137 の評価・F4 の潜在的な空間は補正外。
- 複勝・組合せ(実配当 2025–26 のみ)・2006 年以前の学習(憲法 I)は対象外。

## 4. 137 の表示への含意

出走表の「期待回収率」列と 120% 超の目印は現状の注記(通算 100.8%・2019 年以降 99.5%・前向き未検証)のままでよい。本探索は「それより良い出し方」を見つけられなかったので、表示ルールを変える根拠は無い。3 seed 平均への切替(確認窓 1.079)は seed ノイズの範囲内であり、表示を変える理由にならない(変えるなら前向きで測ってから)。

## 5. 次にやるべきこと

1. **前向き検証を始める**(唯一の独立な確認): 発走前オッズで EV を計算して選定し、確定配当で精算する。065(shadow log)と 106(実購入記録)の器はある。記録すべき事前登録候補は 3 つ: (a) 基準 EV>1.2 (b) 3 seed 平均 EV>1.2 (c) 人気 2–3 & EV>1.2。判定基準は「賭け数 N に達した時点で片側 p」を先に決める。
2. (実施済み)rounds 600 変種の seed 2/3 の安定性 → §2.4。人気 2–3 の上振れは seed で消えたので、前向き候補 (c) は優先度を下げる(記録は残す)。
3. 2025–26 のオッズ混在(発走前スナップショット)を、084/086 の凍結スナップショットで切り分ける(オッズの時点別に回収率がどう違うか)。
4. この土台での過去データ探索はこれで閉じる(再開条件: 新情報源・控除率の変更・前向き検証で (a)〜(c) のどれかが p<0.05)。
