# 2007 年以降のみで学習した市場連動モデルの上に、回収率 100% を超える買い方はあるか — 設計(2026-09-30・事前登録)

**状態: 実施済み(2026-09-30)。結果は `report.md`。生存 25/150・Holm 棄却 0・弱い候補 0。**

**問い**: 137 で製品化した市場連動モデル `mev-binary-v2`(2007 年以降のデータのみで学習・二値・77 入力・当日馬体重と同日先行レース不使用)は、期待回収率 120% 超の単勝を買うと通算 100.8%(95% 区間 94〜108%)・2019 年以降 99.5% で、利益は消えた。**この土台の上で、それより高い回収率が確認できる買い方(選び方・賭け方・モデルの作り方の変種)が存在するか**を、事前に列挙した候補集合に対して発見→資格→確認の 3 段で 1 回だけ測る。

**位置づけ**: 2026-09-23 の広域探索(`docs/roi-pattern-exploration-20260923/`)はルール型 2,356 本+貪欲探索+組合せで生存 0、市場連動モデルだけが 1986 年〜学習で 1.03〜1.09 だった。137 で 2007 年〜に制限するとその優位は消えた。本探索は**憲法 I(2006 年以前のデータ禁止)の中で**、まだ試していない自由度(区分条件・賭け方・レース内選択・モデル変種・選択後の再校正・本番モデルとの合議)を一度に凍結して測る。探索的であり、勝者の呪いは時間分割と Holm で制御する。**null(生存 0)も成功**。

## 1. データと予測

- 行: `artifacts/market_ev/rows_2007.parquet`(931,017 行・65,673 レース・2007〜2026-09-29・started かつ平地かつオッズあり・同着レース除外・`race_ok`)。137 の製品特徴量と 180 万行で一致確認済み。
- 本番勝率モデルの OOF p(108 束・arm E・2008〜)は `artifacts/roi_explore/rows.parquet` から race_id+horse_id で結合(F7 と F5 の一部でのみ使用)。
- 予測: `mev-binary-v2` の年次 walk-forward(年 y は 2007〜y−1 で学習・2010〜2026 を採点・786,049 行)= `artifacts/roi_explore/results/armC_binary_drop-sameday+weightlive_serving_v2_2007/predictions.parquet`。`pred = 100×(p̂×odds − 1)`、期待回収率 EV = 1 + pred/100。
- モデル変種(F4)は同じスクリプト `scripts/roi_explore/direct_return_model.py` を `--rows rows_2007 --train-from 2007 --start-year 2010 --drop-groups sameday,weightlive` で回して作る(ハイパーパラメータは既定値固定・チューニングしない)。

## 2. 窓(事前固定)

| 段 | 期間 | 役割 |
|---|---|---|
| 発見 D | 2010–2015 | 候補の生成(点推定 ≥ 1.00 かつ生存規則) |
| 資格 Q | 2016–2018 | 勝者の呪いの一次除去(点推定 ≥ 1.00 かつ生存規則) |
| 確認 C | 2019–2026-09-29 | Holm つき片側検定(帰無 ROI ≤ 1) |

生存規則(D・Q 各段): 的中 ≥ 20・開催日 ≥ 100・最大 1 的中の払戻寄与 ≤ 50%。
**確認窓の独立性の限界(開示)**: 2019–2026 の値は、137 の評価で「期待回収率 >100/110/120%」の 3 閾値についてだけ既に見ている(いずれも ≈1.0 で不採用)。それ以外の候補は本設計で初めて見る。2025–26 は保存オッズに発走前スナップショットが混ざり(fill-if-null 規約)精度が落ちる。真に独立な確認は前向きにしか無い。

## 3. 候補集合(凍結・計 約 150 本)

すべて単勝・払戻 = 確定オッズ × 賭け金。基準政策 = `EV > 1.20`・均等 100 円。

- **F1 閾値×上限×賭け方**(36): EV 閾値 t ∈ {1.1, 1.2, 1.3, 1.5} × オッズ上限 ∈ {なし, <21, <50} × 賭け方 ∈ {均等, 逆オッズ比例(払戻を揃える), エッジ比例 (EV−1)/(odds−1)(Kelly 形・平均 100 円に正規化)}。
- **F2 区分条件**(85): `EV>1.2` を 1 軸 1 区分に制限。軸と区分は固定: オッズ帯 6([1,3)[3,5)[5,10)[10,20)[20,50)[50,∞))/ 人気 5(1, 2–3, 4–6, 7–9, 10+)/ 頭数 4(≤8, 9–12, 13–15, 16+)/ 芝ダ 2 / 距離帯 4 / クラス 6 / 競馬場 10 / 季節 4 / レース番号 3(1–4, 5–8, 9–12)/ 馬場 4 / 馬齢 4(2, 3, 4, 5+)/ 性別 3 / 通算出走 5(0, 1–3, 4–9, 10–19, 20+)/ 間隔 4(<14, 14–35, 36–90, >90 日)/ 重賞 2 / 騎手 365 日勝率 4(<5%, 5–10, 10–15, ≥15%)/ 前走着順 5(1, 2–3, 4–6, 7–9, 10+)/ 昇降級 3 / 市場エントロピー 4(<0.7, 0.7–0.8, 0.8–0.9, ≥0.9)/ レース内の該当頭数 3(1, 2, 3+)。
- **F3 レース内選択**(5): レース内 EV 最大の 1 頭のみ(t ∈ {1.1,1.2,1.3})/ `EV>1.2` のうち p̂ 最大の 1 頭 / `EV>1.2` かつ p̂ がレース内 1 位。
- **F4 モデル変種**(16 = 8 変種 × {EV>1.2, EV>1.2 & odds<21}): seed 2 / seed 3 / 3 seed 平均(pred の平均)/ rounds 600 / 回帰(純収益・τ>20 円)/ Huber(τ>20 円)/ 本番 OOF p を入力に追加(2008〜学習)/ 直近 8 年のみで学習(rolling)。
- **F5 選択後の再校正**(4): 137 で「120% 超に選ばれた馬は予測 8.2% に対し実現 6.1%」の過大評価が出ている。年 y の予測を、y より前の年(2010〜y−1)の OOS 予測のうち **EV>1.0 の候補行**とその結果だけで再校正(isotonic(p̂→勝率)/ ロジスティック(logit p̂, log odds))し、再校正後の EV > {1.1, 1.2} で買う(2011 年以降のみ・学習行 500 未満の年は買わない)。
- **F7 本番モデルとの合議**(4・2008〜): `EV>1.2` かつ本番 p×odds > {1.0, 0.8} / `EV>1.2` かつ本番 p がレース内 1 位 / `EV>1.1` かつ本番 p×odds > 1.0。
- 対照(判定外): 全馬 / 21 倍未満全馬 / 1 番人気 / 基準政策 `EV>1.2` 均等。

複勝・組合せは実配当が 2025–26 のみ(33,274 行)で確認窓が作れないため**対象外**。2006 年以前の学習は憲法 I で対象外。

## 4. 統計

- 点推定 = Σ払戻 / Σ賭け金。確認窓の主検定 = **ROI=1 に帰無中心化した開催日クラスタ bootstrap(10,000 反復)の片側 p**。**Holm(FWER 片側 2.5%)を確認窓に到達した凍結集合全体に適用**。「候補」= Holm 棄却。「弱い候補」= 点推定 ≥ 1 かつ未補正 95% CI 下限 > 1(診断)。
- 併記: 年別 ROI・1 以上の年数・leave-one-hit-out ROI・賭け数・最大払戻寄与。
- 手順の機械化: スクリプトは D→Q の生存集合を先に JSON に凍結してから確認窓を計算する。非生存の確認窓の値は別ファイルに出し、判定に使わない。
- 帰無診断(任意): 予測を固定し勝者を市場 q から 50 回抽選した合成結果で同じ手順を流し、「確認窓で Holm を通る本数」の分布を出す(多重比較制御の実効確認・利益の検定ではない)。

## 5. 言えないこと(最初から開示)

closing-line oracle(確定オッズで選定・実運用は不利側)/ 公式払戻でなくオッズ×100 円 / 同着除外 / 過去走は現在 DB 値 / 2025–26 のオッズ混在 / 2019–2026 は基準 3 閾値だけ既視 / F4 の変種は 1 seed(seed 平均を除く)= 再学習ノイズを CI に含めていない / モデル変種の探索はモデル選択であり、採用するなら前向き確認が別に要る。
