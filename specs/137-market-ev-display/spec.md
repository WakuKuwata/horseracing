# Feature Specification: 期待回収率(市場連動モデル)の表示

**Feature Branch**: `137-market-ev-display`
**Created**: 2026-09-29
**Status**: 実装中(2026-09-30・ユーザー決定=選択肢 2:2007 年以降のみのモデル+正直な注記)
**Input**: ユーザー「UIUX で期待回収率がわからないのでそれをわかるようにしてほしい。そして期待回収率が 120% を超える馬はさらにわかりやすくしてほしい」

## 位置づけ

2026-09-23〜24 の広域探索(`docs/roi-pattern-exploration-20260923/report.md`)で、ルール型の買い方は全滅し、**現在の単勝オッズと馬の過去成績を入力に持つ「市場連動モデル」の期待回収率が 120% を超える馬**だけが 27 年の walk-forward で回収率 >1 を保った。ユーザーはこの値を画面で見たい。

**本番モデル(mix-129)の勝率 × オッズを表示しない理由**: 本番モデルは市場を見ない設計で、その EV は高いほど負ける(EV≥1.3 で回収 0.70・betting-roi-landscape)。120% 超を強調すると負けが確定している馬群を目立たせる。したがって表示する期待回収率は**別系統の市場連動モデル**の値に限る。

## 何を表示するか

- 出走表(`HorseEntriesTable`)に列「期待回収率」を追加。値は `expected_return = p_mkt × 単勝オッズ` をパーセント表示(例 `124.3%`)し、推定値バッジを付ける(`PseudoValue`)。
- **120% を超える馬**(`expected_return > 1.20`、厳密に超える)は、行に目印の枠線とセル内のテキストチップ「120%超」を付ける。色だけに頼らない。損益色(緑/赤)は使わない。
- 列は並び替え不可(edge ソート禁止・021 R3 と同じ扱い)。
- 出走表の上に常時表示の注記コンポーネント「期待回収率について」:
  - 表示中の「モデル勝率」とは**別のモデル**(市場連動モデル・`model_version`)の推定であること
  - 計算に使ったオッズの取得時刻(`odds_observed_at`)と計算時刻(`computed_at`)。オッズが計算後に更新されていれば「計算後にオッズが更新されています」
  - 過去検証の要約(下の評価結果の数値)と、**直近の不確かさ**(2025〜26 は保存オッズが発走前スナップショットを含み検証精度が落ちる・前向き検証は未実施)
  - 「的中や利益を保証するものではありません」
- 取消・除外の馬、オッズ欠損のレース、計算がまだ無いレースは値を出さず「—」または「未計算」。0 で埋めない。

## 憲法との関係(例外と根拠を明記)

| 原則 | この feature での扱い |
|---|---|
| I(2006 年以前禁止) | 学習・評価・特徴量とも **2007-01-01 以降のデータのみ**(例外を作らない=ユーザー決定)。研究段階(1986〜)の結果は探索であり、製品用モデルは 2007+ で作り直して再検証した。**その結果 120% 超の優位は消え、回収率は約 100% だった**ので、注記でそのまま開示する |
| II(オッズを予測モデルの入力にしない・試すなら別 spec) | **本 spec がその別 spec**。市場連動モデルは本番の勝率モデル系列(features registry / FEATURE_VERSION / prediction_runs)の外に置き、出力はどの特徴量にも戻さない(leak-guard テストで固定)。全特徴量の利用可能タイミングを下表に記載 |
| III(walk-forward OOS・ベースライン・ECE) | 年次 walk-forward(y 年は y−1 年までで学習)・対照(全馬・21 倍未満・1 番人気)・較正表を evidence に保存。**前向き(未使用期間)の確認は未実施**で、強調表示はその前に行う製品判断であることを注記で開示 |
| IV(1着率の Σ=1) | 市場連動モデルの p は二値分類の生出力でレース内正規化していないため、**1着率として表示しない**。表示するのは期待回収率のみ |
| V(再現性・監査) | 行ごとに model_version・logic_version・使用 booster ファイル名と sha256・odds_used・odds_observed_at・computed_at・run_id を保存。オッズ履歴は持たない(レース単位で最新のみを置き換え) |
| VI(契約先行) | DB migration 0018 → API `GET /api/v1/races/{race_id}/market-ev` → front の順。OpenAPI は純追加 |

## 評価結果(製品用モデル・2007+ データのみ)

モデル `mev-binary-v2`(LightGBM 二値・77 入力・当日馬体重と同日先行レース情報は不使用)。学習 2007 年〜、各年を前年までのデータで学習する年次 walk-forward で 2010〜2026 年を予測。開催日クラスタ bootstrap。

| 対象 | 期間 | 単勝回収率 | 95% 区間 | 片側 p(≤1) | 賭け数 | 1 以上の年 |
|---|---|---|---|---|---|---|
| 期待回収率 >120% | 2010–2018 | 101.3% | 94.3–109.2% | 0.36 | 22,354 | 6/9 |
| 期待回収率 >120% | 2019–2026 | 99.5% | 86.7–113.3% | 0.53 | 7,682 | 3/8 |
| 期待回収率 >120% | 2010–2026 通算 | **100.8%** | 94.2–107.9% | 0.39 | 30,036 | 9/17 |
| 期待回収率 >110% | 通算 | 98.2% | 93.8–102.9% | 0.76 | 52,844 | 4/17 |
| 期待回収率 >100% | 通算 | 96.2% | 93.0–99.6% | 0.98 | 94,991 | 3/17 |
| 対照: 全馬 | 2019–2026 | 72.0% | | | 355,466 | |
| 対照: 21 倍未満の全馬 | 2019–2026 | 80.8% | | | 165,149 | |

- 較正: 予測勝率 7 区分の ECE 0.0012(全区分で予測と実現がほぼ一致)。ただし 120% 超に選ばれた馬に限ると予測勝率 8.2% に対し実現 6.1% で、選択された馬では過大評価(勝者の呪い)。
- 120% 超に該当する馬は 2024〜26 年で全出走馬の約 1.5%。
- 研究段階の 1986 年〜学習版(同じ特徴量・同じ閾値)は 2019–2026 年 111%・2000–2026 年 111.5% だった。差は学習データの期間だけであり、優位が古いデータに依存していた可能性がある。製品では採用しない。
- **結論**: 期待回収率 120% 超は「市場平均よりずっと損をしにくい馬群(全馬 72% に対し約 100%)」であって、利益が確認された買い方ではない。注記にこの数値をそのまま出す。

## 非対象

- 買い目推奨(recommendations)・Kelly・自動購入への組み込み
- 本番勝率モデル(mix-129)の変更
- 前向きの確認検定(別 feature。発走前オッズの蓄積が前提)

## Success Criteria

- SC-001: 期待回収率が計算済みのレースで、出走表に全出走馬の期待回収率が推定値バッジ付きで表示される
- SC-002: `expected_return > 1.20` の馬だけに目印(枠線+「120%超」)が付く。1.20 ちょうどには付かない
- SC-003: 取消馬・未計算レース・オッズ欠損レースで 0 や NaN を表示しない
- SC-004: 注記に別モデルであること・オッズ取得時刻・計算時刻・検証要約・直近の不確かさが常時表示される
- SC-005: 日次更新(レース更新)で単勝オッズが書かれた結果未確定レースは、自動で期待回収率が再計算される
- SC-006: 市場連動モデルの出力は本番の特徴量・学習・校正の入力に一切入らない(leak-guard テスト)
- SC-007: 既存の API/front/admin/ops/features テストがすべて緑。OpenAPI は純追加
