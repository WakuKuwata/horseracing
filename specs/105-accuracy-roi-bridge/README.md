# 105: 精度→回収率の橋の決着 — 架からない(2026-08-31)

ユーザーの問い「回収率を上げるには的中させることが必要で、そのために精度を求める。
この考え方・計算・アプローチは正しいか」を、codex 3 レンズ(直観の擁護 / 測定の敵対検証 /
定量の橋)+ 実測 2 本で決着させた。speckit 全工程は踏んでいない。本 README が正本。

## 概念の判定(codex 3 本一致)
- 直観は「当てる = **市場が織り込む的中率より高く当てる馬の識別**」と定義すれば正しい。
  切れるのは全体 LogLoss・的中率の改善をそれと同一視する一点だけ
- 当プロジェクトの旧命題「精度は ROI レバーでない・天井 ×0.816」は**過剰一般化**:
  0.816 は数学的天井でなく「市場と同程度の情報しかない戦略の基準回収率」
- 正しい帰無は P(Y|q,p,Z)=P(Y|q,Z)。ブレンド a≈0.0085 は広域・単調な信号の否定のみ

## 定量の橋(Benter 整合)
- ROI=1.0 に必要な追加情報 **ΔR² ≈ 0.018**(Benter 実測 0.0178 とほぼ一致 = 物差しの妥当性)
- 市場に並ぶだけで歴代最大レバー(−0.0134)× 2.4 個分。以後は**市場と直交する新情報**のみが乗る
- 三連単は控除差 7.5pt で必要情報量が単勝比 2.0〜2.1 倍

## 帰結
codex 事前確率(狭い ΔROI 正 30% / 利益 10%)はどちらも No 側に着地。
**「現在の p は市場に対し追加の収益情報を持たない」は、指摘された測定の穴を塞いだ上で成立。**
橋が開く条件はリベート(JRA に無い)・控除 6.9% 以下の取引所(無い)・市場が見ていない
直交情報の独占のみ。
