# Contract: 重みの適用範囲(US2)

**この契約は US1 の判定が正のときにだけ発効する。** US1 が REJECT なら不要になる。

## 問題

079 の重みは `model_X`(booster)にしか渡っていない。実装を確認したところ、
`fit_target_encoder` / `oof_target_encode` / `fit_calibrator` は**いずれも重み引数を持たない**。
`prior` も `y_model.mean()` で重みなしである。

素直に実装すると **booster は「直近が重い世界」を学び、encoder と校正器は「一様な世界」を見る**。
テストでは捕まらない静かな不整合で、encoder と校正器が booster の変化を相殺しうる。

## 宣言を必須にする

どこに適用するかを**明示的に宣言**し、artifact に記録する。
**「booster にだけ渡して他は素通り」を暗黙の既定にしてはならない。**

宣言と実際の適用が一致することを実行時に検証し、片方にだけ適用する変異でテストが落ちること。

## どちらを採るかは測定で決める

booster 限定と一貫適用の**両方を測る**。理屈だけで決めない。

feature 100 で「正しそうに見える US2(control variate)」が測定で棄却された(R²=0.029)。
同じ形を繰り返さない。

## 一貫適用を選ぶ場合の要件

### target encoding

- **件数・平均・prior をすべて同じ重みで**計算する。一部だけ重み付きは不整合。
- smoothing を**単純件数ではなくカテゴリ別 ESS** で決める。
- ESS が不足するカテゴリは**親カテゴリまたは全体 prior へ縮約**する。
- rare / unknown の明示的 fallback を持つ。
- **as-of 時間境界は動かさない。**

### 校正器(OOF isotonic)

- **bin 別 ESS を監視**する。
- 不足時の fallback(自由度の制限、より単純な校正器)を**事前に規定**する。

### 粒度

各消費者について「**レース当たり**の重みか **馬行当たり**か」を明示する。
PL 損失では `α_r · L_r` が正しいが、TE や校正で各馬行に α を付けると
**多頭数レースが別途強くなる**。

## 評価は無重み

訓練に重みを入れても、**評価は無重みで行う**。目的は「将来レース当たりの平均 winner NLL」で
あり、重み付きで評価すると estimand がすり替わる。

## テスト

| 種別 | 内容 |
|---|---|
| 必須 | 宣言と実適用の一致。片方にだけ適用する変異が落ちる(INV-S1) |
| 必須 | 暗黙の既定が無い — スコープ未宣言は fail-closed(INV-S2) |
| 必須 | TE の as-of 境界が動かない(INV-S3) |
| 必須 | TE の件数・平均・prior が同じ重みを使う(INV-S4) |
| 必須 | 粒度(per_race / per_horse_row)の宣言と一致(INV-S5) |
| 必須 | カテゴリ別 ESS と消失カテゴリが報告される |
