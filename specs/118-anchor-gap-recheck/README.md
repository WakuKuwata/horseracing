# 138列anchor＋出走間隔補正の対応比較

**138列＋出走間隔補正を代替候補として保持し、研究上の第一候補は125列＋補正を維持する。** 3seed平均のwinner NLLは無補正138列より−0.001644改善したが、既保持125列＋補正より+0.000764悪化した。判定は `ANCHOR_GAP_ALTERNATIVE_RETAINED`。

2020-01-01〜2026-08-23の同じ23,030評価レース、22,990適格レース、715開催日を比較した。数値はseed42/43/44の損失の等重み平均で、確率平均アンサンブルの性能ではない。

| 構成 | 全期間の平均winner NLL（低いほど良い） |
|---|---:|
| 138列・無補正の基準 | 2.047361 |
| 今回の138列＋補正 | 2.045717 |
| 既保持125列＋補正 | **2.044952** |

全6比較で最近3/5年・top2/top3・校正の主要品質ガードは通過した。138列への補正増分は3seedとも改善方向だったが、各seedの98.75% total CIはゼロを跨ぐ。小幅改善として研究候補を保持し、改善が確定したとは扱わない。既保持候補との比較ではseed43のnk群の非劣性が未確定で、2026年にnk馬を含むレース群にも未確定が残る。

2026年単独では今回の構成が既保持候補より−0.004336改善した。一方、中山では無補正138列より+0.012902悪化しており、13列を戻すだけで補正の弱点が解消するわけではない。117で固定した診断群の記述であり、群別のモデル切替や追加の採用条件にはしない。

追加学習は不足していたseed43/44の2019年anchorの2本のみ。学習開始から最終完了記録まで約12.0分、fit累計22.7分。補正係数は各seedのanchor自身の厳密な先行年予測から推定し、旧125列側は元115/116の係数を維持した。62テストと2構成smokeを通過し、旧baselineの損失は全レース一致した。[独立監査](evidence/independent-review.json)でも全レースNLLの誤差0、品質指標・CI・係数の時系列・固定診断群の一致を確認した。

次の優先候補は、過去調査で残している季節×性別補正の追加効果。既保持125列＋補正を基準に、補正同士の重複と2026年の品質を確認する。今回の138列版は代替候補として証拠を保持する。

本番モデル・旧研究結果・年枠予約は変更していない。未使用期間での最終確認と、実際の予測時に利用できる入力条件の検証は別に残る。
