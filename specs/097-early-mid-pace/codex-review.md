  にとどまる。`_best` は順序統計で分解不能 = 真に新しい
- **(d)(新列なしで既存 2 列に任せて死列を落とす)は kill-test では棄却できない**: -0.0163 は
  「first3f 分割に依存するよう学習された固定モデル」の分布シフト測定であり、再学習すれば残存
  特徴に容量が再配分されうる。(d) の評価には再学習 ablation が要る
- 各案の追加リスク: (a) early-mid は距離で物理区間が変わるため、距離遍歴の交絡が乗りうる /
  (b) min は出走数・外れ値に敏感 / (c) balance 類似列は last3f 係数がノイズ増幅+相関候補で
  seed 依存の分割入替を悪化 / (d) 木が引き算の再構成に深さを浪費し 1200m の厳密情報も捨てる

なので、**ゲート自体が (d) との比較になっている**。距離交絡は受容リスクとして記録(既存
rel_first3f 列も同じ性質で 023 以来受容済み。レース内相対が距離を大部分吸収する)。

## Q2 評価設計 → 回答: 条件付きで健全。凍結すべき 3 点が未定なら曖昧で gameable

1. **帰属**: 両アームが同一のマスク・再構築規則・行・fold を受け、差が新列だけなら汚染ではない。
   マスクがアームごとに行の適格性を変えたら帰属は壊れる
2. **急停止 vs 漸減**: 0% マスクは定常状態の推定であり移行期の便益を過大評価しうる。
   カットオフ前の観測が as-of 窓に残る **washout 期間**を、除外するか推定対象の一部と定義するか
   を事前に固定する。カットオフと coverage-path の感度も結果を見ずに選ぶ
3. **再学習の意味論(最重要)**: **両アームを各 fold 内で「シミュレートした供給カレンダー」で
   マスクした学習データから再学習する**。学習は非マスクで採点だけマスクすると「stale モデルの
   serving 衝撃」を測ることになり、採用判定(再学習後の価値)とは別物 — 比較が反転すらしうる
4. **前例の射程**: 091 が正当化するのは二重ゲート構造まで。履歴集約を変えるこの介入はより深く、
   合成 2019-2024 採点は「結果非依存・as-of 因果・対称・反実仮想頑健性として報告」の 4 条件を
   満たす場合のみ許容(過去予測の再構成と読ませない)
5. 最強の primary 案: **複数の事前登録カットオフ**での擬似供給停止 + washout 後のみ採点 +
   fold ごとマスク再学習 + v4 seed/cluster CI の pooled paired winner-NLL。
   `ci_high < -0.002` を要求。+0.003 の full-info guard と、実 2025-2026 の方向一致 guard を併設

**採否**:
- 3(fold 内マスク再学習)**採用** — 091 の「mask は付随的工夫でなく機構の本体」と同じ結論
- 2(washout の明示的定義・カットオフ事前固定)**採用**
- 1(同一マスク・行適格性の対称性)**採用**(契約テスト化)
- 4(反実仮想頑健性としての報告)**採用**
- 5 のうち複数カットオフ pooled **採用**・実 2025-2026 方向一致 guard **採用**。
  ただし **`ci_high < -0.002` は不採用**: v4 の共有ゲート実装は
  `point < -δ AND ci_high < 0`(+seed 分散込み区間)で、feature ごとに判定式を変えるのは
  v3 が排除した「2 つのゲート実装」の再発になる。既定式 δ=0.002 を維持し、乖離は plan に記録
