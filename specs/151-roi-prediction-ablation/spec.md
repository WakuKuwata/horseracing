# 151 ROI系への市場非入力予測の追加価値

ユーザー依頼（2026-10-25）: ROI系だけの場合と、予測モデルを混ぜた場合を同じ条件で比較し、予測モデルを残す価値を検証する。

## 固定する比較

- ROI系のみ: `softmax(a log q + b log p_mev)`。
- 予測追加（主）: `softmax(a log q + b log p_mev + c log p_pred_preweight)`。
- 予測追加（感度）: 同式の `p_pred_full`。結果で主条件を選び直さない。
- mevは現行15 seed平均、予測は130の前年まで再学習した129レシピ6本の補正後平均。単一の最新モデルで過去を予測しない。市場qと正規化mev単独も記述的参照にする。
- 係数は全て[0,5]、winner NLL最小化。各年Yのfitは両腕同じ共通完全fieldの2020..Y-1、2020–2021を初期fit専用、主評価2022..2026-06-26。141の2010開始fit係数と取り違えない。

## 同条件と評価

2007以降の履歴を使用した保存物に限定。rows2007の平地・race_ok・非同着・上限日までを使い、全15seedと全6member/両regime、111 snapshotのstarted馬ID集合が完全一致するレースだけ共通採用。馬単位inner joinでfieldを減らさず、IDを変換しない。除外数と理由を保存。130 receipt/SHA/前年までのOOF校正、再構成winと既存130 NLLのparityを確認。

主政策は単勝EV>1.0、選ばれた馬へ各100円、最大10頭、1レース予算1000円、残額現金。候補10頭超はEV降順・馬番・馬IDで固定。オッズ上限なし。EV>1.2は事前固定感度であり、結果による閾値選択をしない。全腕同じオッズ・ラベル・開催日、無購入レースも分母に残す。精算は確定オッズ×的中の仮想精算。

主収益指標は共通予算あたり利益差、回収率差・投資額・購入数・見送り・的中・年別・DD・最大連敗・上位5払戻ゼロ・最大差レース除外も報告。品質はwinner NLL、binary LogLoss/Brier/ECE、選択集合の実勝数/推定勝数。開催日paired bootstrap4000回/seed20261025で毎回各腕の合計比率を再計算。収益は3比較（主追加EV1.0、full追加EV1.0、主追加EV1.2）にBonferroni、NLLは2比較にBonferroni。同じresampleを全腕に使う。

## 判定と限界

主追加EV1.0の利益差と回収率差の補正区間が両方正なら「この過去比較で追加価値を支持」。NLL改善のみなら情報価値とROI価値を区別。区間が0を含む場合は「追加価値未証明」であり無価値の証明ではない。係数c>0だけで存続価値を認めない。fullだけの改善で主条件を昇格させない。
