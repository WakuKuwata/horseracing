# 142: 市場混合EV・購入条件・市場モデルの収益研究

Date: 2026-10-19 / Status: completed (research only; no adoption)

## User scope

ユーザーは固定時刻の新規収集を保留し、②市場混合EV、③購入・見送り条件の同予算比較、④モデル改善から進めることを指定した。141の表示は本日のmainで完成済み。新規capture、automation、購入、本番モデル変更は本研究に含めない。

## Requirements

- FR1: ローカル保存データのみを利用。2007年未満と2026-06-26超を対象外にし、race_ok・非同着の完全なレースを採点する。過去期間は既参照の開発用であり untouched_holdout=false / can_adopt=false / eligible_for_verdict=false。
- FR2: 現行15seed OOFの確率を先に平均し、141の年次凍結係数で市場混合確率を再現する。新モデルへ現行専用係数を移送しない。既存の係数・protocol・S1〜S5・結果を変更しない。
- FR3: 政策はraw EV>1.2、mix EV>1.0、mix EV>1.2、raw EV>1.2 AND mix EV>1.0、および市場一番人気参照を固定する。1レース1,000円の共通予算、100円単位、最大10頭、スコア降順・馬番/馬IDの固定tieで選択。選択頭数nにfloor(10/n)単位ずつ配り余りと見送り分は現金として残す。ラベルを選択関数へ渡さない。
- FR4: 総利益・投資額・払戻・投資分ROI・全レース予算に対する利益・的中・見送り・レース決済単位DD/連敗・最大/上位5払戻除外・高配当依存を報告。全対象開催日を共通抽出するpaired bootstrap(4,000回、seed20261019)。各政策の異なる投資額を同予算損益と混同しない。未購入日も母集団に残す。
- FR5: 主系は保存確定オッズ由来の仮想精算。ローカルに保存済みの公式/結果ページ払戻と勝者キーが照合できる部分集合は別途精算し、出所と対象率を表示。購入時刻の収益を復元したとは呼ばない。
- FR6: 市場モデルのbinary baseline(300 rounds)、6候補のearly-stop小HPO、race-softmax固定1候補を比較する。探索2016〜2018・seed1のみ、候補順と同点時規則を固定。各年Yの早期停止は2007..Y-2でfit/Y-1でvalid、選んだ反復数で2007..Y-1をrefitしてYを予測。外側2019〜2026で候補を選び直さない。特徴は既存市場モデルのsameday/weightliveを除いた77列、カテゴリ辞書も各学習集合限定。
- FR7: binary候補選択はレース均等の正規化winner NLL。softmaxはレース完全groupを維持しgradient/Hessianを検証。主比較は15seedの確率平均(損失差平均とは区別)で、誤差・較正・同予算利益を報告。複数比較に補正した区間も併記し、過去探索から将来利益の採用判定を出さない。
- FR8: 入力・コード・protocolのSHA、cutoff、学習期間、反復数、seed、実費、保存本体roundtripを保存。新しい出力先のみ、既存の凍結結果は上書き禁止。実装後にprotocolを凍結してから新規実験を開始。

## Success criteria

1. 141の完成状態を記録し、現行raw/mixの同予算比較と条件別の不確実性を出せる。
2. 新モデル比較が厳密な過去学習で実行でき、研究用本体・予測・来歴が揃う。
3. 選択ラベル非参照、予算、時系列分割、完全group、数値gradient、保存再生の対象テストが成功する。
4. 失敗候補も全報告し、結果から閾値・候補・対象レースを変更しない。
