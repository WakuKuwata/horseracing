# Data Model: ニックス(種牡馬×母父の配合相性)特徴

**Feature**: 090-nicks-cross-features | **Date**: 2026-08-10

DB スキーマ変更なし・migration なし。特徴行列に **2 列を純追加**し、特徴定義版を
features-018 → **features-021** に更新する。

## 追加する特徴列(2 列・group = `nick_cross`)

| 列名 | 型 | 意味 | 欠損の意味 |
|---|---|---|---|
| `nick_lift_log` | float64 | 配合相性の残差。`log(縮約済み交差率) − log(独立性期待率)`。正=期待以上に走る配合 | 父名または母父名が不明(=キーが作れない) |
| `nick_obs_count` | float64 | 採用された階層段の**実観測数**(親フォールバック行は 0.0)。信頼度の代理 | 同上 |

- 全列 **float64**(プール依存の dtype ドリフト防止・026/059/061 と同一規約)
- **0 埋め禁止**: キーが無い行は NaN。観測が薄い行は「親へ縮約された値 + obs_count=0」で
  表現し、NaN にはしない(D6)
- `nick_level` は**採用しない**(`nick_obs_count` と強相関のため。research D7/D10)

## 算出の定義(実装が従う唯一の正本)

対象行 `(race_id, horse_id)` ごとに、**その馬の出走日より厳密に前**の観測のみを用いる。
同一開催日は除外する。すべての集計から**対象馬自身の過去実績を控除**する。

### 1. marginal(独立性期待値の材料)

```
p_sire     = 父の他産駒の as-of 勝率      (自馬除外)
p_damsire  = 母父の他産駒の as-of 勝率    (自馬除外)
p_overall  = 全体の as-of 勝率            (自馬除外)
expected   = clip(p_sire × p_damsire / p_overall, EPS_LO, EPS_HI)
```

3 つの marginal は**それぞれ独立に as-of 取得**する。縮約済みの値を別の縮約の親に使っては
ならない(親が stale 化する。070 の規律)。

### 2. 入れ子の部分プーリング(硬い段の切り替えはしない)

集計は 2 階層。**閾値で段を選ぶのではなく、連続的に親へ寄せる**(research D5a)。

| 階層 | 集計キー | 縮約先 |
|---|---|---|
| L1 | (父名, 母父系統) — **当該 L0 セルの観測を除く**(leave-child-out) | 独立性期待値 |
| L0 | (父名, 母父名) | L1 の推定値 |

```
mu_L1 = (w_L1_excl + LAMBDA_L1 × expected) / (n_L1_excl + LAMBDA_L1)
mu_L0 = (w_L0      + LAMBDA_L0 × mu_L1)    / (n_L0      + LAMBDA_L0)
```

- **leave-child-out**: `w_L1_excl` / `n_L1_excl` は L1 の集計から当該 L0 セル自身の観測を
  引いたもの(親推定に子を含めると同じ情報の二重利用になる)。
- 観測ゼロのセルは自動的に親へ、親も空なら期待値へ**連続的に**落ちる。
  硬い閾値(旧 `MIN_CELL`)は**廃止**した — 段の切り替えによる不連続が消え、凍結すべき
  定数が 1 つ減る。
- 系統×系統の階層は**設けない**(L1 が父個体を条件付けて 96.4% を覆うのに対し、L2 は
  父個体を失う。将来の再検討事項として research D5a に記録)。

### 3. 残差と信頼度

```
nick_lift_log  = log(mu_L0) − log(expected)
nick_obs_count = n_L0                       (L0 セルの as-of 有効観測数)
```

`nick_obs_count = 0` は「この配合の前例が 1 件も無い」= `nick_lift_log` が親由来である
ことを表す。木はこの 2 列の組で「値をどれだけ信じるか」を学習できる。

### 4. 定数(**実装前に凍結・評価結果で変更しない**)

| 定数 | 値 | 導出 |
|---|---|---|
| `LAMBDA_L0` | **350** | 経験ベイズ最適 `λ* = σ²_within / σ²_between` = 0.0661 / 0.000185(D2 の n≥100 超過分散)= 357.5 を丸めた値 |
| `LAMBDA_L1` | **350** | 同上(L1 の分散を別途推定する根拠が無いため L0 と同値に置く。差を付けるなら実装前に導出を記録すること) |
| `EPS_LO` / `EPS_HI` | **1e-4 / 0.9** | 期待率の clip。`p_sire`/`p_damsire` が極端なときの発散防止 |

**070 の λ=5.0 を流用しない**。実測で 2 桁小さく、n=20・0 勝(帰無確率 22.8% = 全く珍しく
ない)のセルに `lift_log = −1.609` という巨大な負値が付くことを確認した(research D5a)。

定数は**モジュール定数**とし実行時引数にしない(materialize 経路と in-memory 経路で同一値に
なり bit parity が保たれる。025 規約)。

## 集計に含める観測の定義

- 母集団は **`entry_status = started` かつ結果が確定した行**(026 と同一規約)。
- 成果は「1 着かどうか」(spec の Assumptions: 既存の血統特徴と基準を揃える)。
- 取消・除外馬は母集団に含まれない。
