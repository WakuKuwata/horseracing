## D2. 分散分解 — 配合差は実在するか(最重要の測定)

セル間の成績のばらつきが「本物の相性差」か「たまたま」かを、二項標本ノイズと分離した。
残差スケール(観測率 − 独立性期待率)で観測分散を測り、そこから
`E[p(1−p)/n]`(標本分散)を引いた超過を「実在成分」とする。

| セル最小観測数 | セル数 | 観測分散 | ノイズ分散 | 超過 | 超過率 |
|---|---|---|---|---|---|
| ≥20 | 12,605 | 0.002434 | 0.001837 | +0.000597 | 24.5% |
| ≥50 | 3,794 | 0.001201 | 0.000809 | +0.000392 | **32.7%** |
| ≥100 | 1,283 | 0.000624 | 0.000439 | +0.000185 | **29.7%** |
| ≥200 | 388 | 0.000386 | 0.000236 | +0.000150 | **38.8%** |
| ≥500 | 74 | 0.000153 | 0.000110 | +0.000043 | 28.3% |

実在成分を標準偏差に直すと **n≥100 で勝率 1.36 ポイント = 基準勝率(7.12%)の 19.1%**。

**Decision**: 当初の「ほぼ確実に null」という見立ては**下方修正しない**が、素材としての
配合相性は実在すると認める。spec 冒頭の性格づけを「両面」に書き換えた。

**限界(過大評価を避けるための明示)**: この超過には、配合と相関する他要因(生産者・厩舎・
出走クラス・世代)が混入しうる。モデルはそれらを既に入力に持つため、**超過分散の存在は
増分価値の証明ではない**。増分の有無は事前登録ゲートのみが決める。

## D3. 残差の定義

**Decision**: 独立性ベースライン(対数線形モデルの交互作用ゼロ)に対する対数比。

```
expected      = p_sire × p_damsire / p_overall        (すべて as-of・自馬除外)
shrunk_rate   = 入れ子の部分プーリング(D5 参照)
nick_lift_log = log(shrunk_rate) − log(expected)
```

**λ は 070 の 5.0 を流用しない(codex 指摘 → 実測で確認)**。詳細は D5a。

**Rationale**:
- 生の交差率は主効果でほぼ説明される(実測 corr(交差率, 期待率)=0.524・corr(交差率,
  父実績)=0.453)。032 の「既存特徴の単純積は冗長」がそのまま当てはまる。
- 残差にすると**父の実績とほぼ直交**(実測 corr = **−0.126**)= 主効果の引き算が意図
  どおり働いている。
- 期待値を分母に置いた対数比なので、**縮約の中心が期待値**になり、観測が薄いセルは
  自然に「相性なし(=0)」へ寄る。0 勝セルでも縮約後に log を取るため発散しない
  (λ·expected > 0 が下駄になる)。

**Alternatives considered**:
- 加法残差(観測率 − 期待率): スケールが基準勝率に依存し、勝率の高い父と低い父で同じ
  「1 ポイント差」の意味が変わる。対数比なら相対差として揃う。
- logit 差: 理論的には最も素直だが、勝率が 7% 付近と低く logit の裾で数値が暴れる。
  対数比は低レート域で logit 差とほぼ一致するため実質同等で安定。
- 生の交差率をそのまま渡す: **不採用**。主効果と強相関で 032 の失敗を繰り返す。

## D4. 頭数交絡の検証

勝率は出走頭数に依存する(8 頭立て 12.5% vs 18 頭立て 5.6%)ため、特定の配合が小頭数
レースに偏ると生の交差率が歪む。

**実測**: 残差と平均頭数の相関 **+0.004**(生の交差率では −0.059)。

**Decision**: **成果指標は勝利のまま**とし、頭数正規化(着順パーセンタイル等)への変更は
行わない。残差の構成が交絡をほぼ相殺していることが実測で確認できたため。

## D5. 階層の段数(**D5a で撤回済み** — 段選択そのものをやめた)

> **supersede 注記**: 本節の「段を 1 つ選ぶ」「親=父単独」という結論は D5a で撤回した。
> 現行設計は 2 階層(L0 / L1)の**連続的な部分プーリング**で、L1 の縮約先は独立性期待値。
> 父単独の段は存在しない。以下はカバレッジ実測の記録として残す。

各段が「最初に使える段」となる出走の割合(閾値 n≥20・上から順に判定):

| 段 | セル数 | 単独で使える出走 | この段で初めて救われる出走 |
|---|---|---|---|
| L0 父×母父 | 45,574 | 75.6% | 720,637(75.6%) |
| L1 父×母父系統 | 5,592 | 96.4% | 201,850(**21.2%**) |
| L2 父系統×母父系統 | 64 | 98.5% | 19,603(2.1%) |
| L3 父単独(親) | 1,838 | 99.5% | 10,075(1.1%) |
| どの段でも不足 | — | — | 697(0.07%) |

**決定的な観察**: L1 が救う 201,850 行は **100% が L2 でも救える**。つまり L1 は
カバレッジのためには不要。しかし L1 は**父個体の identity を保持**する(L2 は父を系統に
潰す)ため、推定の具体性が段違いに高い。逆に **L2 が単独で救うのは 2.1% のみ**。

**Decision(D5a で撤回)**: 当時は「3 段(L0 → L1 → 親=父単独)」としたが、閾値による
段選択そのものを D5a で廃止した。**L2(系統×系統)を採用しないという判断は維持**。

**Rationale**: L1 だけで 96.4% を覆い、かつ父個体を保つ。L2 は 64 セルと粗く、救う量も
2.1% と小さい。段を 1 つ減らすと as-of 集計の pass が 1 つ減り、072 投影下の serving
レイテンシ(現状 ~24 秒)への上乗せも抑えられる。L2 で救われていた 2.1% は親へ落ち、
残差はほぼ 0(=相性情報なし)になるが、これは正しい振る舞いであり `nick_obs_count` が
その旨をモデルに伝える。

### D5a. 縮約方式と λ の是正(**codex レビューで当初案を 2 点とも撤回**)

当初案は「単段縮約(各段が独立に期待値へ縮約)+ 硬い閾値で段を 1 つ選ぶ + λ=5.0(070 流用)」
だった。codex の指摘を受けて実測で検証した結果、**2 点とも誤りと判明したため撤回する**。

**(a) λ=5.0 は 2 桁小さい**。正規-正規/ベータ-二項の縮約における最適強度は
`λ* = σ²_within / σ²_between`。自分で測った分散分解(D2)を代入すると:

| σ²_between の出所 | λ* |
|---|---|
| n≥50 の超過分散 0.000392 | 168.7 |
| **n≥100 の超過分散 0.000185** | **357.5** |
| n≥200 の超過分散 0.000150 | 440.9 |

λ=5.0 の帰結(codex が数値で指摘・実測で確認):

| セル | λ=5 の lift_log | λ=350 の lift_log | 帰無仮説での 0 勝確率 |
|---|---|---|---|
| n=20・0 勝 | **−1.609** | −0.056 | **22.8%(全く珍しくない)** |
| n=50・0 勝 | −2.398 | −0.134 | 2.5% |
| n=100・0 勝 | −3.045 | −0.251 | 0.06%(本当に珍しい) |

λ=5 では観測 20 走のセルに 80% の重みがかかり、**たまたま 0 勝だっただけのセルに巨大な
負値**が付く。特徴の左裾が丸ごとノイズになる。

**Decision**: **λ = 350**(n≥100 の超過分散から導出・**実装前に凍結**)。
**限界の明示**: この λ は全期間の分散構造から design-time に推定した単一スカラーであり、
厳密には fold ごとの as-of 推定が正しい(deferred)。ただし **λ は評価実行より前に凍結され、
ゲート結果によって変更されない**ため、憲法 III が防ごうとしている「結果を見た調整」は
発生しない。070 の λ=5.0 が根拠なく固定されていたのに比べれば改善である。

**(b) 単段縮約 → 入れ子の部分プーリングへ変更**。codex の指摘「『親が stale 化する』は
再帰を避ける統計的理由になっていない(親も各時点で as-of 再計算すればよい)。単段縮約は
父×母父系統に共有された配合情報を捨てている」は正しい。070 の規律は**実装上の注意**
(pre-shrunk 値をキャッシュして使い回すな)であって、階層モデルを否定するものではなかった。
私はこれを取り違えていた。

**Decision**: 硬い段の切り替えをやめ、**入れ子の連続的な部分プーリング**にする:

```
mu_L1 = (w_L1 + λ1 · expected) / (n_L1 + λ1)     # L1(父×母父系統)を独立性期待値へ縮約
mu_L0 = (w_L0 + λ0 · mu_L1)    / (n_L0 + λ0)     # L0(父×母父)を L1 の推定値へ縮約
nick_lift_log = log(mu_L0) − log(expected)
```

- **親は leave-child-out**: `mu_L1` は L1 から当該 L0 セルの観測を除いて計算する
  (codex 指摘「親推定に子セルを含めると情報の二重利用」)。
- **硬い閾値 `MIN_CELL` は廃止**。段の切り替えによる不連続が消え、凍結すべき定数が 1 つ減る。
- **限界**: `LAMBDA_L1` は L0 と同値の 350 に置くが、粗い階層ほどセル間分散は小さく本来の
  λ はより大きい。つまり L1 は**過小縮約ではなく過大縮約の方向に保守的**に外れうる。
- 観測ゼロのセルは自動的に親へ、親も空なら期待値へ連続的に落ちる。

**まだ採らないもの**: 系統×系統(L2)の段。L1 が既に父個体を条件付けて 96.4% を覆うのに対し
L2 は父個体を失う。codex は「2 段化の根拠は現情報だけでは不十分」としたが、これは L1 を
落とす案への反論であり、L1 は**採用している**。L2 の追加は将来の再検討事項として残す。

## D6. 欠損とゼロの区別

- **キーが存在しない**(sire_name または damsire_name が欠損)→ **NaN**(情報なし)。
- **キーはあるが全段で観測が閾値未満** → 親へ落ち、残差はほぼ 0。これは「相性の情報が
  ない」ことを表す妥当な値であり、`nick_obs_count = 0` が信頼度ゼロを伝える。

FR-007「0 で埋めてはならない」は**前者**に対する要求として解釈する(spec のエッジケース
記述と整合)。後者を NaN にすると、カバレッジ 0.07% の穴が 3.2% 程度まで広がり、木が
「情報なし」を学習する機会を失う。

## D8. リーク境界と再利用機構

- `pedigree_features.py::_other_offspring(targets, runs, key, extra=[...])` が
  strictly-before(daily cumsum − 当日)+ **自馬除外**(`cell_cumsum − self_cumsum`)を
  提供済み。`extra=["damsire_name"]` で交差セルに適用する。
- 自馬除外の正しさ: 馬の damsire は不変なので、その馬は交差セルにちょうど 1 つ属する。
  `_cum_before_by(runs, ["horse_id", *extra])` は horse_id で切った時点で damsire_name が
  定数になるため、extra を含めても自馬累積は変わらない。**この自明性を単体テストで固定**
  する(codex 質問 5)。
- オッズ・対象レース結果・未来レースは入力に用いない(leak-guard テストで機械固定)。

### 結論 — 血統交互作用の軸は閉じた

計画段階の分散分解で「配合差は標本ノイズを 25〜39% 上回る実在成分を持つ」と測定し、
素材の実在は確認していた(D2)。しかしその情報は、**既存 137 入力(種牡馬適性・母父適性・
デビュー×血統・系統を含む)を持つ運用モデルに対して増分にならなかった**。D2 の限界注記
「超過分散の存在は増分価値の証明ではない」がそのとおりの結果になった形である。

これは **null-is-success 型の想定どおりの成果**であり、以後この軸(手元データで作れる
種牡馬×母父の配合相性)を再検討しない。**インブリード(血統ページ約 31,000 件の再取得が
前提)に進む根拠も、これで弱まった**——血統の主効果が既に効いており交互作用が増分を
生まないなら、より深い血統情報が増分を生む見込みも下方修正される。
