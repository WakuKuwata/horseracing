# 159 取得30分以内の保存発走前価格による再比較

ユーザー指定の条件: 新規収集せず、判断時点で取得から30分以内のオッズに絞り、ROI系単独と旧予測追加を同じ条件で比較。精算は公式払戻。対象が少なければ結論保留。

- 158の凍結判断34レースを母集団とし、`0 <= decision_at - quote_observed_at <= 1800秒`をtimestampから再計算する。1800秒を含む。取得から発走までの時間と混同しない。既存quote_age_seconds列の値だけで選ばない。
- 全頭同じ取得/判断/発走時刻、全頭・一意ID/番号・field_sizeを検証し、レース単位で採否。未来取得・時刻欠落・曖昧な時刻は除外し、全件理由を保存。馬単位に分母を縮めない。
- 係数・モデル・価格源・判断時計・旧予測のas-of条件・政策は158と同じ。対象レースの確定価格を判断に使わず、再fit/再推論なし。EV>1、1頭100円、最大10頭、共通レース予算1000円、残金現金。無購入レースも分母に残す。
- 両案の選抜を固定した後で、同じ公式払戻表を結合する。新規DBアクセス・外部収集なし。旧データ/成果物は上書きしない。
- 指標と日paired bootstrap4000/seed20261026、収益2指標Bonferroni区間は158と同じ。投資額0で未定義のROI bootstrapは捨てず区間null。1日以下では区間算出しない。
- 元が34レース・4日しかなく、その部分集合である。結果を見る前に**結論保留・記述的比較のみ**を固定する。同じ買い目/利益でも同等性の証明としない。30分の別閾値や有利な時間帯を探索しない。

158から継承する限界: 判断時計は保存MEV計算時刻でありcommit/公開/約定時刻は不明。quote来歴は保存計算の価格ベクトルを示し、全頭同じWeb応答の同時点観測までは証明しない。既参照期間であり、モデル/係数の過去確定価格での学習に由来する較正制約もある。

独立担当fresh30_independentは、全頭の時刻差を再計算してレース全体を制限する設計と、少標本ゆえ結論保留の事前固定に賛成した。
