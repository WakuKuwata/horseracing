# 出走間隔・季節×性別の再確認結果

**現行モデルの保存済み予測にも、出走間隔で補正できる残差が確認できた。** 単純な対数補正を次の本比較の第一候補に残す。季節×性別は全体では改善方向だが、2026年は悪化しており、出走間隔より後に確認する。

これは補正係数を過去年だけで求める研究用の予備検証。LightGBMへ特徴を追加した結果ではなく、正式な保持・採用判定ではない。現在の組合せモデルへの追加効果も未測定。

## 結果

差は候補−現行モデルのwinner NLL。負が改善。2020-01-01〜2026-08-23の22,990レース・715開催日を評価し、2019年3,447レースは初期係数学習にのみ使用した。

| 事前固定した候補 | 全体差 | 98.75%標本CI | 改善方向の年数 | 2026年差 |
|---|---:|---|---:|---:|
| 出走間隔：log＋短期/長期の折れ曲がり3項 | −0.001501 | [−0.002554, −0.000470] | 6/7 | −0.000509 |
| **出走間隔：logのみ** | **−0.001601** | **[−0.002648, −0.000563]** | **7/7** | **−0.000528** |
| 季節×性別：sin/cos 2項 | −0.000606 | [−0.001276, +0.000143] | 5/7 | +0.000537 |

3候補はいずれも点推定が改善方向の `POINT_IMPROVEMENT`。固定改善幅に届かないことやCIのゼロ跨ぎだけでは除外しない。出走間隔の2表現は同じ仮説の比較であり、独立した利得として加算しない。logのみの2024年差は−0.000026とごく小さく、年ごとの効果が同じ大きさとはいえない。

このCIは開催日bootstrap4,000回による標本CIで、学習seedの変動、補正係数の再推定、探索・選択の不確かさをすべて含むtotal CIではない。7年すべて負でも将来の改善を保証しない。top2/top3/ECE・直近期間・重要部分集団の品質ゲートは未測定である。

## 次の確認

出走間隔log補正について、組合せ比較113で残った候補への追加効果と品質一式を測る。予備検証で使ったのは確率への残差補正なので、単に既存 `days_since_last` のlog列を木へ加えるだけで同じ改善が得られるとは判断しない。補正を実モデルに組み込む場合は、係数学習の時系列境界と上位着順の確率整合まで含めて本比較を固定する必要がある。

季節×性別は小幅だから落とすのではなく、全体の改善と直近年の悪化を両方残し、その後に品質・期間安定性を確認する。

## 入力と検証

113が同値性を認証した110 anchor138、seed42・900本の8年分予測と111固定snapshotを再利用した。全started馬、単一winner、開催日、確率、入力列順・レシピ、SHA・receiptを照合した。各評価年の係数学習の最終日は、その年の評価開始日より前であり、全21回の係数学習で有限性・正則化目的関数・勾配残差の検査を通過した。

出走間隔は現行snapshotの履歴定義を使うため、旧081の芝・ダート限定lagと母集団が異なる可能性がある。季節式も今回の登録式を明示している。旧081の厳密再現ではなく、現行入力での再確認である。

境界テスト26件が通過。復旧後runは実時間17.71秒、最大常駐メモリ約1.69GiB。別計測のpeak memory footprintは約2.49GiBで、常駐量と混同しない。初回の説明項目更新による中断と独立診断は[実行前確認・復旧記録](pre-run-review.md)に保存した。

元予測と保存係数からの[独立検算](result-review.md)でも全レースの差・bootstrap CIが一致した。詳細は[全候補の結果](evidence/residual-screen.json)、[仕様](spec.md)、[実施計画](plan.md)、[固定設定](gate-config.json)。本番モデルと過去調査の判定は変更していない。
