# 143 既存の時計・速度・展開特徴による収益比較

2026-10-19。ユーザー指定: まず①時計・速度と②展開を進め現行と回収率・利益を比較し、③購入判断付近への学習重点配分はその後実行する。固定時刻の新収集は保留。

- ローカル保存111 raw Framesのみから、2007年以降・2026-06-26以前へ最初に制限し、追加特徴を計算する。DB・本番書込みなし。
- 時計速度10列、展開コーナー14列の2候補を別々に現行77列へ追加する。モデル容量・300round・購入条件は固定。候補統合や外側成績からの再選択なし。
- 主比較は142と同じ基準77列再学習済み15seed。実際の現行保存ens15も別参照として表示。元77列は再計算しない。
- 15seed×2019〜2026の各年を前年末までの履歴で学習。2026は保存確定オッズが信頼できる6/26上限。追加特徴も各対象日より前の履歴のみを使用する。
- raw EV>1.2、1レース予算1000円、100円単位・最大10頭・floor(10/n)配分、残りは現金。実投資額は異なり得るため、回収率と同予算利益を両方報告。
- ③は①②の比較を保存/hash後、事前固定した基準77列へ適用。①②の勝者を母体に選ばない。142の年次OOF raw p平均からEV1.2付近を重くする固定重み。2007〜2018はOOF不在で1、2019は基準の完全再現が必要。
- 既参照期間の研究、untouched_holdout=false、can_adopt=false。確定オッズ仮想精算は発走前利益を証明しない。

成功条件は全候補の時系列・ID・欠損・保存再生検証が通り、回収率、利益、投資額、購入数、年別、較正、上位払戻依存、開催日paired CIを同条件で比較できること。改善自体は成功条件にしない。
