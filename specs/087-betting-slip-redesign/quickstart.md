# Quickstart: 買い目推奨の金額主役カード表示 (087)

実装後の end-to-end 検証手順。前提: ローカル製品スタック([local-db-setup]: postgres / API :8000 / front dev)。

## 1. テスト・静的検査

```bash
cd front && pnpm test          # 既存 + 新規テスト green(pseudo coverage 含む)
cd front && pnpm exec tsc -b   # 型
cd front && pnpm exec eslint . # lint
```

drift-check(OpenAPI スナップショット不変)が green であること = SC-005 の機械検証。
`git diff --stat` が front の表示層ファイルのみであることを確認。

## 2. 画面検証(dev)

```bash
cd front && pnpm dev
```

推奨データのあるレース(例: 2024-12-28 の任意レース — 044/045 backfill 済み)を開き「買い目」タブ:

1. **予算未設定**: 入力促し + 比率表示(円額なし)を確認
2. **予算 10,000 円を設定**: 全カードに 100 円単位の円額・先頭に「合計 ¥X・N 点・予算の Y%」。合計=カード金額の総和を目視確認(SC-001/007)
3. **カード**: 券種グループ・枠色チップ(出馬表の枠番と一致)・馬名併記・金額最大表示(US2)
4. **根拠を見る**: 展開して疑似 ROI/疑似オッズ/推定オッズ/Kelly 比率に全てバッジが付くこと(FR-040)
5. **予算を 1,000 円に変更**: 即時再計算。小さい stake_fraction の行が「少額のため見送り」に変わり、サマリから抜けること(FR-003/007)
6. **確定済みレース**: 開いた直後に答え合わせ(的中・回収)が前面(SC-004)。「買い目を見る」で当時のカードへ切替(FR-021)
7. **未確定レース**(結果未取込の日): 買い目前面・切替トグルなし
8. **見送りレース**(win_policy_status=no_win_selected): 見送りカードの理由文言(FR-030)
9. **中立開示文**: どの状態でも常時表示(FR-042)。利益語・損益色・ソートがないこと(FR-041)

## 3. 回帰確認

- 旧行(stake_fraction null)を含むレース: 「—(参考表示)」で表示され、金額が捏造されないこと(FR-004)
- 同着レース(dead_heat)・出走取消(void)の答え合わせ表示が現行と同値であること(FR-022)
- localStorage を無効化(プライベートウィンドウ等)して予算入力 → セッション内では機能し、エラーにならないこと

## 期待される成果

- 予算設定済み利用者は、レースを開いて追加操作なしに「どの馬券をいくら買うか」を円額で読める
- API/OpenAPI/DB は一切変わらない(read-only 境界・契約不変)
