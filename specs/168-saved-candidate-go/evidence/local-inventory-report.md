# 保存済みローカル出走資料の独立確認

2026-10-27。DB・HTTP・モデル・cache APIを使わず、既存の `artifacts/scrape_archive` を直接読んだ。

| 項目 | 確認結果 |
|---|---:|

| shutuba原本の保存版 | 5,629 |
| 元取得時計でrace別最新を選び本人開催日を確認 | 3,665レース |
| 本人開催日の読取不明 | 0 |
| 2025年 / 2026年の本人開催日 | 792 / 2,873レース |
| 最新の本人開催日 | **2026-10-25** |
| 2026-10-27以降の本人開催日を持つ保存出走表 | **0** |
| 独立したrace_listページのURL marker | **0** |
| 最新の元取得時計 | 2026-10-26T04:32:02.460370Z |

日時はarchive filenameの元取得UTCを使い、mtime・今回の読取時計で補っていない。各raceの最新原本をgzip復号し、titleの本人開催日を確認した。原archive byte/復号byteのSHAを全行台帳へ残した。価格・予測値は候補判定に使っていない。

一部の10/25出走表には「次 10/31」等のナビゲーションリンクがあるが、未来開催の本人出走表・全頭カードの保存とは扱わない。synthetic fixtureの予定も対象外。

この範囲では未来の観測候補へ使える保存出走原本がない。これは現実の今後の開催がないという結論ではなく、調べたarchive treeに必要資料が保存されていないという結果である。全コンピュータ上の全ファイルを網羅したとは主張しない。
