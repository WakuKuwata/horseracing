# 保存オッズ・精算の品質監査結果

監査日: 2026-10-26。新規収集・スクレイピング・データ修復・DB更新・モデル学習は実施していない。

## 結論

**直近の現DBでは通常単勝の払戻と勝馬価格は一致するが、過去の研究用保存データには確定価格と異なる価格が残っている。先の151モデル比較期間は、保存公式払戻による検証ができない。** 価格品質、取得時刻、出走馬集合を一括で「検証済み」と扱える状態ではない。

特に、購入履歴の精算が公式払戻表を参照していない点は、モデルの優劣とは独立した問題。同着で実際に公式払戻と計算額が食い違うことを確認した。今回は監査にとどめ、精算処理や旧研究成果物を変更していない。

## 対象と証拠

- 2007年以降の現DB 68,500レース、970,677出馬行、965,520結果行を同一READ ONLY / REPEATABLE READ transactionで抽出。保存データの最終開催日は2026-10-25。
- 既存アーカイブ3,727版・720レースを読み、結果表を持つ最新保存版713レースを選択。DBとの一致度で版を選んでいない。読込失敗・選択版のparse失敗・ページrace ID不一致はいずれも0。
- 研究用の凍結データ `rows_2007.parquet` 931,017行・65,673レースと、151の評価14,893レース・205,786行も別層として照合。
- 入力・コード・仕様・テスト計4,475ファイルのSHAを固定。合成テスト43件通過。独立担当が新しい集計コードをimportせず全レース分類と主要集計を再計算した。

「公式払戻」の保存元はすべて `netkeiba_result`。保存結果ページとの内部整合監査であり、JRAの別系統データとの独立照合ではない。

## 1. 確定オッズと払戻

| 確認項目 | 結果 |
|---|---:|
| 現DBに公式単勝払戻の保存があるレース | 713（714払戻行） |
| 出走/結果集合と勝馬/払戻集合が整合するレース | 712 |
| そのうち通常勝ちの `Decimal(odds) × 100 == payout_yen` | **711 / 711完全一致** |
| 通常勝ちの10円以内の差／それを超える差 | 0 / 0 |
| 同着として別扱い | 1 |
| 結果不足により精算全体を保証できない | 1 |
| 元HTMLと保存払戻の金額一致 | 713 / 713 |
| 元HTMLと出走全馬の馬番・価格が一致 | 712 / 713 |
| parse・明示的なID対応・全頭価格まで確認できた厳格な範囲 | **96 / 713** |

馬番・価格一致712件を、そのままID対応まで検証済みとは呼ばない。HTMLはnetkeibaの生ID、DBには `nk:` を含むIDがあり、厳格な検証では文字列の推測変換をせず、ID完全一致または明示的な `mapped` 対応だけを採用した。残りは価格の不一致とID対応証拠の不足を区別している。

保存公式払戻の期間は**2026-08-15〜2026-10-25**。古い67,787レースに公式払戻がないことは、払戻ゼロや価格が誤りであることを意味しない。

### 研究用の凍結データ

現DBと研究用データで価格が異なるのは221レース・2,855行。この221レースは、保存結果HTMLとの全頭価格照合でも差を確認した。

公式払戻と比較できる研究用データ395レースの内訳は、通常勝ち394＋同着1。

| 通常勝ち394レースの保存価格 | 件数 |
|---|---:|
| 公式払戻と完全一致 | 188 |
| 差が10円以内（完全一致に含めない） | 16 |
| 差が10円を超える | **190** |

例: `202601010704` の勝馬12番は研究用保存オッズ6.0、現在8.5、公式払戻850円。`202601010711` の勝馬11番は研究用4.2、現在4.1、公式410円。現在DBではこの通常勝ち394件はすべて完全一致する。**現在DBの修復を、過去の凍結研究データに遡及して適用してはいけない。**

151の評価期間2022-01-05〜2026-06-21は、公式払戻と結果HTMLの保存coverageがともに**0 / 14,893レース**。研究用価格と現在DBは一致しているが、それだけでは確定価格の証明にならない。従来のunderround12件も、現在DBにすべて残存している。この監査では除外条件を追加せず、ROIの再計算もしていない。

## 2. 取得時刻と履歴の保存

### 結果ページと公式払戻の来歴は追跡できる

- 全3,727版にファイル名由来の取得時刻があり、mtimeへの代用は0。
- 公式払戻714行はすべて、同じレースの保存HTMLのいずれかとSHAが一致した。最新選択版との一致528行、旧保存版との一致186行、出所の保存版がない行0。
- 公式払戻の `observed_at` と対応保存版のファイル名時刻の最短差は最大0.129784秒。この一致は保存ページの取得来歴を支持し、オッズの公表時刻を示すものではない。

### 過去の判断時オッズの来歴は限定される

| 現DBの時刻情報 | レース数 |
|---|---:|
| `win_odds_observed_at` あり | 168 / 68,500 |
| その取得時刻が発走前 | 7 |
| 発走時刻以降 | 161 |
| オッズ公表時刻 `win_odds_official_at` あり | 7 |
| 発走時刻自体が保存されている | 3,666 |

NULL公表時刻は確定価格の証明ではない。確定価格の書込みは一部の馬だけでもrace時刻を更新でき、同じ価格の再書込みでは時刻を更新しない。`race_horses.updated_at` は出馬情報更新でも進むため、取得時刻の真値として扱わない。

保存MEV 165,670行のうち、保存時の来歴tokenがquoteのもの3,160行、旧版で出所を確定できないもの162,510行。計算時刻は発走前1,690行、発走以降92,904行、発走時刻不明71,076行。観測時刻が計算時刻より後の行は0。2モデルが同じレースを保存しているため、行数を独立した判断回数とみなさない。

発走前計算・quote来歴・結果未取込・観測も発走前・現在出走集合一致・run一意を合わせると、現存MEVで39レース（各モデル521行）に限られる。これは構造/時刻条件を満たす候補であり、特徴量の時点再現、未参照holdout、公式払戻coverageまで保証した評価集合ではない。

attentionの発走前147pickは、対応する過去MEV runが現在テーブルに残っていない。pickには選択馬の価格が残るが、当時の全頭MEVと取得元を完全には復元できない。現在のrace時刻を使って過去runの来歴を補完していない。

## 3. 出走馬集合

| DB内の出走IDと結果ID | レース数 |
|---|---:|
| 集合と一意の馬番が整合 | 68,490 |
| 結果行なし | 8 |
| 結果行はあるが不完全 | 2 |
| 馬番重複あり（上記に重複して数える） | 2 |

結果が欠ける10レースの欠落IDは計127。DB内の集合整合は、保存されていない馬が両テーブルから同時に欠けていないことまで証明しない。全頭の根拠には元結果表との照合が必要。

- `202504040406`: 馬番7の `2021105180` と `nk:2021105180` が別started行。結果なし。
- `202504040407`: 馬番15の `2022106098` と `nk:2022106098` が別started行。16出走行に対し結果15。151では完全結果の条件でレース全体が除かれている。
- `202608040910`: 15出走行に対し結果5。最新保存HTML自体が上位5頭分で、完全な結果表ではない。勝馬12番の26.4と払戻2,640円は一致するため、払戻額の誤りと断定しない。

保存snapshotと現在集合の差も残した。MEVは3レース×2モデルの6群で現在非出走となった馬1頭を含む。chaosは31レース（active30・void1）で、現在集合にない35頭はいずれも現DBの取消扱い、現在だけにいる馬はない。取消前に取得したsnapshotとして自然な場合があるため、これらを直ちに破損と判定しない。

全頭価格の逆数和が1を下回るunderroundは現DB123レース（平地64・障害59）、研究用保存物は全頭価格が有効な65レース。現在分はすべて2007〜2025年で、最小0.512152。999.9以上の上限オッズを含む例は0。異常候補として残すが、元資料がないレースの原因までは断定できない。

## 4. 精算処理の確認

現行の[購入履歴精算](../../api/src/horseracing_api/purchase_view.py)は単勝的中時に `購入額 × RaceHorse.odds` を返し、`OfficialWinPayout` を参照しない。attentionの公式払戻を使う経路と異なる。

保存されている同着 `202607020811` で、100円購入あたり次の差が生じる。

| 勝馬 | 保存オッズ | 現行式の計算額 | 公式払戻 |
|---|---:|---:|---:|
| 5番 | 26.5 | 2,650円 | 1,340円 |
| 15番 | 39.6 | 3,960円 | 1,960円 |

これは保存データと現行式の差の確認であり、当該レースの実購入有無・購入金額・実際の受取額を調べたものではない。同着を通常のオッズ不一致として混ぜるべきではなく、公式払戻を使う精算が必要。

## この監査から進める作業

1. 購入履歴の単勝精算を公式払戻へ統一し、同着と結果不足・払戻未保存を明示的に扱う。
2. 研究用価格の版と来歴を保存したまま、既存資料で確認できる範囲を別データセットにする。旧成果物は上書きしない。
3. ROI系単独と混合の判断は、価格・集合・時点の条件を満たす同一集合で評価する。151全期間については、現存資料のみで公式払戻による再検証ができないという制約を保つ。

今回は上記の実装・修復・再学習には進めていない。
