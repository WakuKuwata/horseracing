# Feature Specification: 追加混合の再現性と直近確認

**Feature Branch**: main（並行作業を維持）
**Created**: 2026-09-13
**Status**: Ready for implementation
**Input**: 「その順で進めて」— 本番校正の比較、1/7追加混合の再現性、候補固定後の8/29〜9/6確認。

## User Scenarios & Testing

### User Story 1 — 本番との差を正しく区別する (Priority: P1)

利用者は、132で改善した研究用上位着順校正が、現行本番に何を追加するのかを知る。

**Independent Test**: 同一勝率・同一校正係数で本番計算と研究計算が一致するかを全保存レースで照合する。実運用の材料を復元できない場合は直接の性能差を捏造しない。

**Acceptance Scenarios**:
1. 同じ入力で計算が等価なら、既存方式との差を新しい改善量と数えない。
2. 校正材料の対象・時点に差があれば、同じ期間の材料で制御した比較と、実運用再現の限界を分けて報告する。

### User Story 2 — 追加混合の再現性を確かめる (Priority: P1)

利用者は、補正後候補を1/7追加した改善が、学習乱数や馬体重の公表条件を変えても残るかを知る。

**Independent Test**: 固定した3つの乱数条件と2024／2026年で全情報・馬体重公表前を同一レースで比較し、全結果を保存する。

**Acceptance Scenarios**:
1. 元の乱数条件の全情報予測が元保存結果を再現する。
2. 候補だけを変え、比較基準の6モデル、追加比率1/7、補正規則を固定する。
3. 年・情報条件・乱数条件ごとに勝率と上位着順の誤差、校正、標本数を報告する。改善なしも省略しない。

### User Story 3 — 固定候補を直近期間で確認する (Priority: P2)

利用者は、直近成績を見て選び直すことなく、8/29〜9/6で候補の大きな崩れを確認できる。

**Independent Test**: 直近結果を読む前に候補・学習末日・校正・評価規則を固定し、その固定値で対象期間を一度採点する。

**Acceptance Scenarios**:
1. 直近データの既存参照状況と利用可能時点を調べ、完全未使用と確認できなければそう表示する。
2. 9/12・13を含む9/6後の実レース・結果・統計は取得しない。
3. 少数開催日の結果から微小改善の優位や採用を確定しない。

### Edge Cases

- 年次予測cacheに学習済み本体がない場合、別学習期間のモデルを同じものとして使わない。
- 日付不明、範囲超過、結果不完備、出走馬集合不一致、SHA不一致は検出して停止する。
- 当時の入力が得られず現在の訂正値しかない場合は、実運用時点の検証と称さない。
- 一部条件の悪化やCIが0を跨ぐ結果を隠さない。結果に応じて混合比や候補seedを変更しない。

## Requirements

### Functional Requirements

- **FR-001**: 実レース・結果・統計の上限は2026-09-06。以後の値を検索・調査・学習・採点に利用しない。
- **FR-002**: Step1→Step2→Step3の順で実測する。後続準備のコード・来歴調査は並行可。直近成績は候補固定まで読まない。
- **FR-003**: Step1は本番計算の等価性、材料変換の制御比較、復元できない実運用差を区別する。
- **FR-004**: Step2はseed42/43/44、2024/2026、全情報/公表前、補正後1/7追加を固定し全条件を測る。
- **FR-005**: 同じ学習から両公表条件を予測する。補正係数は同じseed・評価年の過去年係数を移送し、新規に候補へ合わせない。
- **FR-006**: 上位着順比較では、両案に同じ過去年・同情報条件の校正を適用し、公平な基準を保つ。
- **FR-007**: Step3はseed42候補、1/7、8/23までの学習済み6モデル基準を固定する。候補も同じ学習末日に揃え、年次学習比較と区別する。
- **FR-008**: 時点付き入力を優先し、現在の可変属性を当時値と仮定しない。欠ける入力や参照済み期間を明記する。
- **FR-009**: 勝率NLL、上位着順LogLoss/Brier/ECE、同一母集団、日単位の条件付きCI、実費を保存する。採用の自動判定や本番切替は行わない。
- **FR-010**: 既存の学習・提供コードと保存成果物は変更せず、新しい研究CLI・成果物を追加する。保存物は追記方式、入力とsourceのSHAを固定する。
- **FR-011**: 独立レビューと保存予測の独立再計算で確認する。

### Key Entities

- 比較条件：モデル、学習末日、情報条件、校正材料、混合比、評価期間。
- 固定入力：実日付範囲、取得時点、参照状況、入力SHA。
- 研究結果：各条件の全予測、品質、不確実性、再現性、限界、実行費用。

## Success Criteria

- **SC-001**: 使用した全実データが9/6上限に収まり、直近成績を読む前の候補固定を証明できる。
- **SC-002**: 本番との差について、等価と実測差と再現不能部分を読者が区別できる。
- **SC-003**: 固定した6学習条件・2情報条件の比較と、元seed全情報の再現確認が完了する。
- **SC-004**: 固定した直近期間を取得可能な時点入力で採点し、取得不能部分があれば範囲と理由を明記する。
- **SC-005**: 独立検証付きの結果と次の判断が揃う。改善なしも研究完了に含む。

## Assumptions

- 直近確認は小標本の診断であり、採用の最終確認ではない。
- 既存130年次本体は保存されていないため、直近確認は129の8/23学習本体と、それに同条件で追加学習する候補を使う。
- 脚質Unknownや温度補正の追加変更、混合比再探索、全7年への自動拡張は今回含めない。
