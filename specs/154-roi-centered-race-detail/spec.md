# 154 ROI中心のレース詳細と旧予測の比較表示

ユーザー依頼（2026-10-26）: 旧予測モデルは残したまま、買い目推奨を比較用に移し、レース詳細画面をROI系中心に整理する。

## 画面と既存契約

- 初期表示の主領域は「期待回収率・出走表」。馬番昇順とし、市場連動の期待回収率・市場混合・注目条件を既存APIの値で表示する。旧予測勝率・連対/複勝・市場差・寄与・旧モデル実行記録をここへ混在させない。
- 上部の操作はデータ更新。旧予測の生成と買い目生成は「予測モデルとの比較」へ移す。
- 下部は「オッズ」「予測モデルとの比較」。初期選択はオッズ。比較を明示的に開くまで旧予測/買い目を取得しない。初回表示後は比較をhiddenで保持し、タブ移動で実行中ジョブの追跡・完了後更新や選択モデルを失わない。レース変更時は比較の状態をリセットする。
- 比較領域にモデル選択・実行来歴・旧予測出走表・説明・市場比較・モデル診断・結合確率・旧買い目/Kelly配分を残す。生成は従来どおり採用モデルで、モデル切替は予測表示のみと明示する。
- 旧買い目は「比較用」、金額は仮予算での換算と明示。購入記録・訂正・手入力は独立した折りたたみとして保持する。モデル/予測/推奨/記録は削除しない。
- ROI系は「検証中」。推定表示、検証数値・不確実性・時刻・事後計算の開示、注目条件内訳、取消行の扱いを維持。EV順ソートやROI由来の買い目生成は追加しない。
- 主出走表の単勝は現在保存値であることと、ROI計算時の値/時刻とは異なり得ることを明示。ROIのodds_observed_atを主表の現在オッズ時刻に流用しない。旧予測由来OddsFreshnessは比較領域に置く。
- 旧予測の未生成・404/503・モデル切替がROI表示やその計算系列に影響しない。

## API/DB契約を先に固定

既存GET race/market-ev/attention/odds/predictions/recommendations/calibration/importanceを用途別に配置するだけ。POSTは既存opsの明示ボタン・購入記録だけ。API schema・DB・activeモデル・学習・確率・EV・閾値・S1〜S5・自動処理を変更しない。JointPanelは表示モデルのmodel_versionを引き継ぎ、比較中のモデルとの混同を避ける。

## 受入条件

1. 初期表示にROIの状態/値と出走表があり、旧予測勝率/買い目/生成操作は見えない。馬番順でEV列は非ソート。
2. 比較を開くと旧予測・生成・買い目・Kelly・記録と診断にアクセスできる。買い目の生成対象と表示モデルの違いを開示する。
3. モデル切替・予測失敗・未生成でもROI値は変わらず残る。
4. 比較タブから離れても既存ジョブのpollと成功時invalidateが続く。レースが変われば比較状態は初期化。
5. 推定バッジ・注目条件の局所的な表示規律、空・エラー・取消・市場混合欠損を維持。
6. front test/typecheck/lint/buildを実施し、可能な範囲でブラウザの初期/比較/狭幅表示を確認。
