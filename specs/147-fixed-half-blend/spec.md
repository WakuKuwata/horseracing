# 147 現行77特徴と展開91特徴の固定50:50平均

依頼: 現行77特徴と重みなし展開91特徴の保存予測を50:50で平均し、現行モデル・元の③と回収率と利益を比較する。最新提案2の予測後レース内正規化は結果確認まで保留。

- 各親の15seed raw確率を先に平均し、その2親を等比平均する。比率探索・学習・rawEV前の正規化はしない。
- baseline77は142の同条件再現、pace91は143の重みなしpace。③は143 weighted_baseline。現行保存予測は別の参考列として表示。
- 共通2019〜2026-06-21の24,855レース・343,883頭・807日。単勝rawEV>1.2、予算1000円/レース、100円単位・最大10頭、未使用予算は現金。
- 3比較を固定し、4000回の開催日paired bootstrap、seed20261025、指標ごとの3比較Bonferroni補正。購入なし日も含む。
- 既知高配当レース、最大利益差レース、同暦期間、2026年前後、上位5払戻0とDDを診断する。結果で購入ルールを変更しない。
- 既存360fitを検証して再利用、新fit0。本番・UI・DBは変更しない。確定オッズ由来の研究値、未参照holdoutなし・採用判定不可。
