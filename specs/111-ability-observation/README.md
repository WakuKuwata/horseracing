# 能力観測の経過日数・ばらつきの追加検証

**結論: 経過日数2列は長期ゲート未達、標準偏差1列は一次比較で見送り。現行138列・lgbm-094-cap900を維持する。**

110の削除検証後、次の優先候補として実施する研究。実験前に候補・期間・判定条件を固定し、現行138列への追加の効果を測る。本番モデルの変更や自動昇格は行わない。

## 固定候補

| 優先順 | 候補 | 追加列・定義 |
|---|---|---|
| 1 | observation_age | 最後の有効速度指数からの日数、過去最高速度指数を最後に記録してからの日数（同率最高は最新日）の2列 |
| 2 | observation_sd | 過去の有効速度指数の累積標準偏差、ddof=0・最低2観測の1列 |

既存の±5クリップ後の速度指数を用いる。コース基準タイムと個馬の履歴参照の両方で対象日全体を除外する。過去走の結果を素材とし、予測対象が決まれば当日の馬体重やオッズ公開前に計算可能。履歴なし・標準偏差の1観測はNaN、定数2観測以上の標準偏差は0。標準偏差は条件差も含む記述統計であり、推定誤差とは呼ばない。

休養日数・速度指数の観測数・平均/最高/直近3走/前走は既存列で維持する。2案の組合せ、期間や観測数の事後変更、結果を見た追加候補は本ラウンドで行わない。列追加に伴うLightGBMの列抽出なども含めた、現行学習手順での総合効果を比較する。

新しいREAD ONLY / REPEATABLE READトランザクションで、2007年以降・2026-08-23までの素材Frames、TrainingMatrix、EvalRaceを取得。基準と候補に同じFramesを使い、過去実験の別スナップショットを混在させない。

全期間は既に研究に使った履歴であり、未使用の将来期間の証明ではない。`can_adopt:false`を維持する。評価入力は当日馬体重が揃う条件で、公表前のserving性能は未測定。
