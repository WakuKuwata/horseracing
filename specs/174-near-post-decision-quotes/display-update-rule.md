# 表示値の更新規則(C14・2026-10-29 登録・利用者決定 B1)

正本は `display-update-rule.json`(sha256 は同名 `.sha256`)と `eval/src/horseracing_eval/display_update_rule.py`。両者の一致は `eval/tests/unit/test_display_update_rule.py` が固定する。どちらか片方だけ変えるとテストが落ちる。

## 規則

1. **前向き記録でしか変えない**。ROI 画面の表示版 `mev-ens15-v1`・120% の目印(`MARKET_EV_THRESHOLD=1.2`)・市場混合の 100% の目印(141)は、既読期間の点推定(142〜153 の 127% など)では変えない。
2. **証拠は 174 の `decision_quotes` のみ**。発走 3 分前の凍結 quote(1 レース 1 行・append-only)に現行の予測が並んで保存されているので、候補はそれと**同じレース・同じ価格**で精算する。精算は B8 と同じ(目印の馬に 100 円ずつ・公式単勝払戻)。
3. **置き換えの条件**: 精算済み点数 ≥ **300**(138 の第 1 チェックポイント・B8 の判断保留の床と同じ定数 `attention_rules.CHECKPOINTS[0]`)、かつ 候補−現行 の回収率差の **開催日ブロック bootstrap 95% 区間の下限 > 0**(impl/b/seed は 138 と同一 `attention_rules.BOOTSTRAP`)。
4. 300 点未満は `insufficient`(表示不変・判定なし)。300 点以上で下限 ≤ 0 は `keep`(表示不変。同じ点で候補を再試行しない)。
5. **規則の外**: 年次の係数・booster 更新(D17)は表示モデルの定義を保つ保守作業で、置き換えではない。

## 候補の精算経路について

候補(148 の予測後正規化・EV 加重再学習 ③ など)の予測は `decision_quotes.pred` には入っていない(現行 ens15・単一 `mev-binary-v2`・141 混合のみ)。候補を測るときは、保存された `field`(quote)と `features_sha256` の特徴行に候補モデルを**事後に**当てて同一価格で精算する(保存 quote は凍結値なので事後計算でも「判断時の価格」が保てる)。その経路は候補を決めた時の別 spec で作り、規則の数値は本文書から変えない。
