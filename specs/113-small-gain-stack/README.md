# 小幅改善の組合せ比較

**組合せの追加は保留し、相対能力13列を削除した125列モデルを研究候補として維持する。** 能力観測の経過日数2列を足した127列モデルは、現行138列より改善したものの、削除のみ125列に対してはwinner NLLが+0.000801悪化した。

比較は「組合せ127列−削除のみ125列」と「組合せ127列−現行138列」の2本を事前固定した。両方が改善方向で品質条件を満たす場合に組合せを保持する規則だったため、今回は `STACK_DEFERRED_PRUNING_RETAINED`。保留理由は追加効果の点推定が悪化したこと。CIはゼロを跨いでおり、経過日数の効果が存在しないと確定したわけではない。111の単独追加結果も変更しない。

## 結果

2019-01-01〜2026-08-23、26,437適格レース・825開催日。全評価対象は26,482レースで、適格数と区別する。差は候補−基準、負が改善。

|---|---:|---|---:|---:|---|
| 組合せ−削除のみ | +0.000801 | [−0.001636, +0.003252] | +0.001585 | +0.001493 | DEFER |
| 組合せ−現行 | −0.001472 | [−0.004784, +0.001754] | −0.000987 | −0.000892 | RETAIN_UNCERTAIN |

現行のwinner NLLは2.050434、削除のみ2.048162、組合せ2.048963。個別の改善幅を足すと見落とす、組合せでの効果の変化が実測された。

top2/top3、ECE、直近3/5年の非劣性ガードは両比較で通過した。重要部分集団は削除のみ比較ですべてPASS。現行比較ではcanonical/nkはPASS、2026年は `INCONCLUSIVE_LOW_PRECISION` で、非劣性が確認できたとはいえない。2026年の現行比は+0.002963、標本CI [−0.005760,+0.011701]。組合せが最新年でも改善するとの証拠にはしない。

2019〜2026-08-23の研究期間、seed42・900本・OOF8を固定。110/111と同じ入力を使い、来歴・全データ・実効レシピ・確率を照合して基準側16foldを再利用する。組合せ側8foldは最大2並列で新規学習する。再利用分の過去の学習時間は今回の計算時間へ含めない。

## 実行・検証

現在の主要ライブラリ版は111同値証明時と一致し、110/111のfreezeも再照合済み。全行列・EvalRace・8fold・16件の元予測を照合し、113の実行条件を固定した。単体49件・実モデル列と設定の統合5件の計54テスト、独立実装レビューが通過。3構成のsmokeで学習済み列と確率整合性も確認した。

新規8foldの学習を完了。学習開始から最終receipt保存まで約52.7分、各jobの学習経過時間合計104.3分。合計はCPU時間ではない。再利用した基準側16foldの過去の学習時間213.2分は今回の時間へ含めない。1workerあたり最大常駐メモリは約7.33GiBだった。

集計時に両比較の候補指標が一致すること、基準指標が旧110と一致すること、全体/直近3年/直近5年で差の恒等式が成立すること、全8receiptの来歴を確認した。[集計結果](verdict.json)と[検算方法](evidence/summarize.py)に保存した。[独立検算](result-review.md)でも全レースの損失・CIが一致した。

これは過去データでの研究比較であり、未使用期間の採用確認ではない。本番モデルの切替、feature version変更、年間確認枠の予約は行わない。

続けて、[114の残差予備検証](../114-gap-season-recheck/README.md)で改善方向だった出走間隔log補正を削除のみ125列へ加える[115の品質比較](../115-gap-log-quality/README.md)を完了した。補正の増分−0.001565、現行比−0.003617で研究候補に保持した（115の主期間は2020年以降）。この分岐は113結果が出る前に固定した。
